## 附录 B · 易混术语与英美表达 / Terminology Pitfalls

| 中文 | 英文术语 | 使用提醒 |
| --- | --- | --- |
| 中线 / 中位数 | median of a triangle / median (statistics) | 同为 median，但一个是三角形线段，一个是排序后数据的中间值。 |
| 梯形 | trapezoid (US) / trapezium (UK) | 英美用词与“至少/恰有一组对边平行”的定义可能不同。 |
| 一次函数 | linear function / affine function | 中学 y = kx + b 常称 linear；严格线性代数中“linear”通常需过原点。 |
| 直线 / 线段 | line / line segment | line 两端无限延伸；segment 有两个端点。 |
| 垂直平分线 / 角平分线 | perpendicular bisector / angle bisector | 一个平分线段且垂直，一个平分角度。 |
| 圆 / 圆盘 | circle / disk (disc) | circle 常指圆周；disk 指包含内部的圆形区域。 |
| 频数 / 频率 | frequency / relative frequency | 前者是次数，后者是占比；有些教材需看上下文。 |
| 因式分解 / 化简 | factor / simplify | factor 是写成乘积；simplify 是一般化简，不等同。 |
| 全等 / 相似 | congruent / similar | 全等保持形状和大小；相似保持形状但不一定大小。 |
| 命题 / 定理 | statement / theorem | 命题可真可假；定理是已证明的真命题。 |
| 补角 / 余角 | supplementary / complementary | 分别相加为 180° 与 90°，不可混用。 |
| 斜率 / 截距 | slope / intercept | slope 表示倾斜程度；intercept 表示与坐标轴交点的截距。 |

## 附录 C · 双语课堂与证明表达 / Classroom English

| 中文表达 | English classroom sentence |
| --- | --- |
| 设 x 为未知数。 | Let x be the unknown. |
| 根据题意，列出方程。 | Form an equation from the given information. |
| 将方程两边同时乘以 2。 | Multiply both sides of the equation by 2. |
| 合并同类项。 | Combine like terms. |
| 对这个式子进行因式分解。 | Factor the expression. |
| 解方程并检验结果。 | Solve the equation and check the solution. |
| 在同一坐标系中作出函数图像。 | Plot the function in the same coordinate system. |
| 由勾股定理可得…… | By the Pythagorean theorem, we have ... |
| 证明这两个三角形全等。 | Prove that the two triangles are congruent. |
| 因为两条直线平行，所以内错角相等。 | Since the lines are parallel, the alternate interior angles are equal. |
| 因此，这两个三角形相似。 | Therefore, the two triangles are similar. |
| 计算这组数据的平均数和中位数。 | Find the mean and median of the data set. |
| 画树状图列举所有可能结果。 | Draw a tree diagram to list all possible outcomes. |
| 综上所述，命题得证。 | Hence, the statement is proved. |

## 英文译名使用说明

本表面向中国初中（七至九年级）数学双语教学、英文题目阅读和 Manim 场景命名。它不是教育部的官方术语译本，例式也不能代替严格定义或定理证明。

- `linear function` 在中学常指 `y = kx + b`，严格线性映射常要求通过原点。
