## 核心概念辨析

| 概念对比 | 技术区别 |
|---|---|
| 计算机视觉与图像处理 | 图像处理强调滤波、增强、恢复等像素变换；计算机视觉还要推断对象、几何、动作及场景语义，两者有交叉。 |
| 图像分辨率与实际空间分辨率 | 像素宽高反映离散采样规模；能分辨的实际细节还依赖镜头、传感器、光学模糊与物距。 |
| 相机内参与外参 | 内参 K 描述相机坐标到像素坐标的映射；外参 R、t 描述世界坐标与相机坐标的相对位姿。 |
| 仿射变换与单应变换 | 仿射保持平行直线；一般单应变换允许透视畸变，可映射不同视角下的同一平面。 |
| 形态学 Dilation 与卷积扩张率 | 形态学膨胀扩大前景或局部上界；卷积 dilation rate 扩大卷积核采样间隔，两者不能混为同一操作。 |
| SIFT 与 ORB | SIFT 利用尺度空间及梯度直方图构造浮点描述子；ORB 结合 FAST 与旋转 BRIEF 输出紧凑二值描述子。 |
| 基础矩阵 F 与本质矩阵 E | F 描述像素坐标中的双视图对极约束；E 对应已标定相机的归一化坐标，包含相对旋转和平移方向。 |
| 单目深度与双目度量深度 | 单目预测常受绝对尺度不确定性限制；已知焦距和基线的校正双目可通过视差恢复度量深度。 |
| CNN 与 ViT | CNN 的局部卷积和权重共享引入空间归纳偏置；ViT 利用 patch token 与注意力显式建模位置间关系。 |
| 两阶段与单阶段检测器 | 两阶段先获得候选区域再分类回归；单阶段直接在特征图或查询集合上预测，速度与质量需具体测量。 |
| 目标检测 IoU、AP 与 mAP | IoU 衡量单次框重叠；AP 概括某类检测在阈值变化下的精确率召回率；mAP 在类别及约定阈值上聚合 AP。 |
| 语义、实例与全景分割 | 语义分割为像素赋类别；实例分割区分同类的不同物体；全景分割同时覆盖全部像素并标注可数目标身份。 |
| 光流、视觉里程计与 SLAM | 光流估计帧间像素表观运动；视觉里程计估计相机轨迹；SLAM 还要联合维护环境地图与全局一致性。 |
| NeRF 与 3D Gaussian Splatting | NeRF 常通过连续场和射线体积分合成视角；3DGS 使用显式高斯基元和泼溅光栅化，性能与重建结果依场景而异。 |
| CLIP 与可视化语言模型 | CLIP 通过图文对比学习获得共享表示，适合检索和零样本分类；生成式 VLM 通常进一步融合视觉特征与语言解码能力。 |
| 模型精度、鲁棒性与安全性 | 离线准确率只描述某个样本分布；遮挡、分布外输入、隐私泄露及对抗干扰需单独测评与治理。 |

## 中等难度技术面试问答

### 面试题 1：为什么图像 resize 前通常需要考虑抗混叠滤波？

**参考答案：**下采样会降低采样率，未先抑制超出新奈奎斯特限制的高频纹理可能发生频谱混叠，使边缘和纹理产生虚假模式。

### 面试题 2：相机内参矩阵与外参各负责什么？

**参考答案：**相机外参将世界点映射到相机坐标，内参把相机归一化投影映射为像素坐标，常写为 p~K[R|t]X。

### 面试题 3：为什么特征匹配后还要执行 RANSAC？

**参考答案：**描述子最近邻包含误匹配，直接估计几何模型会受异常点影响；RANSAC 通过内点一致性选择较可靠的几何解释。

### 面试题 4：单目相机做 SfM 为什么常存在尺度歧义？

**参考答案：**仅由投影几何无法区分整体场景与平移共同乘相同尺度后的解，需已知长度、IMU、深度或其他约束恢复米制尺度。

### 面试题 5：为什么语义分割 mIoU 高不意味着实例分割质量高？

**参考答案：**mIoU 关注类别像素集合，即使两个相邻同类物体被合并也可能得高分；实例任务需要正确区分对象并匹配掩码。

### 面试题 6：如何解释 COCO AP 与 AP50 的差别？

**参考答案：**COCO 主 AP 在 0.50 到 0.95 的多个 IoU 阈值上平均，AP50 只在 0.50 阈值下评估，因此 AP50 通常对定位精度要求较宽松。

### 面试题 7：什么情况下 CNN 在小数据集上可能比从零训练 ViT 更稳？

**参考答案：**CNN 的局部归纳偏置和参数共享有助于有限样本学习；ViT 表现还受预训练、增强、模型规模与训练配置影响。

### 面试题 8：DETR 为什么引入集合预测和二分图匹配？

**参考答案：**它把检测输出表示为固定数量对象查询的集合，通过一对一匹配分配训练目标，在原始设计中可减少传统锚框与 NMS 依赖。

### 面试题 9：NeRF 和 3DGS 在表示与渲染上的主要区别？

**参考答案：**NeRF 多采用连续神经场及射线采样积分，3DGS 用显式可优化三维高斯投影和 alpha 合成；两者都依赖相机标定和多视图监督。

### 面试题 10：为什么把训练图像随机翻转时也要变换标注？

**参考答案：**目标框、像素掩码、关键点及左右语义会随图像坐标变换而改变；只变图像不变标签会制造错误监督。

### 面试题 11：检测系统从 30 FPS 降到 10 FPS，应如何定位瓶颈？

**参考答案：**拆分摄像头解码、预处理、模型推理、后处理、数据拷贝和显示阶段，比较 p50/p99 时延及设备利用率后优化主要耗时环节。

### 面试题 12：视觉语言模型给出的图片事实为什么仍需核对？

**参考答案：**VLM 可受到训练偏差、分辨率和 OCR 限制，生成并不等于证据；应定位可见图像区域、检查文本数字并在高风险任务中人工审核。

## 中等难度考试题与解析

### 考试题 1：原图尺寸 1920×1080，等比例缩小到宽 640，输出高度应是多少？

**解析：**缩放比为 640/1920=1/3，因此高度为 1080/3=360。

### 考试题 2：给定两个框 A=[0,0,4,4]、B=[2,2,6,6]，计算 IoU。

**解析：**交集面积 2×2=4，两个框各 16；并集 16+16−4=28，IoU=4/28=1/7≈0.1429。

### 考试题 3：双目系统焦距 f=800 像素、基线 B=0.1 米、视差 d=40 像素，深度是多少？

**解析：**Z=fB/d=800×0.1/40=2 米，要求已校正双目并采用相容坐标单位。

### 考试题 4：32×32 图像经 3×3 卷积，stride=1、padding=1、dilation=1，输出空间大小是多少？

**解析：**按 floor((32+2−3)/1)+1=32，输出仍为 32×32。

### 考试题 5：640×480 三通道 uint8 图像未压缩像素数据多少字节？

**解析：**640×480×3=921,600 字节，约 0.879 MiB，不计文件头与内存对齐。

### 考试题 6：分类数据有 200 张图，其中 160 张 Top-1 预测正确，Top-1 Accuracy？

**解析：**160/200=0.8，即 80%。

### 考试题 7：某前景分割的 TP=80、FP=20、FN=40，Dice 系数是多少？

**解析：**Dice=2TP/(2TP+FP+FN)=160/220≈0.7273。

### 考试题 8：某类别分割 TP=80、FP=20、FN=40，IoU 是多少？

**解析：**IoU=TP/(TP+FP+FN)=80/140≈0.5714。

### 考试题 9：一张图分成 16×16 patch，输入为 224×224，每个 patch 不重叠，共多少视觉 token？

**解析：**每轴 224/16=14，共 14×14=196 个 patch token；若额外使用 CLS token 则合计 197。

### 考试题 10：视频有 300 帧、帧率 30 FPS，持续时间是多少？

**解析：**300/30=10 秒，忽略时间戳抖动与丢帧。

### 考试题 11：模型每张图平均推理 25 ms，完全串行、无其他开销时上限约多少 FPS？

**解析：**1/0.025=40 FPS；完整管线通常还受前后处理和设备并发影响。

### 考试题 12：某检测器在 IoU 0.5 和 0.75 下 AP 分别为 0.70 与 0.50，能否宣称 COCO AP 是 0.60？

**解析：**不能。COCO 主 AP 需从 0.50 到 0.95 共十个 IoU 阈值平均；仅两点均值不是该正式指标。
