## 16 组核心概念辨析

| 对比主题 | 关键技术差异 |
|---|---|
| 机器人学与计算机视觉 | 机器人学需要把传感观测转化为受动力学、接触和安全约束的物理动作；计算机视觉主要从图像中恢复结构或语义，属于机器人感知的重要组成。 |
| SO(3) 与 SE(3) | SO(3) 描述三维旋转；SE(3) 还包括平移，表示完整六自由度刚体位姿。矩阵和坐标系约定需要显式说明。 |
| 正向运动学与逆运动学 | FK 从关节角和连杆参数计算末端位姿；IK 从目标末端位姿反求关节配置，可能有多个解、无解或处于奇异附近。 |
| 雅可比奇异性与关节限位 | 雅可比奇异是速度映射的秩亏性质；关节限位是几何与执行器可用范围约束，两者并不等价。 |
| 运动学与动力学 | 运动学描述位置、速度、加速度间的几何关系；动力学研究产生这些运动所需的力、力矩及惯性效应。 |
| 阻抗控制与导纳控制 | 阻抗控制让机器人对运动误差表现为指定等效力响应；导纳控制以测得外力计算期望位移或速度，再由底层运动控制器跟踪。 |
| Holonomic 与 Nonholonomic Constraint | 完整约束可写为构型坐标等式；非完整约束通常是不可积的速度约束。差速底盘的侧向零滑动通常属于非完整约束。 |
| EKF、UKF 与粒子滤波 | EKF 线性化非线性状态模型；UKF 通过 sigma points 传播高斯近似；粒子滤波用样本逼近可多峰的后验，复杂度与假设不同。 |
| 里程计与 SLAM | 里程计积分局部运动、通常积累漂移；SLAM 还联合维护环境地图并利用地图约束或回环减少相对漂移。 |
| Pose Graph 与 Factor Graph | 位姿图通常只把位姿当变量并以相对位姿约束连接；因子图能同时包含位姿、地标、偏置等多类变量及测量因子。 |
| Path 与 Trajectory | Path 只表示经过的几何配置序列；Trajectory 同时规定每个状态的时间，必须满足速度、加速度及控制可行性。 |
| A* 与 RRT* | A* 在离散图上借助启发式求低代价路径；RRT* 在连续空间随机扩展并重连，满足特定假设时具有渐近最优性。 |
| Force Closure 与 Form Closure | Force Closure 借助摩擦约束下的接触力平衡任意方向外扰；Form Closure 基于纯几何约束限制物体自由运动。 |
| Imitation Learning 与 Reinforcement Learning | 模仿学习通过专家演示学习动作；强化学习根据奖励及交互优化策略，二者可预训练、离线学习或在线优化相结合。 |
| ROS 2 Topic、Service 与 Action | Topic 用于持续异步消息流；Service 适合短时请求响应；Action 适合持续任务并需要目标、反馈、结果与取消的交互。 |
| Sim2Real 与 Domain Randomization | Sim2Real 是从仿真策略到真实机器人的迁移目标；领域随机化是一种减少对特定仿真参数过拟合、提高迁移能力的训练策略。 |

## 12 道中等难度技术面试题

### 面试 1：为什么 7 自由度机械臂完成完整六维末端位姿任务时往往存在冗余？

**参考答案：**若任务雅可比在一般构型下满秩 6，则 7 个关节变量映射到六维任务，其一阶零空间至少为 1 维，可用于避障或远离限位；在奇异处零空间维数可能增加。

### 面试 2：为什么同一末端目标有时有多个 IK 解？

**参考答案：**机器人几何可出现肘上与肘下、腕翻转等不同关节构型映射到相同末端位姿；还要满足关节限制和碰撞条件。

### 面试 3：为什么单独调高 PID 的比例增益不一定能提高机器人稳定性？

**参考答案：**较大增益可能放大噪声、触发执行器饱和和延迟引起的振荡；需要考虑耦合动力学、离散采样和阻尼。

### 面试 4：阻抗控制为什么常用于接触丰富的机器人操作？

**参考答案：**它允许在任务方向建立柔顺的力—位移动态关系，降低精确位置指令与不确定接触几何冲突时的力峰值。

### 面试 5：差速底盘为什么通常不能直接在本体坐标系产生横向速度？

**参考答案：**理想纯滚动轮的无侧滑约束限制瞬时横向移动，只能通过前进和转向组合间接实现平面位姿变化。

### 面试 6：为什么 IMU 与相机融合需要时间同步和外参标定？

**参考答案：**两个传感器观测必须对应正确时刻和统一坐标系，否则融合残差会将时间偏差和安装偏差误认为运动或空间测量。

### 面试 7：EKF 为什么不能保证处理任意多峰定位分布？

**参考答案：**EKF 用局部线性化与单一高斯后验概括不确定性；当机器人位置存在多个离散可能位置时，这种表示可能严重失真。

### 面试 8：在地图已经建立的情况下，纯里程计和图优化 SLAM 的误差表现有何不同？

**参考答案：**纯里程计通过积分累积漂移；SLAM 可以利用重访地点及地标约束调整过去位姿，但结果仍取决于可观测性、关联正确性和模型误差。

### 面试 9：RRT 和 A* 应怎样根据问题选择？

**参考答案：**低维离散地图、明确边权时 A* 易于获得可解释路径；高自由度连续空间和复杂碰撞几何适合采样规划，需关注概率完备性和时间参数化。

### 面试 10：Force Closure 为什么需要考虑摩擦锥而不只是接触点数量？

**参考答案：**物体可抵抗外部广义力的能力取决于接触位置、法向、摩擦系数以及可实现的接触力集合，而非只取决于触点个数。

### 面试 11：为什么 ROS 2 长时间导航任务通常使用 Action 而非 Service？

**参考答案：**Action 提供执行过程中反馈、任务状态、目标取消与最终结果，适合持续时间较长且可被中断的导航任务。

### 面试 12：机器人在仿真中成功率高但现实中频繁失败，应如何诊断？

**参考答案：**分别检查传感器时延、相机外参、摩擦与质量参数、接触模型、动作频率、对象分布及成功判据，并通过真实试验和参数随机化缩小现实差距。

## 12 道中等难度考试题与解析

### 考试 1：差速机器人轮半径 r=0.1m、轮距 b=0.5m，左右轮角速度分别为 6、10 rad/s，求车体前向速度与角速度。

**解析：**v=r(ω_R+ω_L)/2=0.1×(10+6)/2=0.8m/s；Ω=r(ω_R−ω_L)/b=0.1×4/0.5=0.8rad/s。

### 考试 2：七关节机械臂执行六维末端任务，若 6×7 雅可比满行秩，雅可比零空间维度多少？

**解析：**按秩零化度定理 dim Null(J)=7−rank(J)=7−6=1。

### 考试 3：机器人平面位姿为 (x,y,θ)=(1m,2m,90°)，局部坐标点为 (1m,0)，其世界坐标是多少？

**解析：**旋转 90° 后偏移为 (0,1)，再加平移 (1,2)，结果为 (1m,3m)。

### 考试 4：一维卡尔曼更新：先验均值 2、方差 4，测量值 4、噪声方差 1，更新后的均值是多少？

**解析：**K=4/(4+1)=0.8；更新均值 μ=2+0.8×(4−2)=3.6，后验方差为 0.8。

### 考试 5：某机器人激光雷达工作频率 10Hz，理论相邻扫描开始间隔是多少毫秒？

**解析：**T=1/10s=0.1s=100ms；总端到端延迟还可能包含传输、处理和调度。

### 考试 6：机器人地图分辨率 0.05m/格，直线距离 3m 跨越多少个栅格单位？

**解析：**3/0.05=60 格，忽略边界取整和网格方向。

### 考试 7：某抓取接触法向压力为 10N、摩擦系数 μ=0.5，库仑静摩擦近似允许的最大切向力多少？

**解析：**|f_t|≤μ f_n=0.5×10=5N，前提是采用理想库仑锥且无额外接触限制。

### 考试 8：机器人关节从 0rad 在 2s 内匀速转到 1.6rad，平均关节角速度多少？

**解析：**平均角速度 Δq/Δt=1.6/2=0.8rad/s；这一计算不包含实际加减速约束。

### 考试 9：某视觉 SLAM 系统检测到回环，是否可以在不检查匹配的情况下直接加入图优化？

**解析：**不应直接加入。错误回环约束可能严重扭曲地图，需要几何一致性和稳健损失或其他验证。

### 考试 10：任务执行 100 次，成功 92 次，任务成功率是多少？

**解析：**92/100=92%；应同时报告场景分布、重复试验和失败类别。

### 考试 11：ROS 2 中持续传输 IMU、查询一次标定结果、执行可取消的导航任务，分别优先用什么接口？

**解析：**持续 IMU 用 Topic，短时请求响应用 Service，较长且需要反馈/取消的导航用 Action。

### 考试 12：路径长 2m，机器人用 5s 完成运动，平均路径速率为多少？是否等于每时刻的实际速度？

**解析：**平均速率 2/5=0.4m/s；不等于任一时刻瞬时速率，轨迹可能存在加速、减速或停止。
