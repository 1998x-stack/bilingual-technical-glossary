# TERM/ATLAS · 深度 Wiki 建设路线图

## 多层知识体系

- **L0 术语索引**：权威源、双语术语及精简释义，网站检索对应 `data/terms.json`。
- **L1 专业 Wiki**：一词一篇，可复核定义、直观比喻及局限、原理、工程决策、面试与考试题及解析、参考资料。
- **L2 知识路径**：依赖关系与跨术语案例，保存在作者工作目录，不在读者网站露出编辑批次。

## 读者与编辑入口

读者进入 [统一 Explorer](https://1998x-stack.github.io/bilingual-technical-glossary/#explorer)，从中英文术语名进入现有的 `term.html`；已合并文章才会通过公开 Wiki 索引映射到详情。批次计划、编辑状态和审稿台账仅供内部维护。

编辑依据：[正文模板](TEMPLATE.md) · [专业审稿](EDITORIAL_REVIEW.md) · [维护者指南](../docs/MAINTAINERS_GUIDE.md)。

## 分批制度（每批 20）

每批连续 20 条，末批不足 20 按余数。过程为：核对源词表及现有 PR → 一手来源调研 → 20 篇正文 → 题解与链接复核 → 完整镜像与索引 → CI → 人工审核 → PR 合并 → Pages 抽测。

## 发表标准

单篇至少 2 道中等难度面试题与 2 道考试题（均含参考解析），明确版本边界、知识辨析与来源。原稿与 Pages 镜像字节一致、源词表序号不跳号、公开索引不包含尚未写作的条目。人类专家审阅记录必须独立署名和带正文 SHA256；结构校验通过不等于技术内容经过专家认证。
