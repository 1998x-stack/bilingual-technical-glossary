# Hybrid Parallelism（混合并行）

> 学科：AI Infrastructure · 专题：分布式训练 · 注意区分概念本身与具体训练框架的版本差异

## 1. 核心定义

混合并行是按多个相互补充的维度同时划分训练任务，例如沿数据维复制模型、沿张量维拆分单层计算、沿深度维拆分网络层，以及将专家或长上下文分配给其他设备。它不是新的单一并行算法，而是**设备组划分 + 计算通信调度**的联合设计。

## 2. 形象理解

建设一座大型工厂：同一种生产线可复制多条（DP），一台机器内部可由多人分担计算（TP），一道产品加工要经过多道工位（PP），专家车间按业务类型分工（EP）。一个工人可能同时属于某条生产线和某个专用工位；这些分组的逻辑重叠必须由具体框架明确建模。

## 3. 技术原理与核心内容

典型 3D 并行以正交设备维度表达：若 `world_size=DP×TP×PP` 且各维都整除世界大小，可用坐标 `(dp,tp,pp)` 为每个 rank 分配通信组。TP 组内部交换激活，PP stage 之间传递前向激活/反向梯度，DP 组在相同模型分片之间归约梯度或分片模型状态。再加入 EP/CP 时需按框架确定哪些维度是真正独立的，**不能不看实现就简单把每个配置参数相乘**，否则可能重复计算 rank 数。联合调度应协调 microbatch、梯度累积、优化器更新和 checkpoint 格式。

## 4. 工程实践与设计权衡

部署 64 GPU 训练不能直接把所有并行度开到最大。先估算每 rank 参数+优化器+激活显存；再按高速互连确定 TP/EP 组，沿多节点分布安排 DP，最后按每个 PP stage 的实测开销切层。对比分组通信带宽、GPU idle、每更新 step 时间、token/s、OOM 与故障恢复。优先从最低复杂度的 DP/FSDP 配置起步，再为单层放不下引入 TP，为深层模型引入 PP。

## 5. 易混概念与边界

**DP** 决定样本分配，**TP** 切层内张量，**PP** 切模型深度，**EP** 切专家。混合并行的显存收益不是各策略收益简单相乘；共享激活、通信缓冲与分片 optimizer 状态要分开计量。

## 6. 中等难度面试题（含参考答案）

1. **问：为什么 TP 适合优先局限于同节点，而 DP 可以跨节点？** 答：TP 的每层计算通常频繁需要集合通信，对延迟和高带宽敏感；DP 常在反向传播梯度 bucket 上同步、可部分重叠。实际拓扑不只按“同节点/跨节点”划分，NVLink 交换网络和 RDMA fabric 可能改变最优映射。

2. **问：混合并行训练频繁 OOM，应该先调哪些维度？** 答：拆分参数/优化器/激活显存归因。权重占主导可考虑 FSDP/TP，长序列激活可考虑 SP/CP/重计算，单 rank stage 激活太多可调 PP/microbatch。每项均重新核算通信与峰值临时 buffer。

## 7. 中等难度考试题（含解析）

1. **题：理想相互正交的 DP=8、TP=4、PP=2，共需要多少 rank？** 解：`8×4×2 = **64**`。某一 DP 复制组有 4×2=8 rank；这是简化 3D 划分，未计 EP/CP 的不同重用规则。

2. **题：64 rank 固定 TP=4、PP=4，且只有 DP 维可扩展；可容纳几份数据副本？** 解：`DP=64/(4×4)=**4**`。如果另需正交 CP=2 则 DP 降为 2；实际框架的设备组定义必须先验证。
