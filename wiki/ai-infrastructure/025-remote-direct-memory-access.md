# Remote Direct Memory Access（远程直接内存访问 · RDMA）

> TERM/ATLAS · AI Infra Wiki · Batch 02 · 025/142 · 专题：互连与网络 · 研究日期：2026-11-16

## 1. 核心定义

**Remote Direct Memory Access**（远程直接内存访问，RDMA）是指：网络设备绕过部分 CPU 路径直接读写远端内存。

**理解边界：** 该术语在实际使用中须结合互连架构、协议、硬件代际和测量方式，而不能仅据标称速率推断性能。

## 2. 形象理解

传统 socket 通信常像让两家公司前台接收包裹、登记再递给仓库；RDMA 则在事先授权后，让网络硬件直接把数据放进对方的指定储位，减少途中反复搬运与内核介入。

## 3. 技术原理与核心内容

RDMA 通过支持的网络适配器将数据放入已注册的内存区域。典型 verbs 生命周期：创建保护域 PD、注册 MR 获取 lkey/rkey、创建 Queue Pair (QP) 与 Completion Queue (CQ)、交换连接/地址信息、投递 WQE、轮询完成。RDMA Write/Read 可以是单边操作，但远端授权和通信协调仍需由软件建立。内存注册/页固定有额外成本。

## 4. 工程实践与设计权衡

对频繁短消息的参数服务或存储场景，使用缓冲池与 MR 复用降低注册成本；审计 rkey 生命周期和访问权限，防止远程越界。测试必须分开报告单次延迟、持续吞吐、CPU 占用、消息大小与是否可批处理。

## 5. 关联知识与易混辨析

RDMA 不等于零拷贝的严格承诺：硬件及协议可能仍有拷贝或额外数据操作；它的核心是经网络直接访问注册内存、减少 CPU 参与数据路径。与普通 TCP socket API 的语义和编程复杂度不同。

## 6. 中等难度面试题（含参考答案）

1. **问：为何 RDMA Write 很快但不应直接用于没有同步协议的分布式锁？** 答：远端可见性、完成语义、内存排序与并发操作都需按协议规定；不能把本地 CQ 完成等同对方应用已消费数据。
2. **问：为什么动态申请、注册并释放每条消息的内存会严重拖慢 RDMA？** 答：MR 注册涉及固定页、建立映射/权限与内核/硬件协作，频繁操作会抵消高效数据路径收益；应预注册和复用。

## 7. 中等难度考试题（含解析）

1. **题：一次 RDMA Write 的本地完成通知是否等价于远端业务处理成功？** 解：否。它反映请求在 RDMA 层达到相应完成条件；远端应用是否读取/处理还须应用层协议确认。
2. **题：将 256 KiB 以有效 32 GiB/s 搬运，忽略固定开销，序列化时间？** 解：256 KiB / 32 GiB/s = (2¹⁸ / 2³⁵) s = 2⁻¹⁷ s ≈ 7.63 μs。
