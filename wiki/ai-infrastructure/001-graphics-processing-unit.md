# Graphics Processing Unit（图形处理器 · GPU）

> AI Infra Wiki · Batch 01 · 术语 001/142 · 来源：[AI Infra 原始术语](../../data/ai-infrastructure.tsv)

## 1. 核心定义

**Graphics Processing Unit**（**图形处理器**，GPU）：擅长高并行计算的处理器，是 AI 训练与推理的主要加速设备。

**精确定义补充：** GPU 含多个计算单元（如 NVIDIA SM），使用大量并行线程与分层存储执行 kernel。关键在于区分**硬件所提供的能力**、**程序的执行模型**和**应用实际获得的性能**。

## 2. 形象理解

把 GPU 想成一座有大量工位的工厂：每个工位处理相似的小任务；CPU 更像少量能处理复杂事务的资深工程师。类比强调吞吐，不代表 GPU 不能执行分支。

## 3. 技术原理与核心内容

GPU 含多个计算单元（如 NVIDIA SM），使用大量并行线程与分层存储执行 kernel。矩阵乘法通常通过分块、数据复用和专门矩阵计算单元提升吞吐；主机到设备的数据传输和同步仍可能限制整体加速。

## 4. 工程实践与设计权衡

先确认任务是否有足够并行度，再用 profiler 检查 kernel 时间、内存带宽、数据搬运和资源占用。小批量、强串行依赖或频繁 CPU↔GPU 往返可能使 GPU 不划算。

## 5. 易混概念与边界

GPU≠显卡：显卡是包含 GPU、显存、供电等的板卡；GPU≠CUDA：前者是硬件，后者是特定厂商的软件平台。

## 6. 中等难度面试题（含参考答案）

1. **问：为什么同一矩阵计算在 GPU 上不一定比 CPU 快？** 答：小矩阵启动与数据拷贝开销占主导，或算子没有足够并行度；必须比较端到端延迟而非仅看峰值。
2. **问：GPU 利用率高是否意味着算法高效？** 答：不意味着。忙碌可能来自无效访存、低算术强度或较差的算子安排；应结合吞吐、带宽和能效。

## 7. 中等难度考试题（含解析）

1. **题：某计算在 CPU 上耗时 120 ms，GPU 计算 15 ms，传输与同步 9 ms，端到端加速比是多少？** 解：(120)/(15+9)=5 倍；只比较 kernel 会误报 8 倍。
2. **题：解释训练时为什么常增大 batch 以提高 GPU 吞吐，但过大 batch 仍有风险。** 解：增大 batch 提高矩阵规模与并行度，却增加显存占用，并可能改变优化和收敛表现。
