# Double Data Rate Memory（双倍数据速率内存 · DDR）

> AI Infra Wiki · Batch 01 · 术语 015/142 · 来源：[AI Infra 原始术语](../../data/ai-infrastructure.tsv)

## 1. 核心定义

**Double Data Rate Memory**（**双倍数据速率内存**，DDR）：广泛用于服务器主内存的 DRAM 技术。

**适用边界：** DDR SDRAM 在时钟信号的两个边沿进行数据传输；速率通常用 MT/s（百万次传输/秒）表示，而不是直接等同于内部时钟 MHz。解释该术语时应指明具体架构、设备代际或测量口径，不能将理论指标直接等同工程表现。

## 2. 形象理解

DDR 像一条道路在时钟上升沿和下降沿各运输一次数据，因此同一时钟频率下每周期有两次传输机会。

## 3. 技术原理与核心内容

DDR SDRAM 在时钟信号的两个边沿进行数据传输；速率通常用 MT/s（百万次传输/秒）表示，而不是直接等同于内部时钟 MHz。理论带宽=传输速率×数据总线字节宽度×通道数。

## 4. 工程实践与设计权衡

服务器 DDR 常用于 CPU 主存、大容量数据缓存与模型装载。配置 NUMA、通道数、频率与访问局部性会影响实际带宽；不同代 DDR 的主板兼容性需逐一核对。

## 5. 易混概念与边界

DDR 的“双倍”指每时钟周期两次数据传输，不等于任何任务速度直接翻倍；DDR 与 HBM 是不同封装/接口设计。

## 6. 中等难度面试题（含参考答案）

1. **问：为何不能把 DDR5-5600 直接当 5600 MHz 时钟？** 答：5600 通常表示 5600 MT/s 的传输速率，两沿传输与内部时钟概念不同。
2. **问：增加内存条数一定提升带宽吗？** 答：只有在增加独立有效内存通道且控制器/拓扑支持时才可能提升，并不与条数线性对应。

## 7. 中等难度考试题（含解析）

1. **题：单通道 64-bit DDR，速率 3200 MT/s，理论峰值带宽？** 解：3200×10^6×8 B/s=25.6 GB/s（十进制）。
2. **题：双独立通道其他条件不变时理论带宽？** 解：51.2 GB/s；实际可能受访问模式和系统限制。
