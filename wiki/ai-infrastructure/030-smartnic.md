# SmartNIC（智能网卡）

> TERM/ATLAS · AI Infra Wiki · Batch 02 · 030/142 · 专题：互连与网络 · 研究日期：2026-11-16

## 1. 核心定义

**SmartNIC**（智能网卡）是指：具备可编程或任务卸载功能的网络接口卡。

**理解边界：** 该术语在实际使用中须结合互连架构、协议、硬件代际和测量方式，而不能仅据标称速率推断性能。

## 2. 形象理解

SmartNIC 相当于可以编写规则的‘智能货运分拣站’，不仅能收包，还能对包进行筛选、加工、调度和某些计算，让主机 CPU 少做重复性工作。

## 3. 技术原理与核心内容

SmartNIC 通常在 NIC 上添加可编程处理能力（例如 eBPF/P4、嵌入式处理器或可配置数据平面），执行隧道封装/解封装、流量分类、加密、安全过滤和虚拟交换等任务。能力由硬件数据路径、固件、驱动和软件 SDK 共同决定，不能假设任意程序都能下沉。

## 4. 工程实践与设计权衡

准备卸载包过滤或虚拟交换时，应建立功能覆盖矩阵：哪些规则能 offload、哪些会退回 host、各项资源表容量和更新延迟如何？采集 CPU 使用率、p99 端到端时延、包丢失率、功耗与可观测性指标。SmartNIC 也会增加版本治理和调试复杂度。

## 5. 关联知识与易混辨析

普通 NIC 已有一些固定 offload（例如校验和），不代表全都应称 SmartNIC。SmartNIC 强调更广泛的可编程/独立执行能力；DPU 可被视为更丰富的一种形态，但业内术语没有绝对边界。

## 6. 中等难度面试题（含参考答案）

1. **问：为什么将防火墙规则放到 SmartNIC 后性能反而下降？** 答：规则无法完整下沉导致 host fallback；规则表容量限制、频繁更新或低效匹配也可成为新瓶颈。
2. **问：设计 SmartNIC 升级策略时最需要防范什么？** 答：驱动/固件/SDK 兼容性，灰度升级与回滚、规则一致性及管理面安全；避免更新时形成不可预期的流量中断。

## 7. 中等难度考试题（含解析）

1. **题：传统路径每包占 CPU 500 ns，卸载后每包只需 120 ns，处理 10⁶ 个包的理论 CPU 时间节约多少？** 解：(500−120) ns×10⁶=0.38 s 的 CPU 时间；不是单个请求端到端延迟降低 0.38 s。
2. **题：在 1.5 Mpps 持续流量下，每包 CPU 处理时间 400 ns，CPU 需求核数理论下界？** 解：1.5×10⁶×400×10⁻⁹=0.6 核（100% 利用时）；实际要为其他处理和峰值预留空间。
