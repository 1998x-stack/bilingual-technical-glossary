# Operating Expenditure（运营性支出 · OpEx）

> 学科：AI Infrastructure · 专题：成本、能效与资源治理 · 成本、能效与遥测的边界需按产品版本声明

## 1. 核心定义

运营性支出（Operating Expenditure，OpEx）指在正常经营与服务提供过程中发生并通常在相应期间确认的费用，例如云 GPU 实例租用、电力、带宽、运维服务、软件订阅和日常支持。费用会计分类取决于合同、准则与组织政策；不能把所有按月付款自动判定为 OpEx，也不能把所有资本资产的当期折旧重复算作新增现金流。

## 2. 形象理解

开餐馆买厨房设备更接近一次性资本投入，而每月的电费、食材、租金与雇员工资是持续经营支出。少付一次性采购款可能使每月运营费更高，因此必须看完整生命周期。

## 3. 技术原理与核心内容

在成本模型中可按月度运营费分项：`OpEx_month = GPU实例费 + 存储 + 网络/出区 + 电力 + 软件 + 运维 + 平台共享分摊`，并注明是否包含税、折扣与预付承诺的摊销。云服务有按需、Spot、RI/Savings Plans 等计费模型：实际现金支付时点与资源使用期的有效成本应统一。年度成本预测常用 `C=Σ_i(rate_i×usage_i)+fixed_costs`，资源使用要按账单单位和边界匹配，GPU-hours 不等于成功生成的 token。

## 4. 工程实践与设计权衡

FinOps 实践首先按服务、项目、环境、模型和租户建立标签/成本中心，再结合 usage counters 分配 GPU 计算、对象存储、网络和可观测性平台费用。比较上周/本周有效百万 token 成本时控制输入/输出长度、量化精度、SLO 与地区，不把成本下降但错误率升高当成成功优化。做月度预算偏差、闲置资源、承诺覆盖率和异常账单分析，明确共享平台的分摊规则。

## 5. 易混概念与边界

OpEx 是持续运营费用视角，CapEx 是资本资产投入视角，TCO 是指定周期内全生命周期成本。长期云承诺可以影响现金和折扣，不意味着企业从此无需考虑资产或会计准则。

## 6. 中等难度面试题（含参考答案）

1. **问：为何只统计云 GPU compute 账单会低估推理 OpEx？** 答：常被漏算的有对象存储、权重下载/出区、日志和 trace、网关、支持、开发运维、失败重试与闲置资源。应定义完整成本池并归属工作负载。

2. **问：月度成本增加 20% 就必然变差吗？** 答：不一定。若合格服务请求或 token 产出增长更多，单位经济性可能改善；还要看质量、SLO、业务收入与资源风险。

## 7. 中等难度考试题（含解析）

1. **题：某平台月 GPU 费用 80 万元、存储 10 万、网络 5 万、运维软件 15 万，月 OpEx？** 解：`80+10+5+15=**110 万元**`，假设无其它成本项。

2. **题：每月固定成本 40 万元，每百万有效 tokens 可变成本 500 元，产出 200 百万 tokens，总月运营成本？** 解：`400000+500×200=**500,000 元**`，即 50 万元。
