# Generalist Agent（通用智能体）

> AI Agents · 专题：多智能体协作 · 多智能体角色和可复核的工程能力边界

## 1. 核心定义

**Generalist Agent（通用智能体）**：Generalist Agent（通用智能体）是能够跨多个任务类型进行理解、规划、工具选择和行动的 Agent。它适合任务类别变化、初步分诊、信息整合或复杂工作流入口，但能力广度并不保证每个专业领域的深度和安全性。

**适用边界：**通用 Agent 可能使用通用模型和多种工具，但‘通用’不是任意系统权限，也不是所有环境操作都可靠。任务越复杂、专门约束越多，越需要路由给专业能力和受控执行器。

## 2. 形象理解

像综合事务协调员能理解多部门需求并帮忙找到合适流程，却不必亲自完成法律审查或系统部署。

**类比的局限：**协调员知识面广，但对专业问题可能需要咨询专家；任务接得多也更容易使用错误工具。

## 3. 技术原理与核心内容

通用 Agent 的输入为意图和上下文，首先做 `classify goal/risk → select capabilities → act or delegate → verify outcome`。工具发现应限制可见候选，并依身份过滤；遇到领域高风险时调用有明确职责的 Specialist Agent 或进入人类批准。对工具多样性的失效使用混淆矩阵和高后果误操作率评价，而不是只看任务数量。

## 4. 工程实践与设计权衡

**工程案例：**企业办公 Agent 可以回答制度问题、安排会议和查工单，但用户提出生产数据删除时转入审批/专职运维流程，而非凭广泛工具描述自动删除。对跨业务会话保留必要授权与隐私隔离。

**失败模式与验证：**过多同名工具导致误选、不同领域规则冲突、长提示挤出关键用户约束、任务委派循环。通过多域基准、混淆型对抗输入和独立业务成功标准验收。

## 5. 关联知识与易混辨析

Generalist Agent 侧重能力覆盖面；Specialist Agent 侧重单领域深入和受限能力；Manager Agent 侧重分配任务与最终控制，它也可能兼具通用能力，但不是同义词。

## 6. 中等难度面试题（含参考答案）

1. **问：通用 Agent 什么时候该转交专业 Agent？** 答：遇到专业工具/政策边界、复杂领域评估或高风险动作时，且专员有明确更适配的能力与权限范围。
2. **问：给通用 Agent 200 个工具为什么可能降低效果？** 答：会增加选择混淆、上下文成本与误用风险；宜通过发现、检索与路由分层暴露必要能力。

## 7. 中等难度考试题（含解析）

1. **题：通用 Agent 在文档、财务、代码三类各完成 20、15、10 项任务，共 60 项任务，整体成功率？** 解：(20+15+10)/60=45/60=75%；各类基数可能不同，应分别报分项指标。
2. **题：用户只想查询订单，但通用 Agent 有订单创建权限，这是否意味着可以创建？** 解：不是。权限能用不等于用户已授权执行此动作，需与用户目标及执行授权相符。
