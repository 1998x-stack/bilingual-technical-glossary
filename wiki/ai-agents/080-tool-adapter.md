# Tool Adapter（工具适配器）

> AI Agents · 专题：工具使用与环境交互 · 具体工具行为、权限与版本以官方规范为准

## 1. 核心定义

**Tool Adapter（工具适配器）**：Tool Adapter（工具适配器）是在 Agent 统一工具接口与异构外部 API、CLI、数据库或 GUI 之间进行协议、认证、字段、错误和数据模型转换的组件。其目标是屏蔽差异，同时不掩盖真正的业务语义。

**适用边界：**适配器不能凭空创造原始服务不存在的幂等性或权限；转换过程应保留来源、请求 ID 与错误细节，避免把未知状态误规范化为成功。

## 2. 形象理解

像不同国家电器的插头转接器：让物理接口能连接，但不能自动解决电压不兼容或用电安全。

**类比的局限：**若背后的协议/事务规则不兼容，只有形状转换远远不够。

## 3. 技术原理与核心内容

外部接口可定义统一 `ToolRequest={tool_id,args,context,idempotency_key}` 与 `ToolResult={status,data,error,provenance}`。adapter 把统一字段映射到目标服务、绑定可信身份、处理序列化/分页/重试约束，并将 HTTP 错误、CLI exit code 或数据库异常映射到明确状态。验证转换前后语义一致、单位/时区正确，不可静默吞掉错误。

## 4. 工程实践与设计权衡

**工程案例：**订单 Agent 同时接入两个快递公司：A 返回 weight_g、B 返回 weight_kg。两个适配器统一转为千克且带原始来源；当某服务只有‘已接单’状态时，不得强行映射为‘已送达’。

**失败模式与验证：**单位换算丢精度、无条件重试非幂等接口、适配器拥有高于业务请求的权限、错误码被吞并或数据字段错映射，会导致跨系统失真。使用双向合约测试、故障注入和版本固定审查。

## 5. 关联知识与易混辨析

Tool Adapter 做具体协议/数据转换；Tool Routing 决定选用哪个适配器；Tool Registry 提供定义与版本元信息；API/CLI 是外部工具的实际接入形式。

## 6. 中等难度面试题（含参考答案）

1. **问：为什么统一适配器仍不能保证重试安全？** 答：后端可能没有幂等语义，适配器无法靠本地重试伪造服务器端事务去重；需按后端协议设计状态查询和补偿。
2. **问：两个服务分别以克和千克返回重量，适配层必须做什么？** 答：显式单位映射、记录来源/时间，必要时处理精度/舍入；对调用方暴露一致的单位契约并用合约测试。

## 7. 中等难度考试题（含解析）

1. **题：供应商 A 返回 1250 g，供应商 B 返回 1.5 kg，统一成 kg 分别是多少？** 解：A 为 1.25 kg，B 为 1.5 kg；A×0.001，不能直接按数值大小比较。
2. **题：后端返回 HTTP 超时，适配器能否直接标准化为 status=failed？** 解：通常不能，特别是写操作结果未知；应标记 unknown、记录请求 ID 并按后端状态查询决定后续处理。
