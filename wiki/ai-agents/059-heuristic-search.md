# Heuristic Search（启发式搜索）

> 适用领域：AI Agents · 专题：任务规划与决策 · 基础概念与具体 SDK 权限实现需分开判断

## 1. 核心定义

**Heuristic Search（启发式搜索）**：Heuristic Search（启发式搜索）利用启发函数 h(n) 对目标距离或后续代价进行估计，从而优先探索更可能通向好解的候选。A* 是经典例子，用 `f(n)=g(n)+h(n)` 综合已付成本和估计剩余成本。

**适用边界：**启发信息不必总是准确；A* 的最优性结论依赖启发式可采纳性（不高估真实最小剩余代价）以及具体图搜索实现的处理条件，不能泛称任何 h 都保证最优。

## 2. 形象理解

像配送司机依据距目标的地图距离优先试探道路，比毫无方向地遍历更有目的。

**类比的局限：**直线距离可能忽略封路和拥堵；“看起来最近”并不保证真实总成本最低。

## 3. 技术原理与核心内容

在非负边代价的最短路径问题，令 g 为已知路径成本、h 为从当前状态到目标的估计，A* 按最小 `f=g+h` 扩展。若 h 不高估剩余真实最优代价则为 admissible；若 `h(n)≤c(n,n')+h(n')` 则为 consistent。图搜索使用最优 g 表、必要时重开节点，具体停机/最优性条件按实现验证。

## 4. 工程实践与设计权衡

**工程案例：**维修派单 Agent 用预计路程和历史服务耗时排序候选路线，再由地图服务校验限行及实时交通；对紧急任务必须先通过区域权限与安全限制，不允许模型的“估计距离”代替真实导航。

**失败模式与验证：**估计不合理会导致无效扩展甚至次优结果；启发式评估开销过大可能抵消节省节点的收益。测试在已知最优的小图上验证成本与扩展数量。

## 5. 关联知识与易混辨析

Heuristic Search 使用经验估价引导搜索；盲目 BFS/UCS 不依赖目标距离估计；Lookahead Search 强调模拟未来若干步的后果，可能结合启发值。

## 6. 中等难度面试题（含参考答案）

1. **问：何种情况下 A* 可以保证最短路径？** 答：需明确非负成本、适当的终止/重复状态处理，以及 admissible h；图搜索若不重开节点通常还需一致性条件。
2. **问：启发函数越大越好吗？** 答：不一定；过高估计可能破坏 admissibility，过于复杂也会增加计算开销。应比较扩展节点数、CPU 成本和解的最优性。

## 7. 中等难度考试题（含解析）

1. **题：候选 X 已花费 g=6、估计 h=4；Y 的 g=3、h=8。A* 优先扩展哪个（无其他节点）？** 解：f(X)=10，f(Y)=11，优先 X；这是选择下一扩展节点，并不独立保证最终路径最优。
2. **题：真实最短剩余成本为 7，启发 h=9 是否 admissible？** 解：否，h=9>7，高估了剩余最优代价；因此不满足可采纳性条件。
