# Agentic Retrieval（智能体式检索）

> AI Agents · 专题：检索与知识增强 · 适用范围：知识管理与检索工程；具体 API 以版本文档为准

## 1. 核心定义

**Agentic Retrieval（智能体式检索）**：Agentic Retrieval（智能体式检索）是由 Agent 根据问题复杂度、已获证据与当前目标，动态决定检索工具、查询语句、是否拆分子问题及何时继续或停止检索的流程。它把检索视为可反馈的多步决策，而不是固定一次向量搜索。

**适用边界：**该术语没有单一强制算法标准；多轮规划可能提高复杂问题的证据覆盖，也会增加成本、延迟和循环误用风险。所有检索仍须遵守资料访问权限。

## 2. 形象理解

像研究员发现第一份资料只回答一半问题后，改用不同关键词查官方文件，并对冲突材料交叉验证。

**类比的局限：**研究次数越多不意味着证据越好，反复查看同一低质量来源只会增加噪声。

## 3. 技术原理与核心内容

流程可建模为 `decompose question → select collection/tool → retrieve → judge coverage/conflict → rewrite/refine → repeat within budget → synthesize with citations`。在每轮保存查询、资料来源、失败原因和已覆盖的子问题；使用停止准则如事实已足够、达到 token/请求预算或剩余问题无法证实。对检索工具返回的提示词指令保持低信任隔离。

## 4. 工程实践与设计权衡

**工程案例：**分析采购合同是否符合今年的风险要求，Agent 先查当前制度，再查询合同条款，发现缺少地域附录时补检，不会仅凭合同标题的语义相似度给出合规结论。最后保留证据链接和未解决事项。

**失败模式与验证：**无限检索循环、重复搜索同一查询、自动改写丢掉限制条件、受污染网页引导 Agent 调用写工具。以新增证据收益、完整性、成本和来源可靠性评测，设置每轮上限和失败退出。

## 5. 关联知识与易混辨析

Agentic Retrieval 是多步自适应搜索控制；Query Rewriting 是其中一种查询变换动作；Reranking 是对已有候选重排序；固定 RAG pipeline 不一定包含自主检索循环。

## 6. 中等难度面试题（含参考答案）

1. **问：什么问题适合 Agentic Retrieval 而不是单次搜索？** 答：多跳问题、证据分散或需对比多个版本/主体的情况，但必须权衡增加的延迟和工具成本。
2. **问：如何阻止 Agent 在检索中越查越远？** 答：限制子问题范围、工具/轮数预算，用证据覆盖与任务目标判断是否继续，记录检索收益和停止原因。

## 7. 中等难度考试题（含解析）

1. **题：一次检索花 0.4 秒，Agent 连续执行 5 轮、每轮评估额外 0.2 秒，严格串行总耗时？** 解：5×(0.4+0.2)=3 秒，忽略网络排队。
2. **题：问题要求‘2026 年某地现行政策’，模型重写成‘政策简介’，可能丢失什么？** 解：丢失年份、地区与现行性约束，会召回无效版本；重写必须保持这些过滤条件。
