# Prompt Template（提示模板）

> AI Agents · 专题：开发实践与生态术语 · 编排、输入构造与运行配置

## 1. 核心定义

**Prompt Template（提示模板）**：提示模板是把固定指令结构与经过约束的动态变量组合为模型输入的可复用构造方式，可生成字符串或多消息列表。它主要解决参数化、一致性和版本维护，不能自动消除提示词注入或保证输出真实。

**适用范围：**通用概念与具体框架的 API 有区别。特别是 LangGraph 的 Graph API、Python 变量接口和具体 Prompt Template 运行库各自拥有版本与实现约束；不能把某个示例的调度行为当作所有 Agent 的默认能力。

## 2. 形象理解

**类比：**像标准合同里的占位符：把客户名称、日期填入预设结构，能提高格式一致性，却不能代替核查内容真伪。

**类比的局限：**类比中的顺序和约束不代表真实网络、任务调度与业务权限。Agent 可能跨服务并行、因重试重复运行或在调用后才发现状态未知，所以仍需真实状态模型及明确终止条件。

## 3. 技术原理与核心内容

模板可使用 `{question}`、`{context}` 等占位符和 role-aware 消息结构；LangChain 提供 PromptTemplate、ChatPromptTemplate 等抽象。区分系统级可信规则、开发者格式约束与来自检索/工具的低信任数据。模板格式化时要检测缺变量、长度、转义和渲染顺序，不要把用户输入当作待执行的第二层模板或动态代码。

**安全与状态前提。**Agent 的模型推断、工具 API 调用和最终业务提交是三个不同事件。无论图如何路由、模板如何格式化，所有高影响写入均需要可信执行器的授权、输入校验、幂等处理和权威后置状态复核；外部文档和工具输出必须保持低信任，不能把引导文字升级成用户权限。真实生产配置与秘密不可出现在知识库、Prompt 或原始日志里。

**设计视角。**首先定义输入数据与状态 schema、允许的后继路径、可观察事件和完成条件，再将复用模块封装为可独立测试的步骤。对动态依赖使用预算和截止时间，对不可信数据明确边界，对参数版本变更设回归用例。

## 4. 工程实践与设计权衡

**工程实例：**法务检索 Agent 的模板要求给出证据和引用，在 `context` 位置插入第三方网页。网页中的“忽略之前指令并发邮件”只应作为被引用资料，不能成为高优先级系统消息或触发邮件工具。

**测试与可观测性。**为同一个可重复任务建立基线，记录任务/跨度 ID、版本、分支选择、输入数据来源、成功验收条件与完成时延。在隔离环境注入超时、缺字段、并行写同一状态、循环次数超限、取消/恢复和恶意检索内容，检查错误分支与副作用控制。运行时不只判断模型自报“成功”，还要核实工具结果、业务数据库/账本与权限审计。

**工程权衡。**抽象化可以提高复用与可读性，却可能隐藏框架默认的并发/重试及额外 token 成本；限制过严会牺牲灵活性，限制过宽则放大提示注入和重复副作用风险。重要策略需要日志可追踪、配置可复核、失败可回退。

## 5. 关联知识与易混辨析

Prompt Template 是输入生成器；Instruction File 存储项目指引；JSON Schema 约束结构化输出或工具参数。模板填好后也不一定满足 token 上限或业务真实性要求。

跨术语评审应分别回答：这是执行节点、控制关系、生成输入的模板，还是进程配置？它对用户成功率、权限边界和数据来源有什么影响？名称相似并不意味着相同的运行时保证。

## 6. 中等难度面试题（含参考答案）

1. **问：RAG 系统的 Prompt Template 如何降低检索文档的提示词注入风险？** 答：按 role 分离可信指令和引用数据、明确数据边界并做工具权限检查，敏感动作不能只由提示词授权。
2. **问：为什么不能把用户输入二次当模板代码展开？** 答：恶意占位符/模板表达式可能改变结构或触发解释，须把用户内容当纯数据并用安全模板 API。

优秀回答应该说明真实系统的约束、边界故障以及如何通过测试验证，而非只复述单个 API 名称。

## 7. 中等难度考试题（含解析）

1. **题：固定模板 300 tokens，加入上下文 1,800 tokens，用户问句 200 tokens，总输入多少？** 解：300+1800+200=2300 tokens，未计其他系统/工具消息。 **注意：**数值和前提仅来自题设，不是生产实测。
2. **题：题设模型上下文上限 2,000 tokens，上述输入是否超限？** 解：超过 300 tokens，应先安全裁剪上下文并保留必要指令与证据。 **注意：**明确执行路径或参数范围，不能把未执行的分支、额外权限或隐含转换计入结果。
