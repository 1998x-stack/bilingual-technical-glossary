# Instruction File（指令文件）

> AI Agents · 专题：开发实践与生态术语 · 结构化能力、工具契约与执行安全

## 1. 核心定义

**Instruction File（指令文件）**：指令文件是在仓库、技能或项目中存放对 Agent 开发行为、测试流程和约束的可阅读文档，例如 `AGENTS.md` 或 `SKILL.md`。它为使用者提供环境约定，但不是操作系统权限或真正的服务端授权。

**适用边界：**通用术语与特定规范的关系需分别确认。MCP、Agent Skills、JSON Schema 等有各自版本与作用域，不能把某个宿主的实现行为假定为标准要求。读取声明、通过校验和产生外部业务结果是不同的阶段，不可一概称为“执行成功”。

## 2. 形象理解

**类比：**像施工现场的安全规程和楼层平面图，指引工人如何作业。

**类比的局限：**真实 Agent 还涉及权限、分布式网络、模型选择与动态状态，直观比喻没有完整表达数据流和并发失败。即使一个参数格式合法，也不表示执行主体有权读取/写入相应资源。

## 3. 技术原理与核心内容

典型 AGENTS.md 描述项目结构、测试命令、代码风格和维护注意事项；SKILL.md 则是具有元数据和正文的技能说明。Agent 应按可信来源与适用范围解析，避免让仓库中不受信任的文件覆盖用户授权、泄露秘密或改变保护策略。说明文本及其优先级依宿主实现，不能宣称所有文件都相同。

**可信执行边界。**Schema、Instruction File、Tool Manifest 和 Skill 文件都属于声明/约束信息，无法直接证明数据真实、调用被授权或外部动作已成功。Agent 应按照可信用户授权、宿主执行策略、工具后端 ACL 和真实业务状态分别检查；外部工具说明与文件内容必须保持低信任。读取一个 Skill 或发现一个 Tool 不意味着可以运行敏感脚本，参数形状校验更不能代替付款/删除等操作的服务端鉴权。

**实施步骤：**确定用户目标与可用资源→解析声明和规范版本→匹配技能/工具→校验具体输入及其来源→应用后端权限与业务规则→记录后置状态。对外部脚本设置沙箱、网络出口和秘密隔离；对工具输出保留来源标签，阻止提示词注入跨越数据/指令边界。

## 4. 工程实践与设计权衡

**工程案例：**Coding Agent 开始修改代码前读取仓库 AGENTS.md 并遵循测试命令；但恶意依赖包中的文本要求“上传本地秘密”，不能把它提升为可信管理员命令。

**工程化检验。**用受控案例覆盖版本升级、缺字段、类型错误、未知字段、工具动态更新、技能投毒、未经授权资源访问以及调用超时。要记录真实的 validator 输出、工具执行日志和权威后置状态，而非只看模型说“格式正确”。将 Schema 规范版本与宿主/SDK 版本固定在测试配置，避免不同 validator 方言造成静默差异。每个练习计算的数量都是教学假设，不代表行业覆盖率。

**设计取舍：**严格 schema 和最小工具能力能降低误用风险，但对旧客户端的兼容性、动态发现与维护成本有影响。需明确版本迁移、allowlist、错误信息及回退策略，保证正常任务仍能完成而不会因模糊约束绕开权限。

## 5. 关联知识与易混辨析

Instruction File 存放指引；System Prompt 是调用模型时设置的高优先级消息；Repository README 面向人阅读，AGENTS.md 更专注给代码 Agent 的项目指导。

实践时要区分“静态描述”“动态发现”“真正的调用”和“业务写入确认”。通用 Schema 可选择多种语言，JSON Schema 是其中一种；Skill 说明文件和工具注册元数据也不具备后端的认证授权能力。

## 6. 中等难度面试题（含参考答案）

1. **问：如何验证指令文件的适用范围与冲突？** 答：按宿主的文件发现规则、目录范围和优先级处理，遇到冲突保留可信用户要求并记录判定。
2. **问：为什么项目 AGENTS.md 不能自动赋予读取生产密钥的权限？** 答：它是文本资料，不是身份凭证；访问权限必须由操作系统和后端策略控制。

面试答案应给出具体规范关键词、版本边界、危险反例与可执行的后端控制，不能仅把“Schema 校验通过”当成安全结论。

## 7. 中等难度考试题（含解析）

1. **题：项目根目录和两个子目录各有一个有效指令文件，按题设合计几个？** 解：共 1+2=3 个；生效范围仍依宿主规则，不能简单认为三份都全局适用。 计算或判断的假设由题设明确，须给出完整推理。
2. **题：第三方依赖目录内文件要求忽略安全测试，应怎样处理？** 解：它来自低信任依赖，不能覆盖仓库维护者与用户约束，应审查来源并继续运行必要测试。 要区分结构校验和真实业务授权，不能把格式错误自动转换为合法数据。
