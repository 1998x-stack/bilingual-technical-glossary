# Token Usage（词元用量）

> AI Agents · 专题：工程化、成本与可观测性 · 模型用量、成本预算与缓存治理

## 1. 核心定义

**Token Usage（词元用量）**：模型调用中消耗的输入、输出以及适用时的缓存命中、内部推理等 token 数。它是推理资源和费用的重要计量维度，通常与不同模型、调用类型和具体计费规则相关，不等于字符数或单词数。

**定义边界：**有关 token、价格、配额和缓存的产品语义可能依模型与服务版本变化。本文只定义可以迁移的工程方法；练习数字均假设给定，不能误称任何供应商当前实际价格或基准数据。成本不是唯一目标，正确的任务结果、隐私和安全权限应具有清晰的最低门槛。

## 2. 形象理解

**类比：**像打印店分别记录送来的原稿页数和打印出的纸张数，再计算用量。

**类比的局限：**token 与汉字、字节、英文单词没有固定一比一关系；不同 tokenizer 的结果也可能不同。 实际 Agent 有多种费用、资源状态和分布式后置结果，因此不能从类比推导精确计费或可靠性保证。

## 3. 技术原理与核心内容

记录 input_tokens、output_tokens 和维护者实际返回的 cached/reasoning 子类；不要无条件把子类与总量相加而重复计数。整条 Agent 任务还需聚合各模型调用的 usage，并核对重试是否重复产生收费。token 用量可用来估算成本，但正式金额依模型 SKU、缓存价格、工具费用和当期账单。

**成本模型与治理边界。**一个 Agent 任务会跨多次模型调用、检索、数据库、工具、人工审批和失败重试；应依调用 ID 归集用量，再按相应计价规则计算，不凭空使用特定厂商报价。要区分当前已结算与在途预留，模型回答成功不等于业务完成。缓存值、外部工具结果和旧记忆属于数据来源，不得因低成本或高相似度而突破现有授权与业务实时状态。

**执行闭环。**入口分配 task_id 和共享额度，执行器在每个子任务前检查预估资源需求，随后记录实际 usage 与工具费用；必要时主动拒绝或降级。所有业务写入仍要使用真实权限和幂等键，不能因为缓存或便宜模型的建议就直接行动。

## 4. 工程实践与设计权衡

**工程案例：**RAG Agent 每轮读取 100 个文档块，导致输入 token 激增；可通过更优检索、上下文裁剪和缓存降低用量，但不能随意删除约束和必要证据。

**验证程序。**用固定任务集同时统计输入/输出用量、模型/工具调用数、重试次数、实际成功数、端到端 P95、成本与安全拦截；计算两组候选方案的成功摊销成本并标记计费口径。注入并发、超时、缓存过期、权限变更和费用报告滞后等边界用例，不使用真实客户数据。把质量阈值和安全边界作为必须满足的约束，不应以平均费用下降证明总体方案更优。

**失败与取舍：**便宜模型可能增加修复重试次数；高命中缓存若权限键错误会泄露数据；账单告警并不必然是执行层硬上限。预算控制应对不确定价格做保守预留，对失败任务记录消耗，在权限或关键事实变更时使旧结果失效。

## 5. 关联知识与易混辨析

Token Usage 是数量计量，Token Budget 是任务限制，Cost per Task 是货币费用；同样 token 数在不同模型和时间不必有同样价格。

应把调用级 token、任务级费用、预算策略、缓存有效性和业务完成率作为不同量分别建模。进行选型或成本报告时注明单位、统计期间、纳入的工具费用和失败样本，否则“每次调用价格下降”可能掩盖真正的任务总成本上升。

## 6. 中等难度面试题（含参考答案）

1. **问：为什么不能简单按字符数估算模型账单？** 答：分词器对语言、标点和格式切分不同，且输入/输出/缓存可能计费不同；优先读 API usage。
2. **问：多 Agent 重试链如何防止 token usage 重复计算？** 答：按模型调用/attempt ID 去重账单记录，分别汇总成功和失败调用，避免把内含子类重复加总。

回答应覆盖数据来源、并发资源控制、计量精度以及业务边界，说明如何用受控任务评测验证所提出的优化。

## 7. 中等难度考试题（含解析）

1. **题：某任务输入 9,000 tokens、输出 1,500 tokens，总用量？** 解：9,000+1,500=10,500 tokens；仅是题设简化分类。 明确分母、币种或 token 数、所含费用范围，并验证数值合理性。
2. **题：若 usage 输入总量为 10,000，其中缓存命中 3,000，不能怎样计算？** 解：不能直接算成 13,000 输入 tokens；缓存命中通常是输入总量的子集，须看返回字段语义。 要解释正确原因和常见误用，不能把成本优化与忽略业务授权混同。
