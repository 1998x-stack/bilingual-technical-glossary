# Version Control（版本控制）

> AI Agents · 专题：开发实践与生态术语 · 生产治理、可复现变更与持续交付

## 1. 核心定义

**Version Control（版本控制）**：版本控制是对代码、提示模板、工具 schema、测试和其他可管理文件记录历史变更、分支协作、差异与恢复的技术过程。Git 以提交对象和父子关系保存版本历史，但并不自动复制外部数据库或模型服务状态。

**适用条件：**这里对生产、版本控制和 CI/CD 采用可迁移的工程定义。各组织的审批、发布与支持策略可能不同，特定 GitHub Actions 功能的可用性也取决于计划、仓库配置及权限。不能把 PR 自动测试通过误称已合并 main 或完成领域专家审核。

## 2. 形象理解

**类比：**像带修订号的工程图纸档案，可追踪某次设计修改与其审批记录，而不会直接把现实中造出的机器变回旧版。

**类比的局限：**类比未涵盖真实分布式负载、模型随机性、外部副作用和可重复部署限制。即使打包或测试环节全部通过，也不能推出用户业务结果正确；仍需产品级验收与必要的人工授权。

## 3. 技术原理与核心内容

Git commit 引用 tree 快照及 parent 提交，形成历史图；branch 是可移动引用，merge/rebase 用于协作整合。对 Agent 应将 Prompt 版本、schema、evaluation data、依赖锁与构建步骤纳入可复现流程，并在生产部署记录 SHA、镜像 digest、模型版本和检索数据快照。严禁将明文 secret 提交版本库，泄漏后必须轮换和审计。

**权威边界。**AI Agent 模型回答、工具返回与最终业务后置状态彼此不同。代码审查、测试和配置也不能替代独立的权限校验及真实业务验收。对模型/提示词等非确定性组件，需要以可重复的任务集与条件化质量目标评估；所有外部写入需由可信服务端检查用户、租户与资源授权，并处理未知执行状态和幂等重试。日志不得输出明文秘密。

**关键机制。**先定义变化的提交、配置和构建标识，再记录每一阶段测试的输入、结果及发布门槛；将安全策略、环境权限、成本预算与失败恢复作为流水线的明确条件，而不是依赖提示词承诺。外部业务提交应有独立后置状态与幂等凭据。

## 4. 工程实践与设计权衡

**工程案例：**智能客服 Agent 的 Prompt 从 v12 更新到 v13 后出现错误引用，通过 Git SHA 与发布元数据定位回归，重放固定评测并恢复先前可用构建；已经发出的错误邮件则需独立业务补救。

**工程验证。**在沙箱中演练 schema 迁移、模型响应偏移、工具 429/503、并行工作流、回滚和恢复后的重复写入。记录 commit SHA、artifact digest、Prompt/Model 版本、tool schema 版本、测试结果与 trace ID；检查任务成功率、尾延迟、费用、告警与审计。真实生产灰度应有可执行停止条件和 Runbook。自动化合格不等于独立专家人工技术审核完成。

**设计取舍。**频繁变更可以降低一次发布的差异量，却要求稳定测试和可追溯流水线；过度依赖人工会延迟反馈，完全忽略人工专业复核又可能放行结构上正确而内容错误的文章。应将可自动验证的内容尽量自动化，把领域事实、授权与高风险动作留在明确审核关口。

## 5. 关联知识与易混辨析

Version Control 解决变更历史与协作，CI 验证每次变化，CD 让经验证的构建可发布。Git revert 撤销代码变更，不是数据库或外部动作的事务补偿。

评审时需要严格区分“Git commit 存在”“CI 通过”“产物可部署”“已经正式上线”和“真实用户任务完成”五个状态。每一项分别需要自己的证据来源，不能由后一项自动推导另一项。

## 6. 中等难度面试题（含参考答案）

1. **问：为什么只锁定 Git commit 仍不足以复现 Agent 结果？** 答：模型服务版本、外部工具、检索索引、配置和随机性仍可能变化；应记录依赖和运行证据。
2. **问：若历史提交里意外出现 API 密钥，删掉工作树中的文件是否足够？** 答：不够，Git 历史/克隆可能继续可见；须立即吊销或轮换凭据并按泄漏应急流程处理。

面试答案应兼顾理论与运行时约束，解释哪些部分可以完全自动化，哪些部分需要独立审核或可追溯的权限批准。

## 7. 中等难度考试题（含解析）

1. **题：main 直线有 15 个提交，feature 从顶端分支再加 3 个未合并提交，feature 顶端共有多少祖先和自身提交？** 解：15+3=18 个提交，假设没有额外 merge。 计算结果只在题设条件下成立。
2. **题：执行 git revert 后已支付订单会自动退款吗？** 解：不会；revert 影响代码版本，业务支付需要独立的授权补偿流程。 应区分统计样本、项目实际状态和对外发布保证。
