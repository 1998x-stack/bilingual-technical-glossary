# Large Language Model (LLM)（大语言模型 · LLM）

> AI Agents · 专题：基础概念与角色 · 适用范围：通用智能体系统设计；具体 SDK 与平台版本以对应文档为准

## 1. 核心定义

**Large Language Model (LLM)（大语言模型）**：Large Language Model（LLM）是以大量文本等数据训练、通过 token 序列建模执行语言理解与生成任务的模型；在 Agent 中常作为决策和语言接口，而不负责自动执行真实世界操作。

**适用边界：**LLM 有多种架构和训练方式；Transformer 很常见，但不是“LLM”定义的必要条件。

## 2. 形象理解

像阅读过大量材料的文字预测与归纳引擎，能提出下一步建议。

**类比的局限：**模型输出概率高不等于事实正确，且模型建议并不能直接代替工具验证。

## 3. 技术原理与核心内容

文本经 tokenizer 变为 token ID；模型估计条件概率 P(x_t|x_<t) 并以解码策略生成；上下文窗口限制一次可直接利用的信息量。Agent 运行器把模型提出的工具调用转成受控 API 操作，再反馈结果。

## 4. 工程实践与设计权衡

在合同处理 Agent 中，让 LLM 提取条款和推荐操作，让确定性校验器检查金额、权限与 JSON 格式。用任务完成率评估整个系统，用幻觉率与格式有效率分别评估模型环节。

## 5. 关联知识与易混辨析

LLM 不等于 Agent；Foundation Model 更广，可覆盖语言、视觉及其他模态；LLM 专指语言建模及其扩展任务能力。

## 6. 中等难度面试题（含参考答案）

1. **问：为什么 LLM 不能直接证明已经发出了邮件？** 答：文字表示与外部执行分离；必须有邮件 API 的真实成功返回、消息 ID 与审计记录，并考虑失败/重试。
2. **问：如何缓解 LLM 上下文遗漏造成的决策错误？** 答：限定关键上下文、检索可验证证据、分步结构化输出并提供失败恢复；不能依赖扩大窗口解决权限问题。

## 7. 中等难度考试题（含解析）

1. **题：假设输入 1500 token，输出 600 token，总计多少？另有一轮输入 800、输出 200，合计多少？** 解：第一轮 2100 token，第二轮 1000 token，两轮计 3100 token；若模型计费细分缓存、推理等需按产品规则另算。
2. **题：比较提高 temperature 与加入检索证据对事实可信度的作用。** 解：提高随机性不是事实校验；检索证据可提高可追溯性，但仍须验证证据相关性和输出是否被充分支持。
