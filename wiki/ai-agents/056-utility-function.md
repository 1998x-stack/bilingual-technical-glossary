# Utility Function（效用函数）

> 适用领域：AI Agents · 专题：任务规划与决策 · 基础概念与具体 SDK 权限实现需分开判断

## 1. 核心定义

**Utility Function（效用函数）**：Utility Function（效用函数）为不同结果或行动后果赋予反映偏好与风险取舍的数值，通常用于比较有不确定结果的候选决策。经济与决策理论中可通过期望效用来选择动作，但安全与权限等硬约束应先满足。

**适用边界：**效用的单位和标度依建模约定；奖励可能是过程中的局部学习信号，效用更常表达结果层的偏好，两者并非严格同义。

## 2. 形象理解

像旅行者评价路线不只看时间，还考虑花费、疲劳与风险，并把这些因素按偏好综合。

**类比的局限：**把不同单位简单相加往往会掩盖难以量化的安全约束，不能靠一个高分合法化违规行为。

## 3. 技术原理与核心内容

对行动 a 的可能结果 o，以 `EU(a)=Σ_o P(o|a)·U(o)` 比较期望效用。若使用多项加权目标 `U=w1·quality−w2·cost−w3·risk`，必须明确权重、量纲/归一化和阈值；禁止动作应先过滤，而非只给它一个较低分数。

## 4. 工程实践与设计权衡

**工程案例：**采购 Agent 比较不同供应商价格、到货及时率和退款风险，优先过滤无资质供应商，再以经业务确认的效用函数排序。对概率估计和权重变化做敏感性分析。

**失败模式与验证：**权重不透明、概率估计不校准或优化替代指标容易触发 Goodhart 式失真。设计评估时记录实际业务结果，而不只报告模型打分。

## 5. 关联知识与易混辨析

Utility Function 评价结果偏好；Reward Signal 常作为随时间提供的学习反馈；Task Priority 直接影响调度顺序，未必等于效用最大化。

## 6. 中等难度面试题（含参考答案）

1. **问：为什么不能把“高收益”作为越权下单的理由？** 答：授权是硬约束，必须先过滤非法候选；效用最大化仅在合法动作集合内进行。
2. **问：效用函数的权重变更如何验收？** 答：用相同样本回放/离线评测，比对完成率、成本、风险和公平性，并做权重敏感性分析及审批。

## 7. 中等难度考试题（含解析）

1. **题：方案 A 70% 概率收益 100 元、30% 概率收益 −20 元；方案 B 确定收益 55 元。风险中性线性效用下选哪个？** 解：`EU(A)=0.7×100+0.3×(−20)=64 元`，`EU(B)=55 元`；无其他约束时选 A。
2. **题：一项非法动作被评分为效用 100，合法动作效用 60，应执行非法动作吗？** 解：不能。先执行授权/安全过滤，再在合法集合内选择最大效用。
