# Euclidean Distance（欧氏距离）

> 领域：机器学习 · 专题：支持向量机、核方法与近邻 · 数学、工程实践及邻域检索

## 1. 核心定义

欧氏距离（Euclidean Distance）是多维实数坐标中最常见的 L2 距离：d₂(x,z)=√Σ_j(x_j−z_j)²。它符合对称性、三角不等式和同一性，常用于低维几何、聚类、KNN 与 RBF 核的距离基础。

## 2. 形象理解

像从地图上两点之间拉一根笔直的绳子，求最短直线长度，而不是沿一条条街道转弯。

**类比的局限：**‘直线最短’依赖选定的欧氏坐标与单位；在高维嵌入中距离大小可能受范数、尺度和方向共同影响，不能等同语义相似。

## 3. 技术原理与核心内容

对 x,z∈R^d，d₂(x,z)=||x−z||₂。平方欧氏距离 D²=Σ_j(x_j−z_j)² 在相同查询点下与 d₂ 排序一致，但 **平方距离不满足通常的三角不等式**，不能当成标准 metric。若 x,z 经过相同平移或正交旋转，欧氏距离不变；若某一维特征缩放，则距离会改变。RBF Kernel 正是 exp(−γd₂²)，而 scikit-learn 的欧氏 KNN 可直接采用 p=2 的 Minkowski 距离。

## 4. 工程实践与设计权衡

电池寿命预测在 5 个异单位传感器数据上检索近邻，应使用训练尺度统一特征并记录异常值处理；若改为归一化嵌入，欧氏距离与 cosine 排序在单位范数向量上存在可推导关系。

## 5. 关联知识与易混辨析

Euclidean 是 L2 距离；Manhattan 是 L1 路径长度；Squared Euclidean 便于优化却不是严格 metric；Cosine Similarity 对向量共同正比例缩放不敏感，几何意义不同。

## 6. 中等难度面试题（含参考答案）

1. **问：为何 RBF 的指数使用平方欧氏距离不意味着平方欧氏距离本身是 metric？** 答：核函数只需以距离平方构造 PSD 核，平方 Euclidean 可能违反三角不等式；核与 metric 的数学要求不同。

2. **问：单位范数向量中欧氏距离和余弦相似度有什么关系？** 答：若 ||x||=||z||=1，则 ||x−z||²=2−2cos(x,z)，所以两者的排序等价（无数值并列歧义时）。

## 7. 中等难度考试题（含解析）

1. **题：x=(1,2)、z=(4,6)，欧氏距离是多少？** 解：sqrt((4−1)²+(6−2)²)=sqrt(9+16)=5。

2. **题：d₂((0,0),(1,1)) 和平方欧氏距离分别多少？** 解：分别为 sqrt(2)≈1.4142 和 2，单位不同，平方距离不能直接与原距离值混用。
