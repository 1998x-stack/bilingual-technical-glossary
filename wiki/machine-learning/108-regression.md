# Regression（回归）

> 领域：机器学习 · 专题：回归、分类与线性模型 · 定义、条件、推导与工程适用边界

## 1. 核心定义

回归（Regression）是学习从输入 X 到连续数值响应 Y 的映射，目标可能是条件均值、条件中位数、条件分位数或完整分布参数。它不等于必须使用线性模型；评价损失应匹配业务代价与目标测量尺度。

## 2. 形象理解

像根据面积、地段、楼龄预测房价；输出是价格数值，而不是“便宜/昂贵”两个类别。

**类比的局限：**不同业务目标对应不同估计量：平方损失偏向均值，绝对损失偏向中位数，不能不加说明地把预测值叫“最可能真实值”。

## 3. 技术原理与核心内容

典型形式 ŷ=f_θ(x)。平方损失 min E[(Y−a)²|X=x] 的最优 a=E[Y|X=x]（二阶矩存在）；绝对损失的最优预测是条件中位数；pinball 损失对应条件分位数。常用指标 MSE、RMSE、MAE、R²，但它们的单位和对极端值敏感性不同。验证要按用户/时间切分，且目标对数变换后的反变换需注意 Jensen 偏差。

## 4. 工程实践与设计权衡

电力需求预测需区分预测点值与不确定性区间；极端峰值可采用非对称成本或分位数回归。报告各季节误差与基线模型比较，不用训练集 R² 作为唯一指标。

## 5. 关联知识与易混辨析

Regression 是任务类别；Linear Regression 是线性参数化的一种模型；Classification 输出离散标签；Poisson Regression 面向具有特定条件均值/方差假设的计数任务。

## 6. 中等难度面试题（含参考答案）

1. **问：为什么有时 MAE 比 MSE 更适合异常值较多的回归任务？** 答：平方误差对大残差施加强烈惩罚，容易被少数极端值主导；MAE 更稳健但优化与目标统计量不同，应结合损失代价选择。

2. **问：模型在训练集 R² 很高就可以部署吗？** 答：不能。R² 可被数据泄漏、重复客户和分布偏移影响；应做独立测试、按群体验证并报告绝对误差和部署成本。

## 7. 中等难度考试题（含解析）

1. **题：真实 y=[2,4]、预测 ŷ=[3,6]，MAE 与 MSE 各是多少？** 解：绝对误差 1、2，MAE=(1+2)/2=1.5；平方误差 1、4，MSE=(1+4)/2=2.5。

2. **题：预测目标在对数尺度输出 2，直接取 exp 得什么？它一定是原尺度的条件均值吗？** 解：exp(2)≈7.389，不一定为原尺度条件均值；一般 E[exp(Z)]≠exp(E[Z])，需要误差分布/偏差校正。
