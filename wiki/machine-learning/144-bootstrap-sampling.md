# Bootstrap Sampling（自助采样）

> 领域：机器学习 · 专题：树模型与集成学习 · 理论、数学与工业决策

## 1. 核心定义

自助采样（Bootstrap Sampling）是从给定原始样本中有放回地独立抽取指定次数的重采样方法，常用于估计统计量的不确定性以及构造 Bagging/随机森林的训练子集。被抽到多次的记录仍代表同一个原始观察，不能当作新采集独立数据。

## 2. 形象理解

像把 100 张写有编号的纸条放进盒中，每抽一张又放回；抽 100 次时有人会被反复抽到，有些原始编号一次都没出现。

**类比的局限：**若原始样本存在时间依赖或用户内相关，普通逐行 bootstrap 会破坏统计依赖，置信区间与泛化推断可能失效。

## 3. 技术原理与核心内容

标准 n-out-of-n bootstrap 从 n 条样本中以 1/n 概率有放回抽 n 次。某固定原样本从未出现的概率为 (1−1/n)^n→e^(−1)≈0.368，因此一次抽样中被覆盖的**不同原记录比例**期望约为 63.2%（n 大时）。重复生成 B 份 Bootstrap 数据，统计量 θ̂_b 的经验分布可估计标准误或置信区间；但百分位/BCa 等区间方法也依赖条件，模型选取要避免用测试集过度调整。

## 4. 工程实践与设计权衡

机器故障预测按设备而非传感器行数做 grouped bootstrap，才有机会捕捉设备间不确定性；在分组不均衡且有时间序列时应使用合适的 cluster/block bootstrap，而不是把所有行随机重排。

## 5. 关联知识与易混辨析

Bootstrap Sampling 是重采样技术；Bagging 是使用多个重采样训练集聚合模型；OOB 是某次抽样未选中的观察；SMOTE 是少数类特征插值，不等于 Bootstrap。

## 6. 中等难度面试题（含参考答案）

1. **问：为什么 n=100 的 Bootstrap 样本长度虽为 100，但通常只含约 63 个不同原样本？** 答：因为有放回导致重复抽取，单个原样本被抽中的概率约 1−e^(−1)=0.632；不同原样本数是随机变量而非固定 63。

2. **问：何时必须考虑分组或时间块 Bootstrap？** 答：当同一个实体或相邻时间点的观测相关时，逐行独立抽样会错误估计变异程度，应按合理的独立统计单元重抽。

## 7. 中等难度考试题（含解析）

1. **题：n=2，抽 2 次，某固定原记录未被选到的概率是多少？** 解：(1−1/2)^2=(1/2)^2=1/4=0.25；不能用大 n 近似 0.368 代替此精确值。

2. **题：n=100、Bootstrap 100 次，单条记录未被选概率近似多少？** 解：(99/100)^100≈0.366，接近 e^(−1)≈0.368。
