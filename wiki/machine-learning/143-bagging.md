# Bagging (Bootstrap Aggregating)（自助聚合）

> 领域：机器学习 · 专题：树模型与集成学习 · 理论、数学与工业决策

## 1. 核心定义

自助聚合（Bagging，Bootstrap Aggregating）通过在训练集上反复有放回采样构造多个训练子集、训练一组基学习器，并对预测求平均或投票，以降低不稳定学习器的预测方差。它主要通过并行多样性聚合降低波动，不是按轮纠错的 Boosting。

## 2. 形象理解

像让多位分析员分别从同一案例库随机抽取样本制定判断规则，最后综合他们的意见，减少单个分析员因抽到特殊案例做出的偶然决定。

**类比的局限：**分析员训练集仍共享大量样本，多模型误差可能相关；如果基学习器高度偏差，仅增加 Bagging 数量也不一定解决欠拟合。

## 3. 技术原理与核心内容

对 n 条训练样本，每棵基学习器从中有放回抽 n 次（或按设定 max_samples 抽不同数量），得到 S_b，训练 h_b。回归 F(x)=(1/B)Σ_b h_b(x)；分类可按概率平均或类别投票，具体行为依实现。Boostrap 的未抽取样本可以进行 OOB 估计，但需要每条样本覆盖足够多棵树、样本独立且采样假设适用；BaggingClassifier 还能选择无放回抽样、特征子采样，严格说这些设置是一般化的 Bagging 接口。

## 4. 工程实践与设计权衡

图像元数据欺诈检测可用不稳定的决策树作基学习器，使用 Bagging 降低方差并对比单树在客户分组测试上的结果；训练集含重复客户时 OOB 也未必代表新客户泛化。

## 5. 关联知识与易混辨析

Bagging 并行训练多样化模型并平均；Bootstrap Sampling 是有放回选样的具体数据操作；Random Forest 在树 Bagging 中加随机特征选择；Boosting 则逐阶段针对当前模型不足训练。

## 6. 中等难度面试题（含参考答案）

1. **问：为什么 Bagging 更适合高方差的决策树而非显著高偏差的线性模型？** 答：平均能减少独立或低相关的波动，但如果所有基学习器都系统性遗漏非线性信号，平均不会自动消除共同偏差。

2. **问：为什么 Bagging 的各树预测高度相关时收益会下降？** 答：均值方差包含树间协方差，相关性高时不能按 1/B 缩小整体方差；需要采样和特征随机性创造差异。

## 7. 中等难度考试题（含解析）

1. **题：三棵回归树预测值 [2,5,8]，Bagging 简单平均预测？** 解：(2+5+8)/3=5，前提是三棵树等权。

2. **题：单个样本没有出现在 n 次有放回 Bootstrap 中的概率表达式？** 解：(1−1/n)^n，当 n 很大时约为 e^(−1)=0.368。
