# RBF Kernel / Gaussian Kernel（径向基核／高斯核）

> 领域：机器学习 · 专题：支持向量机、核方法与近邻 · 数学、工程实践及邻域检索

## 1. 核心定义

径向基核／高斯核（RBF / Gaussian Kernel）按两个样本的欧氏距离平方呈指数衰减：K(x,z)=exp(−γ||x−z||₂²)，γ>0。它是常见的正半定平稳核，可使 SVM 获得原始输入空间的非线性决策边界；核值在相同点为 1，在距离增加时趋近 0。

## 2. 形象理解

像每个训练点周围有一团半径可调的影响云，越靠近这个点影响越强，离得越远贡献越小。

**类比的局限：**云的‘宽窄’依特征尺度与 γ 决定；对非代表性数据或距离集中严重的高维空间，RBF 并不自动有效。

## 3. 技术原理与核心内容

RBF 写作 exp(−γ||x−z||²)=exp(−||x−z||²/(2σ²))，因此 γ=1/(2σ²)。γ 越大核衰减越快、局部性更强，可能导致复杂边界；γ 越小则核接近常数、容量受限。RBF SVM 同时调 `C` 和 `gamma`；scikit-learn `gamma='scale'` 通常按 1/(n_features×X.var()) 定义，随输入缩放变化。完整核矩阵通常需要 O(n²) 空间，百万样本任务可能要线性近似或随机 Fourier 特征。

## 4. 工程实践与设计权衡

工业传感器异常分类，先在每折对传感器单位标准化，再以按设备分组的时间验证选择 C、gamma。避免把同一设备相邻读数同时放在训练与测试中，否则局部核容易记住近重复输入。

## 5. 关联知识与易混辨析

RBF 是 Kernel Function 的具体成员；Polynomial Kernel 使用内积的幂，RBF 使用欧氏平方距离；Euclidean Distance 是原始空间距离，Cosine Similarity 更强调方向；同 γ 的数值不能跨未标准化任务比较。

## 6. 中等难度面试题（含参考答案）

1. **问：为什么增大 gamma 可能导致 RBF SVM 更容易拟合训练细节？** 答：核随距离更快衰减，各点的有效局部影响范围变窄，决策边界可变得更曲折；还需结合 C 与样本覆盖判断。

2. **问：为什么先标准化再用 RBF 很重要？** 答：欧氏距离会被量纲巨大的特征主导，核值分布也随尺度变化；预处理必须在训练折内拟合以避免数据泄漏。

## 7. 中等难度考试题（含解析）

1. **题：γ=0.5、||x−z||²=2，RBF 核值是多少？** 解：K=exp(−0.5×2)=e^(−1)≈0.3679。

2. **题：σ=2 时对应的 gamma 是多少？** 解：γ=1/(2σ²)=1/(2×4)=1/8=0.125。
