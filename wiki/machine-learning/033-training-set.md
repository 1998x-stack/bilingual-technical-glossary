# Training Set（训练集）

> 适用领域：机器学习 · 专题：数据、样本与数据集划分 · 统计单位、采集与数据协议

## 1. 核心定义

训练集是参与拟合模型参数、特征变换统计量或学习算法状态的数据子集。为得到可信的泛化评估，它应与最终测试集按独立实体和预测时间要求隔离。

## 2. 形象理解

像学生用于练习和纠错的作业；练习题可以反复看，但不能把正式考题提前当训练题。

**类比局限：**即使测试集中没有相同行，重复实体、时间后验信息或全局特征统计仍会导致泄漏。

## 3. 技术原理与核心内容

经典切分 D=D_train∪D_val∪D_test；参数在 D_train 上拟合，超参可在 D_val 上选择，最终测试只用于估计。交叉验证中每一折各自拟合缩放器、插补器、特征选择器和模型。训练集的选择机制影响部署目标的可迁移性。

## 4. 工程实践与设计权衡

医疗风险模型训练集仅使用截止预测时点可见的病历，按患者 ID 排除跨集重复；标签延迟会影响近时段能否纳入训练。对类别不平衡，可在训练折内部重采样而非先全量重采样。

## 5. 关联知识与易混辨析

Training Set 用于学习；Validation Set 用于开发选择；Test Set 保留最终评价。模型选择过程中反复访问测试集会把它变成另一套验证集。

## 6. 中等难度面试题（含参考答案）

1. **问：为什么在分折之前用全部数据做标准化不合适？** 答：因为验证/测试的均值和方差已反馈给训练管道，产生轻微或严重的评估偏乐观；把变换器包含进每折 Pipeline。

2. **问：为什么大量历史训练样本仍可能不适合新用户？** 答：训练目标人群、产品版本或采样机制和新用户不同。需覆盖性检查、分群验证与部署监控。

## 7. 中等难度考试题（含解析）

1. **题：总样本 1,200 条，按 70%/15%/15% 划分，训练集多少？** 解：1200×0.70=840 条；验证和测试各 180 条，前提是可按行独立划分。

2. **题：训练集含 600 条，正类 30 条，正类占比多少？** 解：30/600=5%。若做类别重采样只应作用于训练折，并保留真实部署先验供评价。
