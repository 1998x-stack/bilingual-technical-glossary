# AdaBoost（自适应提升）

> 领域：机器学习 · 专题：树模型与集成学习 · 理论、数学与工业决策

## 1. 核心定义

自适应提升（AdaBoost）是经典 Boosting 算法，通过逐轮训练弱分类器，并提升前一轮错分样本的相对权重、降低正确样本的权重，再用带权投票组合多个基学习器。其推导与指数损失及弱学习条件相关，但遇噪声标签时可能持续放大难例影响。

## 2. 形象理解

像每轮考试后教师将更多辅导资源分配给上轮做错题的学生，下轮继续训练，然后按每轮教师可靠性汇总最终意见。

**类比的局限：**被重复关注的‘难例’可能是标签错误或未覆盖子群；增加权重不一定代表它们真的值得模型学习。

## 3. 技术原理与核心内容

经典二分类 AdaBoost 取标签 y∈{−1,+1}、基分类器 h_m，带权错误率 ε_m=Σ_i w_i·1[h_m(x_i)≠y_i]/Σ_i w_i。若 0<ε_m<0.5，可设 α_m=0.5 ln[(1−ε_m)/ε_m]，然后 w_i←w_i exp(−α_m y_i h_m(x_i)) 并归一化。最终 sign(Σ_m α_m h_m(x))。多类 SAMME 的加权公式不同，不可直接照搬二分类 α；scikit-learn 的 `AdaBoostClassifier` 版本也有演进，应以实际接口为准。

## 4. 工程实践与设计权衡

信用欺诈表格中可将深度为 1 的决策桩作为弱学习器，观察错分样本权重的逐轮集中度。记录标签质量、人工审核成本与停止轮次，并在未重新采样的独立时间测试集评价召回。

## 5. 关联知识与易混辨析

AdaBoost 用指数损失/权重重排，是 Boosting 特例；Gradient Boosting 采用任意合适可微损失的负梯度思想；Random Forest 不是逐轮按错误更新权重。

## 6. 中等难度面试题（含参考答案）

1. **问：为什么经典二分类 AdaBoost 要求弱分类器错误率低于 0.5 才获得正的 α？** 答：由 α=0.5ln((1−ε)/ε) 可知，ε<0.5 才 α>0；边界情况应终止或调整弱学习器。

2. **问：为什么新版本 AdaBoostClassifier 不应直接用旧 `algorithm` 参数示例当作通用代码？** 答：库 API 会演进，多分类策略和参数支持可能改变；应核对当前版本实际文档及训练目标。

## 7. 中等难度考试题（含解析）

1. **题：二分类加权错误率 ε=0.2，经典 AdaBoost 的 α 是多少？** 解：α=0.5ln(0.8/0.2)=0.5ln4≈0.6931。

2. **题：弱分类器 ε=0.5，经典公式中的 α 是多少？** 解：α=0.5ln1=0，本轮不提供正向加权贡献；实际算法可能停止训练。
