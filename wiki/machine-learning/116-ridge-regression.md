# Ridge Regression（岭回归）

> 领域：机器学习 · 专题：回归、分类与线性模型 · 监督目标、优化公式和工程条件

## 1. 核心定义

岭回归（Ridge Regression）通过在线性回归平方残差和上添加 L2 系数平方惩罚降低参数方差和共线性敏感性。它常用连续收缩而非把大量系数恰好置零，强正则可能引入明显欠拟合偏差。

## 2. 形象理解

像在每个回归参数上装一根弹簧，某个参数想被拉得过大时会产生额外代价，让一组相关特征分摊解释。

**类比的局限：**弹簧不能修复错误标签、未来信息泄漏或严重分布偏移；L2 的尺度还依赖特征单位。

## 3. 技术原理与核心内容

scikit-learn Ridge 常见目标 min_w ||y−Xw||₂²+α||w||₂²；若截距单独处理且 α>0，正规方程解 ŵ=(XᵀX+αI)^(−1)Xᵀy。Ridge 的 α 不能与按均方误差乘 (1/2n) 的 Lasso 目标直接等量比较。对特征统一尺度后，惩罚强度更有可比性；按组或时间 CV 选择 α，并保留最终测试。

## 4. 工程实践与设计权衡

电价预测中室外温度、风速和历史耗能存在多重共线性，用 Ridge 提升回归系数稳定性，比较 α 随验证误差的曲线并监测时间外推误差。

## 5. 关联知识与易混辨析

Ridge Regression 是具体平方损失加 L2 的回归估计器；L2 Regularization 是更广义惩罚机制；Lasso 使用 L1 并可产生稀疏解；Elastic Net 组合两者。

## 6. 中等难度面试题（含参考答案）

1. **问：为何 α>0 有助于解决满秩不足时的数值奇异？** 答：XᵀX 是半正定，加入 αI 使其正定可逆，但必须另行处理未正则化的截距；更稳并不等于无偏。

2. **问：为什么 Ridge 之前通常需要标准化数值特征？** 答：同样的系数范数惩罚在不同量纲列上效果不同，尺度过大/过小的列会受到不均衡约束；标准化参数必须只用训练折估计。

## 7. 中等难度考试题（含解析）

1. **题：已中心化一维数据，XᵀX=8、Xᵀy=12、α=2，Ridge 系数？** 解：w=12/(8+2)=1.2。

2. **题：简单 Ridge 目标 (w−4)²+αw²，α=1，最优 w？** 解：导数 2(w−4)+2w=0，得 w=2；本题无截距且以平方残差和为准。
