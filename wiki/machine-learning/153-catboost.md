# CatBoost（类别提升）

> 领域：机器学习 · 专题：树模型与集成学习 · 一手研究与实现、真实工程约束、可复算例题

## 1. 核心定义

CatBoost（Categorical Boosting，类别提升）是面向含类别特征表格数据的梯度提升决策树库。其关键研究贡献包括基于排列的有序类别目标统计（ordered target statistics）与 ordered boosting，旨在减少利用当前样本自身标签计算编码或梯度估计造成的 prediction shift。

## 2. 形象理解

像编写每个类别的历史口碑时，只允许使用该订单之前已经看过的其他订单评分，而不能偷偷把本订单答案也写进自己的参考资料。

**类比的局限：**排列顺序是算法控制训练期目标泄漏的机制，不等同数据本身的真实时间顺序；线上仍必须遵守实际特征可用时点与用户分组边界。

## 3. 技术原理与核心内容

对某类别 c 的训练样本 i，可以使用一个随机排列中位置排在 i 之前、同类别样本的标签统计，并引入先验平滑，典型形式 CTR_i=(sum_previous_target+a·prior)/(count_previous+a)。该计算减少每条训练样本对自身类别编码的直接目标泄漏。Ordered Boosting 使用与排列相配合的历史模型/梯度估计降低预测偏移；实际 `boosting_type` 可能为 Ordered 或 Plain，默认依 CPU/GPU、数据规模及任务设置而不同，不能声称 CatBoost 总是 Ordered。模型可以使用对称树等优化以提高推理效率。

## 4. 工程实践与设计权衡

推荐与用户流失预测具有上万高基数商户或内容类别时，CatBoost 可避免手工全量目标均值编码的常见泄漏，但仍需时间/用户分割数据、标记类别缺失和新增值，记录 `cat_features` 映射与推理延迟。

## 5. 关联知识与易混辨析

CatBoost 与 LightGBM/XGBoost 同属梯度提升树框架；核心差别在类别处理、排列与训练机制。Ordered Categorical Statistics 不等于直接把全体训练标签均值填给每条记录，仍不能替代严格的数据切分。

## 6. 中等难度面试题（含参考答案）

1. **问：为什么对某类别用包含本样本 y 的全量类别均值编码有泄漏问题？** 答：当前目标进入了自己的输入特征，训练期编码与推理未见样本的条件分布不同，易产生乐观偏差；ordered 统计只使用排列之前样本。

2. **问：为什么不能断言所有 CatBoost 模型都采用 Ordered Boosting？** 答：官方参数支持 Ordered 与 Plain，且默认由处理器类型、样本数和任务决定；需记录实际训练参数及文档版本。

## 7. 中等难度考试题（含解析）

1. **题：某类别先前有 3 个目标值 1、0、1，a=2、prior=0.5，ordered CTR 为多少？** 解：(2+2×0.5)/(3+2)=3/5=0.6；这是题设的平滑编码，不代表 CatBoost 所有 CTR 类型。

2. **题：若某类别此前没有样本，按同一平滑公式 a=2、prior=0.4，CTR 是多少？** 解：(0+2×0.4)/(0+2)=0.4，返回先验；a 必须为正以防 0/0。
