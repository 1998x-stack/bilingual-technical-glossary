# Class Imbalance（类别不平衡）

> 适用领域：机器学习 · 专题：数据、样本与数据集划分 · 可信验证、偏差与防泄漏

## 1. 核心定义

类别不平衡指分类数据中某些类别的频率显著低于其他类别；它会让总体准确率掩盖少数类识别质量，并影响训练损失、阈值和概率校准。类别比例差异未必说明抽样错误。

## 2. 形象理解

像安检中绝大多数人没有危险物品；全回答‘安全’就很准，但无法完成关键任务。

**类比局限：**盲目把所有类别调到 50/50 可能破坏真实概率先验，并带来额外误报和部署成本。

## 3. 技术原理与核心内容

对正类先验 π=P(Y=1)，只预测负类的准确率为 1−π，但正类召回为 0。评价应结合 TP/FP/FN/TN，precision=TP/(TP+FP)、recall=TP/(TP+FN)、PR 曲线和代价矩阵。处理方式包括 class weights、阈值调整、训练折内部重采样和分层划分，部署评测必须恢复真实先验。

## 4. 工程实践与设计权衡

欺诈检出中真实发生率 0.5%，应优先衡量特定人工审单量下的召回及成本；若训练时过采样正类，评分输出未必对应真实后验概率，必要时重新校准。

## 5. 关联知识与易混辨析

Class Imbalance 是观测类别比例特征；Sampling Bias 指样本代表性偏差；Stratification 保持某种比例；重采样修改训练数据频率不等于改善泛化。

## 6. 中等难度面试题（含参考答案）

1. **问：为什么 99.5% 准确率可能毫无价值？** 答：全预测负类在正类仅 0.5% 的数据上也有 99.5% 准确率但漏检 100%；需按业务损失选择 recall、precision 与 PR-AUC。

2. **问：什么时候不应该简单使用 SMOTE？** 答：对极高维稀疏类别、时序相关、混合类型变量或按组泄漏风险大的数据，合成插值可能无效或违法约束；应只在训练折使用并验证。

## 7. 中等难度考试题（含解析）

1. **题：测试集 10,000 条，正类 50，模型全判负，准确率和正类召回多少？** 解：准确率 9950/10000=99.5%，正类召回 0/50=0%。

2. **题：TP=30，FP=20，FN=10，计算 precision、recall。** 解：Precision=30/(30+20)=60%，Recall=30/(30+10)=75%。是否适合业务取决于误报与漏报代价。
