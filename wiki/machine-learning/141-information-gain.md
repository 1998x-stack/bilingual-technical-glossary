# Information Gain（信息增益）

> 领域：机器学习 · 专题：树模型与集成学习 · 树结构、训练准则与统计边界

## 1. 核心定义

信息增益（Information Gain）是在决策树训练中用熵衡量候选分裂前后类别不确定性减少的量。它依赖节点类别分布和候选划分后的加权条件熵，而不等于信息论中所有情形下的互信息数值估计过程。

## 2. 形象理解

像老师按题目答案把学生分成不同组，分组后每组对掌握知识的判断更确定，前后不确定性降低就是信息增益。

**类比的局限：**信息增益偏好某些能将训练样本切成很多小纯组的分裂；有限样本高增益不意味着因果信息或低测试错误。

## 3. 技术原理与核心内容

熵 H(Y)=−Σ_k p_k log₂ p_k；对分裂变量 A，IG(Y;A)=H(Y)−Σ_a P(A=a)H(Y|A=a)。常见 CART 二叉树通过特征阈值产生左右孩子，并计算加权熵减少。若使用自然对数，增益单位为 nats 而不是 bits，排序在固定底数下不变。信息增益与 Gini 减少是两种不同的分类准则；ID3、C4.5 的多分支类别规则及增益率需和 CART 二叉处理分开说明。

## 4. 工程实践与设计权衡

客户支持意图树若用工单 ID 能把训练数据分成很多纯叶，信息增益可能很高却没有可迁移规律；应限制高基数标识符、检查时间可用性和外部验证。

## 5. 关联知识与易混辨析

Information Gain 具体基于 Entropy Reduction；Gini Decrease 使用不同不纯度公式；Mutual Information 在分布层面可与此表达联系，但估计假设及高基数偏差需交代。

## 6. 中等难度面试题（含参考答案）

1. **问：为什么 ID3 式信息增益容易偏向取值数量多的属性？** 答：高基数属性可以把训练记录切得很细，使训练子节点趋于纯净；C4.5 用增益率等尝试控制这种偏好，但仍需外部验证。

2. **问：使用自然对数计算的熵增益与 log₂ 熵增益排序是否不同？** 答：若对所有候选同样改底，仅乘一个正常数，排序不变；数值单位从 bits 变 nats。

## 7. 中等难度考试题（含解析）

1. **题：一个均衡二分类父节点熵为 1 bit，分裂后两个子节点都纯净，信息增益是多少？** 解：加权子节点熵为 0，因此 IG=1−0=1 bit。

2. **题：父熵为 1 bit，左右孩子比例 1/4、3/4，孩子熵分别 0 与 0.8 bit，信息增益？** 解：加权子熵=0.25×0+0.75×0.8=0.6 bit，所以 IG=1−0.6=0.4 bit。
