# VC Dimension（VC 维）

> 领域：机器学习 · 专题：统计学习与泛化理论 · 推导、理论前提与工程设计

## 1. 核心定义

VC 维（Vapnik–Chervonenkis Dimension）是二分类假设类 H 能够打散的最大样本点数：存在一组 d 个点，使该类能实现这组点的全部 2^d 种二值标签分配。它研究的是函数类的组合表达能力，而不是训练集包含多少样本或神经网络的 embedding 维数。

## 2. 形象理解

像一个分类工具箱：给你 d 颗位置固定的钉子，无论将它们随意涂红或蓝，工具箱都能找出一条规则全部分对，才叫打散。

**类比的局限：**存在某一组点可打散，与任意一组点都可打散不同；VC 维大不代表在任意特定真实分布上一定有更高错误率。

## 3. 技术原理与核心内容

形式化定义 VC(H)=sup{d: ∃x₁,…,x_d，使 {(h(x₁),…,h(x_d)):h∈H}={0,1}^d}。实轴上固定方向阈值 h_t(x)=1[x≥t] 的 VC 维为 1；实轴区间指示函数 1[a≤x≤b] 的 VC 维为 2；R^d 中仿射线性半空间的 VC 维在一般情形下为 d+1。经典均匀收敛界通常在有界 0–1 损失、iid、固定 H 等前提下涉及 VC(H)、n 与 δ，常出现 √((d log(n/d)+log(1/δ))/n) 类型项；常数与形式需以原定理为准。

## 4. 工程实践与设计权衡

小样本医学分类器选线性决策边界前，应认识到输入维度影响线性半空间容量，但真实风险还取决于边界分布、样本独立单位和特征选择是否泄漏。不要把“VC 维 20”直接解释为“只需 20 条训练记录”。

## 5. 关联知识与易混辨析

VC Dimension 是容量的一种组合度量；Model Complexity 可用多种指标；PAC Learnability 在标准二分类 iid 条件下与有限 VC 维具有深刻联系，但还涉及是否为无分布限制、可计算等定义。

## 6. 中等难度面试题（含参考答案）

1. **问：为什么直线上的定向阈值不能打散两个有序点？** 答：设 x₁<x₂，h_t=1[x≥t] 无法产生 (1,0) 的标签模式；但一个点能实现 0 与 1，所以 VC 维为 1。

2. **问：为什么 VC 维不是保证样本量等于 d 就能泛化？** 答：泛化界还包含误差容忍度 ε、置信度 δ、具体学习规则和分布假设。d 只是函数类复杂度参数之一。

## 7. 中等难度考试题（含解析）

1. **题：对实轴上的区间分类器 h_[a,b](x)=1[a≤x≤b]，两个有序点能被全部四种二值标记打散吗？** 解：能：空区间得 (0,0)，只覆盖左点得 (1,0)，只覆盖右点得 (0,1)，覆盖两点得 (1,1)。

2. **题：三个有序点 x₁<x₂<x₃，区间正类能否实现 (1,0,1)？这说明什么？** 解：不能：同时覆盖两端必覆盖中点，因此无法打散三个有序点，区间类的 VC 维为 2。
