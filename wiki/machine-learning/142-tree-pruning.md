# Tree Pruning（决策树剪枝）

> 领域：机器学习 · 专题：树模型与集成学习 · 理论、数学与工业决策

## 1. 核心定义

决策树剪枝（Tree Pruning）是通过删除部分分支、以叶节点替代复杂子树来控制预测树的复杂度，减少对训练噪声的适应。它既可以在训练过程中提前停止生长（预剪枝），也可以先长树再用代价复杂度准则选择子树（后剪枝）。

## 2. 形象理解

像修剪枝叶繁杂的盆景：剪掉只服务于个别偶然生长方向的枝杈，让结构更稳健且更容易理解。

**类比的局限：**过度剪枝会丢掉真实的少数群体规则，导致欠拟合；‘剪得最小’不等于预测最优。

## 3. 技术原理与核心内容

预剪枝常用 max_depth、min_samples_leaf、min_samples_split、min_impurity_decrease；后剪枝采用代价复杂度 J_α(T)=R(T)+α|Leaves(T)|，R(T) 在 scikit-learn 中按加权叶不纯度计算。`cost_complexity_pruning_path` 返回不同有效 ccp_alpha 与对应不纯度；应在训练 CV 内选择 α，再在整个训练集重拟合并于独立测试集评价。α=0 不代表树必定增长无限，仍可能因纯度/样本量早停。

## 4. 工程实践与设计权衡

信用评分树对真实时间验证集比较不同 `ccp_alpha`，在漏报/误报成本与叶支持约束间找平衡；对低频客户群同时报告叶被剪掉后的影响，保留审计模型与训练数据版本。

## 5. 关联知识与易混辨析

Tree Pruning 是结构压缩与正则化；Tree Depth 是结构上限；Bagging 通过平均多棵随机树降低方差，两者可组合但机制不同。

## 6. 中等难度面试题（含参考答案）

1. **问：为何不能用最终测试集选择最佳剪枝参数？** 答：测试集反复用于 α 选择后变成开发数据，最终分数偏乐观；应使用训练折的交叉验证选 α。

2. **问：成本复杂度剪枝中 α 变大通常有什么影响？** 答：更重惩罚终端叶数量，倾向选择更简单的子树，可能降低方差但也增加偏差；不是所有有限数据上测试误差单调下降。

## 7. 中等难度考试题（含解析）

1. **题：某树 R(T)=0.20、叶数 8，α=0.02，代价复杂度分数多少？** 解：J=0.20+0.02×8=0.36，题设 R 已按约定归一化。

2. **题：树 A：R=0.2、L=8；树 B：R=0.25、L=3；α=0.02 时哪棵目标更小？** 解：A 为 0.36，B 为 0.25+0.06=0.31，按本代理目标选 B。
