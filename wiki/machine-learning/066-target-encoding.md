# Target Encoding（目标编码）

> 领域：机器学习 · 专题：数据预处理与特征工程 · 数理解释和工程实用边界

## 1. 核心定义

目标编码以类别对应的目标统计量（如历史正类率、条件均值）替换原始类别，适用于高基数分类特征。若当前训练行标签参与自身编码，尤其唯一 ID，会导致严重目标泄漏，因此必须采用交叉拟合或严格历史统计。

## 2. 形象理解

以商家的历史好评率代替商家名称，让模型知道其既往表现。

**类比的局限：**一个商家只有 1 条好评就显示 100%，这种估计极不稳定，且可能直接暴露当前订单标签。

## 3. 技术原理与核心内容

类别 c 的统计均值 μ_c=Σ_{i:c_i=c}y_i/n_c，可用平滑 μ̃_c=(n_cμ_c+αμ_global)/(n_c+α) 稳定小类别。在训练时采用 OOF 编码，保证每行的 y 不进入对应编码；验证/测试用仅在合法训练数据上估计的映射。scikit-learn TargetEncoder.fit_transform 与 fit().transform() 不相等，因为前者含 cross-fitting。

## 4. 工程实践与设计权衡

广告点击率建模使用截至预测时点的历史广告点击率和分层平滑，监控新广告、低曝光商家及标签延迟；不能对当前点击结果编码。

## 5. 关联知识与易混辨析

TargetEncoder 用到 y，与不使用标签的 OneHot/Ordinal 不同。LabelEncoder 是编码目标类的索引，不能用于生成监督类别统计。

## 6. 中等难度面试题（含参考答案）

1. **问：为什么不能先对训练集整体求每个 ID 的目标均值，再送给同一训练行？** 答：当前行标签参与自己的编码，唯一类别甚至直接露出 y。必须用 OOF 或过去时点统计。

2. **问：为何要做平滑和时间截断？** 答：低频组均值方差高，平滑向全局先验收缩；时点截断防止使用尚未发生的结果或延迟反馈。

## 7. 中等难度考试题（含解析）

1. **题：类别 A 两条标签 [1,0]，全局均值 0.2、α=3，平滑统计值？** 解：(2×0.5+3×0.2)/(2+3)=1.6/5=0.32；但不应把含自身 y 的值直接给该训练行。

2. **题：新商家一条标签 1，全局均值 0.1、α=4，平滑后多少？** 解：(1×1+4×0.1)/5=1.4/5=0.28，降低偶然极端值。
