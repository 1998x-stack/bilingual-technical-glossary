# Random Forest（随机森林）

> 领域：机器学习 · 专题：树模型与集成学习 · 理论、数学与工业决策

## 1. 核心定义

随机森林（Random Forest）是由多棵随机化决策树组成的并行集成模型，典型做法是对每棵树使用 Bootstrap 训练子样本，并在每次节点分裂时随机选择候选特征子集，以减少不同树预测之间的相关性。分类经集成概率平均等规则产生结果，回归通常平均预测。

## 2. 形象理解

像多支调查队从数据中各自随机选择采访对象，也只允许询问部分问题，最后汇总结果；让每队不因同一噪声线索做出相同误判。

**类比的局限：**树之间仍有强相关时平均收益有限；随机森林擅长表格预测，但它不能天然推断因果关系或保证概率已校准。

## 3. 技术原理与核心内容

训练 B 棵树 h_b。回归 F(x)=(1/B)Σ_b h_b(x)；scikit-learn RandomForestClassifier 通常平均各树的类别概率后选最高类，并非必然简单硬投票。Bootstrap 各树抽样、`max_features` 的节点级随机特征子集、`min_samples_leaf` 和 `max_depth` 决定随机性/容量。OOB_score 只在 bootstrap=True 时可用，且 OOB 是内部估计而非保证来自不同用户/时间的外部测试。

## 4. 工程实践与设计权衡

客户信用预测应在按人及日期划分的测试集比较 RF 与 Logistic/GBDT，审查不平衡少数类指标、类别编码、模型内存和线上特征缺失。特征重要性易受基数与相关性影响，可配合外部置换重要性审查。

## 5. 关联知识与易混辨析

Random Forest 结合 Bagging 与每节点特征子采样；Extra Trees 在候选阈值上引入更强随机性且 sklearn 默认不 Bootstrap；GBDT 则序列化拟合加性残差。

## 6. 中等难度面试题（含参考答案）

1. **问：为什么随机森林通常能降低单棵深树的方差？** 答：Bootstrap 和节点候选特征随机化使树产生不同预测，聚合抵消部分偶然波动；树相关性越大效果越弱。

2. **问：RandomForestClassifier 是否总是直接对各树的类别标签多数投票？** 答：在 scikit-learn 中分类通常平均各树类别概率后取最大值；与硬标签投票可能在概率不一致时得到不同结果。

## 7. 中等难度考试题（含解析）

1. **题：三棵回归树预测 [8,10,12]，平均输出多少？** 解：(8+10+12)/3=10。

2. **题：随机森林 `n_estimators=100`、每棵树训练使用 60% 原数据的有放回抽样，训练共抽取多少条记录（按原 n=1000）？** 解：每棵抽 600 次，共 100×600=60000 次抽样，含重复，不代表 60000 个独立样本。
