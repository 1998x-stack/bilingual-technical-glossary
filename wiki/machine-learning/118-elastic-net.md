# Elastic Net（弹性网络）

> 领域：机器学习 · 专题：回归、分类与线性模型 · 模型与数学定义、业务应用和边界条件

## 1. 核心定义

弹性网络（Elastic Net）是一种线性回归估计器，在平方误差目标同时使用 L1 和 L2 正则。它允许系数稀疏同时相对平滑地处理相关变量组，常用于高维、多重共线性数据；选用 α 和 l1_ratio 需要明确目标的数值约定。

## 2. 形象理解

像精简团队但给留下的任务适当分担：一部分惩罚减少岗位数，一部分惩罚防止某个人负担过重。

**类比的局限：**相关变量不一定会一起被保留，调参不当仍会欠拟合；高维稀疏输出也不自动可解释成因果关系。

## 3. 技术原理与核心内容

scikit-learn 的目标为 J(w)=1/(2n)||y−Xw||²+α·r||w||₁+0.5α(1−r)||w||₂²，其中 r=l1_ratio。r=1 时变成 Lasso 惩罚形式；r→0 时 L1 减弱，但某些求解器在极小 r 时可能不可靠。若把惩罚写成 a||w||₁+(b/2)||w||₂²，则 a=αr、b=α(1−r)。标准化应在训练折内部拟合，CV 搜索 α 与 r，并保留独立测试。

## 4. 工程实践与设计权衡

针对高度相关的用户活跃时长、会话数和滚动点击次数，可用 ElasticNetCV 在用户分组或时序分折中选择参数，与 Ridge/Lasso 比较模型稳定性、预测成本和业务解释。

## 5. 关联知识与易混辨析

Elastic Net 是具体线性回归模型；Elastic Net Regularization 是通用正则组合；Ridge 惩罚 L2，Lasso 惩罚 L1。多输出版本及组稀疏还涉及不同目标定义。

## 6. 中等难度面试题（含参考答案）

1. **问：Elastic Net 相比 Lasso 的主要优势在哪里？** 答：L2 项改善强相关特征条件下的数值稳定性，减少只能保留某一个变量的偏好；但具体是否成组选入需靠数据验证。

2. **问：为何跨不同框架不能直接复制相同的 α 和 r？** 答：损失归一化、是否包含 1/2、截距处理和正则定义不同，必须先写出两个 API 的优化目标再映射。

## 7. 中等难度考试题（含解析）

1. **题：α=0.6、r=0.25，分别对应 a、b（L2 按 b/2 写）是多少？** 解：a=0.6×0.25=0.15，b=0.6×0.75=0.45。

2. **题：若 r=1、α=0.2，正则项是什么？** 解：正则项变为 0.2||w||₁，L2 项系数为 0；在该目标定义下对应 Lasso。
