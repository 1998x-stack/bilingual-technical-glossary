# Machine Learning (ML)（机器学习 · ML）

> 适用领域：机器学习 · 专题：基础概念与学习范式 · 核心概念、理论与工程边界

## 1. 核心定义

机器学习是让参数化或非参数化模型从样本中估计可复用规律，以对未观察输入作预测、生成或决策。它不要求每条规则都由程序员显式写出；是否有效以目标分布下的泛化表现而非训练集记忆为准。

## 2. 形象理解

像学徒从大量已解案例中学会判断新案例，而非背下每一页答案。

**类比局限：**数据会选择性呈现世界；记住答案或学到伪相关都可能在新场景失效。

## 3. 技术原理与核心内容

典型监督学习取数据 D={(x_i,y_i)}、模型 f_θ 和损失 ℓ，最小化经验风险 L(θ)=1/n Σℓ(f_θ(x_i),y_i)+λΩ(θ)。预处理必须仅在训练折拟合；验证集选择超参，独立测试集只用于最终估计。归纳偏置、容量与样本机制共同决定泛化。无监督、强化学习等范式不必有逐样本人工标签。

## 4. 工程实践与设计权衡

例如欺诈检测用历史交易训练，但需按时间切分、检查标签延迟与概念漂移。先定义业务成本，再给出离线指标、置信区间、上线监控和回滚条件；训练准确率提升并不保证误报成本下降。

## 5. 关联知识与易混辨析

ML 是 AI 的一种重要实现途径，不等同整个 AI；深度学习只是使用多层表征的 ML 子类。训练集好并不意味着泛化好。

## 6. 中等难度面试题（含参考答案）

1. **问：为什么训练错误率接近 0 仍可能不能上线？** 答：模型可能过拟合、标签泄漏或训练与生产分布不同。先检查分组/时间切分、误差分层和真实成本；独立测试与灰度监测比单一训练指标更可信。

2. **问：如何区分标签泄漏与合法的强预测特征？** 答：核对预测发生的时间点和特征可用性。如果字段仅在结果发生后生成，即使相关性极高也是泄漏；可通过特征时点审计与回放检测。

## 7. 中等难度考试题（含解析）

1. **题：给定真实标签 [1,0,1,0] 与预测 [1,1,1,0]，计算准确率并指出潜在不足。** 解：3/4=75%。若正负样本比例严重不平衡，应补充召回率、精确率、PR-AUC 等，且本例不能评估跨时间泛化。

2. **题：2000 条独立样本按 70%/15%/15% 划分，数量多少？若同一用户重复出现，怎么办？** 解：训练 1400、验证 300、测试 300。若同一用户关联样本，必须先按用户分组再划分以避免跨集泄漏，具体数量可能因此略偏离比例。
