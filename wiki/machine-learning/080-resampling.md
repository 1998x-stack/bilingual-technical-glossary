# Resampling（重采样）

> 领域：机器学习 · 专题：数据预处理与特征工程 · 定义、原理、数学与真实工程边界

## 1. 核心定义

重采样是按照一定规则重新抽取、复制、剔除或加权样本的操作，可用于统计不确定性估计（Bootstrap）、处理类别不平衡（过/欠采样）或构造训练子集。不同目的对应不同统计解释，不能把重采样当作新采集的独立数据。

## 2. 形象理解

像从已有扑克牌里重新抽牌：可以反复抽到同一张牌来研究结果波动，但这不会产生新的原始牌。

**类比的局限：**自助采样有放回，类平衡采样可能改变训练类别先验；未经分组的重采样会传播重复实体泄漏。

## 3. 技术原理与核心内容

Bootstrap 从原始 n 条观测中有放回抽 n 次，某一原样本未被选中的概率为 (1−1/n)^n≈e^(−1)=0.368（n 大时）。对分类训练可做 RandomOverSampler 或 RandomUnderSampler，需将操作限制在训练折；测试集应保留目标分布。相依数据应按用户、时间块等统计独立单位设计 bootstrap。

## 4. 工程实践与设计权衡

欺诈检测可在每个训练折重采样正类，评估仍在自然先验的时间测试集上计算 Precision、PR-AUC 和成本。分析置信区间时按用户而非交易行重采样，避免高频账户被当成大量独立观察。

## 5. 关联知识与易混辨析

Resampling 是上位概念；SMOTE 是插值型少数类过采样；Data Augmentation 是语义变换；Stratified Sampling 在设计阶段按层比例选样，不一定改变总体类别比例。

## 6. 中等难度面试题（含参考答案）

1. **问：为什么过采样训练出的分类器概率不必等于真实概率？** 答：训练先验被改变，判别阈值与后验校准受影响；必须在真实目标先验数据上校准与验证。

2. **问：为什么时间序列不能随意随机 bootstrap 每条记录？** 答：会打乱自相关与趋势结构，使置信区间假设失效；可使用经验证的块重采样或时序专用方法。

## 7. 中等难度考试题（含解析）

1. **题：有放回地从 n=100 的样本抽 100 次，单个指定样本一次未被抽中的概率表达式？** 解：(99/100)^100≈0.366，接近 e^(−1)≈0.368。

2. **题：一训练折中有 900 个负例和 100 个正例，简单复制正类至与负类相等需要新增多少行？** 解：目标正类 900；须额外复制 900−100=800 行。该训练折变为 1800 行，测试分布不能随之改变。
