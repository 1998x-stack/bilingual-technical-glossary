# Polynomial Features（多项式特征）

> 领域：机器学习 · 专题：数据预处理与特征工程 · 数理原理、适用条件与生产风险

## 1. 核心定义

多项式特征通过原始变量的幂与交叉乘积扩展输入，使线性参数模型可在扩展空间表达非线性关系。它改变模型容量而非自动改进泛化，尤其高阶展开会增加维度、数值不稳定与过拟合风险。

## 2. 形象理解

除了只看温度和湿度，还加入温度平方和温度乘湿度，捕捉弯曲趋势与联合作用。

**类比的局限：**展开程度一高，特征数可能组合爆炸；数值越大，高次幂越易导致条件数恶化。

## 3. 技术原理与核心内容

当输入 x=(x₁,…,x_d)，degree=2 且 include_bias=False 时可生成所有 x_i、x_i² 和 x_i x_j（i<j）；输出数目为 C(d+2,2)−1。若仅交互项可设 interaction_only=True。PolynomialFeatures 只构造特征，不做非线性参数训练；随后线性回归在扩展的 φ(x) 上为线性，但对原始 x 是多项式预测。

## 4. 工程实践与设计权衡

工业控制中的耗能曲线可能存在温度二次关系，用二阶展开加岭回归构造解释性基线；需要把缩放、展开和正则化放在同一 Pipeline 中并限制无意义交互。

## 5. 关联知识与易混辨析

PolynomialFeatures 按固定规则展开，不等于核技巧（核法隐式操作特征内积）；Interaction Feature 可以仅保留部分交叉项；增加维数不一定比树模型有效。

## 6. 中等难度面试题（含参考答案）

1. **问：为什么多项式回归仍被称为线性模型？** 答：它对展开后的特征系数是线性的，如 y=a+b x+c x²；它对 x 非线性，但优化对参数仍可使用线性回归结构。

2. **问：二阶展开什么时候容易过拟合？** 答：当样本少、原维度大或变量强相关时，项数快速增长，需要交叉验证限制阶数并用 L1/L2 正则。

## 7. 中等难度考试题（含解析）

1. **题：原始 3 个输入变量，只取最高 2 阶、包括一次项与平方交互、不加偏置，输出维数？** 解：C(3+2,2)−1=C(5,2)−1=10−1=9。包括 3 一次项、3 平方和 3 两两交互。

2. **题：f(x)=2+3x+4x²，当 x=2 输出多少？** 解：2+3×2+4×(2²)=2+6+16=24。
