# Machine Learning · 第一批学习路径（001–025）

> 内部编辑资料，不在公开站点暴露批次导航。源词序来自 [机器学习术语表](../../glossaries/machine-learning.md)。

## 建议学习路径

1. **领域边界 001–003：** AI 包含 ML，但二者不等价；统计学习解释经验风险、总体风险与泛化假设。
2. **学习范式 004–010：** 按目标信号（有/无/少量标签、自监督、奖励）和更新时机（在线/离线）建立二维概念图。注意监督标签与代理目标、在线更新与在线推断的区别。
3. **资源与迁移 011–017：** 主动学习购买信息，迁移学习复用知识，多任务联合学习，元学习优化快速适配，few/zero-shot 描述评价协议，领域自适应处理分布差异。
4. **统计推断与建模 018–024：** 归纳式泛化 vs 特定目标集合上的直推；判别模型 vs 生成模型；预测建模全链路、表征学习、基础模型的可复用性。
5. **数据协议 025：** 数据集、记录、独立统计单元、时间切分和来源校验是上述所有技术可信评价的前提。

## 综合案例：工业缺陷识别

- 先界定目标：新增设备型号的缺陷识别，并注明漏检代价与检修负担；记录设备/批次/时间、图像及标签来源。
- 对比基线：固定监督训练、预训练骨干迁移、半监督伪标签；必要时从未标注图像中做主动学习采样。
- 测评设计：以设备组和未来时间段划分，禁止同一设备序列跨集合泄漏；few-shot 需明确 N-way K-shot 与目标类别隔离。
- 上线检验：按设备、光照、缺陷类别报告置信区间与漏检率；设置人工复核、漂移监控和回滚机制，避免用训练集准确率替代真实风险。
