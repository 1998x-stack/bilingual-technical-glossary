# Root Node（根节点）

> 领域：机器学习 · 专题：树模型与集成学习 · 树结构、训练准则与统计边界

## 1. 核心定义

根节点（Root Node）是树结构中没有父节点的唯一入口，在传统训练决策树中代表全部训练样本或其权重总和。一次预测从根开始沿条件路径走向叶；根的划分可能对整树预测影响极大。

## 2. 形象理解

像医院分诊台的第一道询问：所有新患者先经过同一个入口问题，再分往不同科室。

**类比的局限：**根节点规则可能只是训练数据上的最佳局部划分，不能凭它判断某一特征具备真正的因果优先级。

## 3. 技术原理与核心内容

常见实现中根的 node id 为 0、depth=0。训练时计算根节点原始不纯度 H(root)，比较候选特征阈值分裂后的加权不纯度，选贪心收益最大的合法划分；若无满足 min_samples_split 或 min_impurity_decrease 的候选，整棵树可只有根节点且根同时是叶。按权重训练时，根的 weighted_n_node_samples 与原始样本数不同。

## 4. 工程实践与设计权衡

在线上资格审批模型中，应固定根阈值和缺失路径在模型序列化版本；如果根节点使用年龄等敏感字段，需要进行合规审查。定期监控根左右子群规模，突变可能提示输入分布漂移。

## 5. 关联知识与易混辨析

Root Node 是结构角色，Internal Node 是有孩子的非叶节点，根若继续分裂也属于内部节点；Leaf Node 无孩子。Root Split 的重要性不能直接等同整体因果解释。

## 6. 中等难度面试题（含参考答案）

1. **问：根节点一定同时是内部节点吗？** 答：不一定。如果数据纯净、样本太少或停止条件禁止分裂，根就是叶；只有至少发生一次分裂才是内部节点。

2. **问：根节点为何对数据漂移敏感？** 答：根阈值决定大量样本的主分支去向；输入分布跨阈值的比例变化可能显著影响预测与下游叶分布。

## 7. 中等难度考试题（含解析）

1. **题：根节点 100 个样本里 60 个正类、40 个负类，根的 Gini 不纯度多少？** 解：1−0.6²−0.4²=1−0.36−0.16=0.48。

2. **题：根节点分为 30 和 70 个样本，两分支样本占比各多少？** 解：30% 和 70%；若样本权重不等，训练准则使用的比例可能不同。
