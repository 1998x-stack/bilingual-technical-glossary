# Internal Node（内部节点）

> 领域：机器学习 · 专题：树模型与集成学习 · 树结构、训练准则与统计边界

## 1. 核心定义

内部节点（Internal Node）是决策树中含有至少一个子节点、负责执行分裂判断的节点。经典二叉 CART 内部节点有左右两个孩子，其规则将到达该节点的样本分配到不同子树；内部节点不直接作为最终预测终点。

## 2. 形象理解

像客服流程中间的条件问答框，依据回答继续向左或向右询问；只有走到底的结果框才给最终处理。

**类比的局限：**内部节点并不必然具有较高业务重要性，它可能只覆盖极少数训练样本；树的位置也不代表因果优先级。

## 3. 技术原理与核心内容

节点 t 可表示区域 R_t 与局部样本集合 S_t，判定 x_j≤s 时走左孩子，否则走右孩子（缺失值规则依实现）。其局部收益 ΔH_t=H(t)−(n_L/n_t)H(L)−(n_R/n_t)H(R)。训练时一般只在满足 min_samples_split、min_samples_leaf、max_depth 等约束下生成内部节点。很多树模型存储 feature[t]、threshold[t]、children_left[t]、children_right[t]；叶的孩子索引被标记为无效值。

## 4. 工程实践与设计权衡

生产风险树可通过每个内部节点的样本覆盖量和分裂后的目标率检查极小子群，防止少数客户群因为高方差分裂而出现异常高拒绝率。检查新输入缺失值分支是否与训练一致。

## 5. 关联知识与易混辨析

Internal Node 负责分裂，Leaf Node 负责输出；Root Node 在可分裂时也是内部节点；Split Criterion 是训练时评价分裂的目标，不是上线额外计算的实时规则。

## 6. 中等难度面试题（含参考答案）

1. **问：节点只覆盖 5 个样本，是否还能继续分裂？** 答：取决于 min_samples_split、min_samples_leaf、最大深度和纯度等；满足数目并不保证有合法可改善准则的分裂。

2. **问：根节点和内部节点是否互斥？** 答：不是。根是唯一入口，若有子节点就是内部节点；只有没有子节点时它同时为叶。

## 7. 中等难度考试题（含解析）

1. **题：内部节点包含 12 条样本，左孩子 5 条、右孩子 7 条，不纯度分别为 0.2 与 0.5，加权子不纯度？** 解：(5/12)×0.2+(7/12)×0.5=0.0833+0.2917=0.375。

2. **题：某内部节点到达深度 2，继续分裂一步形成子节点，孩子深度是多少？** 解：孩子深度为 3；按根深度 0 计，深度是从根经过的边数。
