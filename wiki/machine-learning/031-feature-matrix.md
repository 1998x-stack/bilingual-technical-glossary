# Feature Matrix (X)（特征矩阵）

> 适用领域：机器学习 · 专题：数据、样本与数据集划分 · 统计单位、采集与数据协议

## 1. 核心定义

特征矩阵 X 将 n 个样本的 d 个模型输入特征组织为矩阵；传统表格监督学习常按行放样本、按列放特征。X 可以是稠密数组或稀疏矩阵，列序与类型是模型契约的一部分。

## 2. 形象理解

像表格中每个学生一行、每个考试科目一列；行列颠倒就把学生和学科弄反了。

**类比局限：**图像、时序和图结构的数据可能是多维张量或图对象，不能强行认为所有输入都是二维矩阵。

## 3. 技术原理与核心内容

通常 X∈R^{n×d}，线性预测 ŷ=Xw+b（广播截距），w∈R^d，输出 ŷ∈R^n；分类变量需编码，缺失可能需特殊处理。训练/预测应使用相同的特征顺序、预处理参数及版本。

## 4. 工程实践与设计权衡

线上批量评分服务应检查输入形状、dtype、列名和列顺序，防止两个同为数值列交换而导致静默错误。高维稀疏文本特征优先使用稀疏矩阵以节省内存。

## 5. 关联知识与易混辨析

Feature Matrix X 保存输入；Target Vector y 保存监督目标。X 与 y 行必须对齐；数据框索引一致不代表连接合并后天然正确。

## 6. 中等难度面试题（含参考答案）

1. **问：为何 X.shape 相同，预测结果仍可能完全错？** 答：列顺序、编码词表、单位和缺失语义可能变化；需要 schema 校验和端到端特征契约，而不只是检查维度。

2. **问：为什么文本词袋矩阵通常保持稀疏？** 答：绝大多数词在单个文档中未出现，显式存储全部零值浪费内存；可用 CSR/CSC，需按后续算子选择格式。

## 7. 中等难度考试题（含解析）

1. **题：200 个样本、12 个数值特征，X 与 w 的形状分别是什么？** 解：X=(200,12)，w=(12,)，Xw=(200,)。矩阵乘法内维 12 必须匹配。

2. **题：X 有 1,000 行、10,000 列，float64 稠密存储不计开销占多少字节？** 解：1000×10000×8=80,000,000 字节，约 80 MB（十进制）；稀疏存储另有索引开销。
