# Sparse Feature（稀疏特征）

> 领域：机器学习 · 专题：数据预处理与特征工程 · 定义、原理、数学与真实工程边界

## 1. 核心定义

稀疏特征是绝大多数维度为零或未激活的输入表示，典型例子是独热类别、词袋计数和高基数哈希桶。其核心工程价值在于只存储和计算非零项，但稀疏性本身不保证模型准确或统计上稀有。

## 2. 形象理解

一张有一百万个格子的记录纸，大多数格子空着；只登记那些填了内容的格子，比复印整张纸省空间。

**类比的局限：**“未激活=0”与“缺失值未知”语义不同；某些库里稀疏零只是未显式存储的数值零，不是数据缺失。

## 3. 技术原理与核心内容

稀疏矩阵可用 CSR（行压缩）或 CSC（列压缩），典型 CSR 存储 data、indices 和 indptr。若 X∈R^(n×d)，只含 nnz 个非零值，存储量近似 O(nnz+n)，而稠密存储 O(nd)。中心化 StandardScaler、某些矩阵操作和类别编码可把零变为非零，使表示无意中稠密化。模型 API 对 sparse 输入及格式的支持需要逐一核对。

## 4. 工程实践与设计权衡

百万维广告特征在样本级只有几十个非零桶时可用 CSR 与支持稀疏运算的线性模型；为在线服务定期监控每行 nnz、稀疏密度和模型内存占用，防止误调用 .toarray() 导致 OOM。

## 5. 关联知识与易混辨析

Sparse Feature 指输入特征/表示稀疏；Sparse Model 指参数稀疏，两者不同；Missing Value 表示未观测而不等同零值；Dense Feature 的非零密度通常更高。

## 6. 中等难度面试题（含参考答案）

1. **问：为什么稀疏数据未必能被任何算法高效处理？** 答：算法可能内部转换为 dense、需要高开销随机列访问，或依赖不兼容的矩阵格式；要看具体实现的复杂度与 API。

2. **问：词袋中的零与原始传感器缺失有什么区别？** 答：词袋零按词表表示‘此文档该词未出现’，是已定义计数；传感器缺失是未得到数值，不能自动按零处理。

## 7. 中等难度考试题（含解析）

1. **题：有 1000 行、10000 列的矩阵，共 20000 个非零值，密度是多少？** 解：20,000/(1000×10000)=0.002=0.2%，这是数值存储密度。

2. **题：一个 500 维 one-hot 向量仅有 1 个 1，稀疏率（零占比）？** 解：(500−1)/500=499/500=99.8%；是否适合稀疏存储还需考虑索引开销。
