# Support Vector Machine (SVM)（支持向量机 · SVM）

> 领域：机器学习 · 专题：支持向量机、核方法与近邻 · 数学形式、优化条件与独立评估

## 1. 核心定义

支持向量机（Support Vector Machine，SVM）是一类通过最大化分类间隔、并可使用核函数处理非线性关系的监督学习器。二分类 SVM 以带符号决策函数的正负判别类别；软间隔通过对间隔违规支付代价应对不可完全线性分离的样本。SVM 也有回归与异常检测等变体，但并非只要用核函数就属于同一个任务。

## 2. 形象理解

像在两群训练样本之间放一条尽可能宽的安全走廊，走廊两侧离边界最近的一批样本决定走廊究竟能放多宽。

**类比的局限：**走廊宽度是所选特征空间中的几何量，特征量纲和核映射会改变它；安全边界宽不直接意味着在线上风险概率已校准。

## 3. 技术原理与核心内容

二分类 y_i∈{−1,+1} 的软间隔原始问题：min_{w,b,ξ} 0.5||w||₂²+CΣ_i ξ_i，约束 y_i(wᵀφ(x_i)+b)≥1−ξ_i、ξ_i≥0。可等价表示为 0.5||w||²+CΣ_i max(0,1−y_if(x_i))。通过对偶，预测 f(x)=Σ_{i∈SV}α_i y_i K(x_i,x)+b，α_i 通常受 0≤α_i≤C 约束。线性与 RBF 核的计算、支持向量数和推理延迟差异大；scikit-learn 核 SVC 大样本训练代价至少可能二次增长。

## 4. 工程实践与设计权衡

设备缺陷分类先按设备/时间封存测试集，在训练 Pipeline 内标准化并对 C、gamma 做对数网格搜索。线性高维稀疏数据可比较 LinearSVC，若要风险概率必须额外独立校准，不能直接把 decision_function 当概率。

## 5. 关联知识与易混辨析

SVM 是分类模型家族；Support Vector 是影响解的训练样本；Margin 是间隔量；SVR 对连续目标采用 ε 不敏感损失；Logistic Regression 优化对数损失而非 Hinge，虽同样可用线性决策面。

## 6. 中等难度面试题（含参考答案）

1. **问：为何 SVM 对输入特征尺度敏感？** 答：间隔和 RBF 距离依赖特征坐标的度量；若一个单位大很多，优化会偏向某维。标准化应只在每训练折拟合。

2. **问：SVC 的 score=2 可以直接解释为 88% 的概率吗？** 答：不能。得分是符号和间隔相关的实数，需使用独立的 Platt/Isotonic 校准并测试可靠性。

## 7. 中等难度考试题（含解析）

1. **题：w=(3,4)，硬间隔标准化约束中的几何单侧间隔 1/||w|| 为多少？** 解：||w||=5，所以单侧几何间隔=0.2，两个规范间隔超平面之间宽度为 2/5=0.4。

2. **题：给定二分类 y=−1、得分 f=−0.5，单样本 Hinge Loss 是多少？** 解：max(0,1−yf)=max(0,1−0.5)=0.5。
