# Validation Set（验证集）

> 适用领域：机器学习 · 专题：数据、样本与数据集划分 · 验证协议与模型选择

## 1. 核心定义

验证集用于模型开发过程中的超参数选择、阈值设定、早停和方案比较，不应充当最终无偏测试结果。对验证集重复试验本身会产生选择偏差。

## 2. 形象理解

像模拟考试：它能决定该复习哪块知识，但做了上百套同一模拟题后不能拿原分数证明正式考试水平。

**类比局限：**验证集并非天然独立；与训练集共享用户、时间段或预处理统计时，评估会偏乐观。

## 3. 技术原理与核心内容

将数据分为 D_train 与 D_val；先对 D_train 拟合参数 θ_λ，再用 D_val 的损失选择 λ*，形式为 argmin_λ L_val(θ_λ)。早停每轮查看验证损失，也属于利用验证集。超参频繁搜索时需要嵌套交叉验证或保留最终测试集。

## 4. 工程实践与设计权衡

搜索排序模型调 100 组正则化与阈值，必须记录尝试次数、候选空间及验证协议；当用户簇相关时用分组验证，在时间场景则用后续时间窗评估。

## 5. 关联知识与易混辨析

Validation Set 用于训练流程外的开发选择，Training Set 用于拟合，Test Set 用于最后一次性能声明；CV 的每一折验证集也承担模型选择角色。

## 6. 中等难度面试题（含参考答案）

1. **问：为什么验证集选出来的最优模型分数偏高？** 答：在许多候选中取最优本身利用了验证集上的随机波动，若以同一验证集报告最终泛化分数会高估真实表现。

2. **问：没有单独验证集时如何调参？** 答：可在训练部分内部采用交叉验证并保留独立测试集；组相关和时间相关任务要选适配的 CV 划分策略。

## 7. 中等难度考试题（含解析）

1. **题：三个候选模型验证 MAE 分别为 2.1、1.7、2.0，按 MAE 选哪个？** 解：第二个模型，MAE=1.7 最小；最终报告应在未参与选择的测试集上重新评估。

2. **题：训练 900、验证 300、测试 300。若误把验证 300 合进训练后仍在这 300 条上报告开发分数，会有什么偏差？** 解：此 300 已用于拟合，评估不再独立；测试集 300 仍应封存，开发指标需重新定义。
