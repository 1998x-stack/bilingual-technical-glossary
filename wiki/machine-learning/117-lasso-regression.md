# Lasso Regression（套索回归）

> 领域：机器学习 · 专题：回归、分类与线性模型 · 模型与数学定义、业务应用和边界条件

## 1. 核心定义

套索回归（Lasso Regression）在线性回归平方损失上施加 L1 系数绝对值惩罚，促使部分系数精确为零，常用于稀疏预测和特征选择。它与泛化理论中的 L1 Regularization 相关，但这里特指回归估计器及其目标函数。

## 2. 形象理解

像招聘时给每个岗位的人力成本定价，模型可能干脆关闭某些作用有限的岗位，只留下少数重要变量。

**类比的局限：**高度相关的候选变量可能被随机挑选其中一个；非零系数并不证明因果影响，稀疏也不代表没有遗漏变量。

## 3. 技术原理与核心内容

scikit-learn Lasso 的目标为 (1/(2n))||y−Xw||²+α||w||₁。对于标量目标 0.5(w−a)²+λ|w|，最优解是 sign(a)max(|a|−λ,0)，即 soft-threshold；在多列相关设计中通常用坐标下降、近端优化等求解。不同特征尺度会影响惩罚，因此通常在训练折内标准化，再以交叉验证选 α。若 n<d，稀疏选择可改善可解释性，但不能自动保证系数一致性。

## 4. 工程实践与设计权衡

贷款违约前的收入、负债、交易频率有多组高度相关变量，可以比较 Lasso 与 Ridge/ElasticNet 的时序外部误差和特征稳定性，避免把单次随机选择误报为确定机制。

## 5. 关联知识与易混辨析

Lasso 是 L1 惩罚的线性平方损失回归；L1 Regularization 可以用于其他模型；Ridge 使用 L2 通常不稀疏；Elastic Net 兼顾 L1 和 L2 的正则。

## 6. 中等难度面试题（含参考答案）

1. **问：Lasso 选择出来的变量为什么不一定稳定？** 答：相关特征常能互相替代，样本扰动或 α 小幅变化即可使稀疏解改变；宜做稳定性评估并明确业务允许字段。

2. **问：为什么 α=0 和极小 α 不一定都建议使用 Lasso 求解器？** 答：无惩罚情形更适合用专门最小二乘实现；坐标下降对极弱惩罚可能收敛慢且数值表现依条件数而异。

## 7. 中等难度考试题（含解析）

1. **题：标量目标 0.5(w−4)²+1|w|，最优 w？** 解：软阈值 sign(4)max(4−1,0)=3。

2. **题：a=−0.5、λ=1 的软阈值最优 w？** 解：|a|≤λ，因此 w=0；这展示 L1 对小系数的精确稀疏作用。
