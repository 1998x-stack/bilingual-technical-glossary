易混淆概念速辨

Frequently confused concepts · 16 pairs

英文概念对关键区别
Program vs Process程序是静态代码与数据；进程是正在执行、拥有运行时状态和资源的实例。
Process vs Thread进程通常提供资源和地址空间边界；线程是进程内的执行流。
Concurrency vs Parallelism并发强调时间范围内交错推进；并行强调同一时刻真正同时执行。
Trap vs Interrupt陷入通常指同步进入特权处理路径；中断通常指异步外部事件。
Exception vs Page Fault异常是处理器事件的大类；缺页异常是与页面映射相关的具体异常。
Race Condition vs Data Race竞态条件是更宽泛的顺序依赖问题；数据竞争特指无适当同步的冲突内存访问。
Deadlock vs Livelock死锁是互相等待而不动；活锁是仍在活动但没有实质进展。
Mutex vs Semaphore互斥锁侧重排他访问和持有者语义；信号量侧重计数与资源协调。
Virtual Memory vs Swap虚拟内存是地址空间与映射机制；交换空间只是页面管理可能使用的存储。
Page vs Page Frame页是虚拟地址空间的单元；页框是物理内存中对应大小的区域。
Hard Link vs Symbolic Link硬链接引用同一文件对象；符号链接保存另一条路径。
Blocking vs Nonblocking I/O阻塞调用可能等待条件满足；非阻塞调用在暂不能完成时及时返回。
Buffer vs Cache缓冲主要协调数据流和速率；缓存主要复用已有结果以减少重复访问。
Kernel vs Hypervisor内核管理操作系统进程和资源；虚拟机监控器管理虚拟硬件与客户机。
Container vs Virtual Machine容器通常共享宿主内核；虚拟机通常有独立客户机内核。
Authentication vs Authorization认证确认是谁；授权确认能做什么。
