## 附录 B · 常见易混术语 / Terminology Pitfalls

| 中文 | 英文表达 | 注意 |
| --- | --- | --- |
| 中线 / 中位数 | median of a triangle / median (statistics) | 同为 median，但一个是三角形线段，一个是排序后数据的中间值。 |
| 梯形 | trapezoid (US) / trapezium (UK) | 英美用词与“至少/恰有一组对边平行”的定义可能不同。 |
| 一次函数 | linear function / affine function | 中学 y = kx + b 常称 linear；严格线性代数中“linear”通常需过原点。 |
| 直线 / 线段 | line / line segment | line 两端无限延伸；segment 有两个端点。 |
| 垂直平分线 / 角平分线 | perpendicular bisector / angle bisector | 一个平分线段且垂直，一个平分角度。 |
| 圆 / 圆盘 | circle / disk (disc) | circle 常指圆周；disk 指包含内部的圆形区域。 |
| 频数 / 频率 | frequency / relative frequency | 前者是次数，后者是占比；有些教材需看上下文。 |
| 因式分解 / 化简 | factor / simplify | factor 是写成乘积；simplify 是一般化简，不等同。 |
| 全等 / 相似 | congruent / similar | 全等保持形状和大小；相似保持形状但不一定大小。 |
| 命题 / 定理 | statement / theorem | 命题可真可假；定理是已证明的真命题。 |
| 补角 / 余角 | supplementary / complementary | 分别相加为 180° 与 90°，不可混用。 |
