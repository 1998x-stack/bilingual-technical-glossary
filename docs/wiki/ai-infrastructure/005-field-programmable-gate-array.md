# Field-Programmable Gate Array（现场可编程门阵列 · FPGA）

> AI Infra Wiki · Batch 01 · 术语 005/142 · 来源：[AI Infra 原始术语](../../data/ai-infrastructure.tsv)

## 1. 核心定义

**Field-Programmable Gate Array**（**现场可编程门阵列**，FPGA）：可在部署后重新配置逻辑功能的芯片。

**精确定义补充：** FPGA 具有可配置逻辑、查找表、触发器、片上 RAM 和 DSP 单元；配置比特流确定其硬件连接。关键在于区分**硬件所提供的能力**、**程序的执行模型**和**应用实际获得的性能**。

## 2. 形象理解

FPGA 像“可重新布线的电路积木”，开发者可以把所需运算与数据流直接组织成硬件流水线。

## 3. 技术原理与核心内容

FPGA 具有可配置逻辑、查找表、触发器、片上 RAM 和 DSP 单元；配置比特流确定其硬件连接。与 CPU 执行指令不同，多个流水线阶段可在同一时钟周期并行处理不同数据。

## 4. 工程实践与设计权衡

适于低时延数据流、定制协议、固定尺寸推理等，但开发周期、时序收敛、资源利用和量化精度往往是挑战。并非所有 FPGA 都支持运行中无中断重配置。

## 5. 易混概念与边界

FPGA 可改变硬件逻辑，而 GPU 主要改变运行的软件指令；FPGA 通常较 ASIC 灵活，但能效、频率和单位成本的比较依具体方案而定。

## 6. 中等难度面试题（含参考答案）

1. **问：FPGA 如何降低数据流处理的单条记录延迟？** 答：可通过深度流水线、硬件并行与绕开通用软件调度来控制延迟。
2. **问：FPGA 算法迁移的难点是什么？** 答：需进行位宽设计、并行资源映射、时序约束与验证，不能简单照搬 CPU 算法。

## 7. 中等难度考试题（含解析）

1. **题：流水线包含 5 级、每级 1 个周期，稳定后理想吞吐是多少？** 解：首条延迟 5 周期，之后理想情况每周期输出 1 条。
2. **题：为何将所有计算完全展开可能无法布置到 FPGA？** 解：逻辑/DSP/片上 RAM 资源有限，且布线与时序也会受影响。
