# Tensor Parallelism（张量并行 · TP）

> 学科：AI Infrastructure · 专题：分布式训练 · 内容范围：训练系统与工程实现（以所引官方资料的版本为准）

## 1. 核心定义

张量并行（TP）将**同一个层的权重或激活张量**沿指定维度分到多个设备，使单层矩阵运算由多设备共同完成。它解决单层权重/激活放不下或单设备计算不足的问题，并非复制模型处理不同数据。

## 2. 形象理解

把一张巨大表格按列交给四名成员计算，再按后续层所需的数据形状汇总。每个人只存一部分列，但最终结果需要交换中间值；如果成员之间传输特别慢，分工未必划算。类比不能推导任何线性加速比。

## 3. 技术原理与核心内容

以线性层 `Y=XW` 为例：若 `W` 沿输出维切为 `W_i`，各 rank 产生不同的 `Y_i`，需要拼接/all-gather 才得到完整输出；若沿输入维切分，rank 产生部分乘积，须用 reduce-sum 等集合通信汇总。Transformer 的注意力头和前馈层可采用不同切分。关键约束是分片维度整除性、通信分组、数值一致性、布局转换以及自动求导的集合通信反向规则。TP 分组一般优先放在高速同节点互连上。

## 4. 工程实践与设计权衡

当一个 Transformer 层的权重在单卡容不下时，先尝试 TP=2 或 TP=4；核对隐藏维度、注意力头数和框架支持的分块策略。分别测矩阵核时间、all-gather/reduce-scatter、TP 组带宽与端到端 tokens/s；不要只报告权重显存的下降。TP 越高，局部 GEMM 越小，通信启动开销在小 batch 时尤其显著。

## 5. 易混概念与边界

**TP** 划分一层的张量，**PP** 按层深度分配，**DP/DDP** 复制模型并分不同样本；**SP** 仅将部分算子按序列维分片，不等同于把整条序列的注意力独立处理。

## 6. 中等难度面试题（含参考答案）

1. **问：TP 的列并行线性层与行并行线性层通信各发生在何处？** 答：列切分让各 rank 得到输出特征子块，后续若需要完整激活通常 all-gather；行切分让各 rank 计算输出部分和，需要 reduce-sum 或 reduce-scatter。具体安排取决于连续层的布局与算子融合，不能把每层都机械地加一次 all-gather。

2. **问：TP=8 为什么可能反而比 TP=4 慢？** 答：更小的局部矩阵降低 GEMM 效率，同时集合通信次数、同步等待与跨节点网络成本可能增大；通信与计算重叠不足时收益倒退。先分析网络拓扑及每个操作的规模，再选 TP degree。

## 7. 中等难度考试题（含解析）

1. **题：假设单层权重矩阵为 `8192×8192`，元素 BF16、2 字节；理想按一维均匀 TP=4 分片，每 rank 存多少权重？** 解：总元素 `8192²=67,108,864`，总原始权重字节数 `134,217,728`=**128 MiB**；4 等分后每 rank **32 MiB**。这里没有计入梯度、优化器、临时 all-gather 缓冲、对齐及副本。

2. **题：隐藏维度 `6144`，TP=3 沿输出特征均匀分片，每 rank 输出多少维？** 解：`6144 / 3 = 2048` 维。若分片轴不能整除，需额外 pad、非均匀分片或选其它并行度；本题假设整除。
