# Post-Training Quantization（训练后量化 · PTQ）

> 学科：AI Infrastructure · 专题：推理与服务 · 具体实现应核对官方接口及版本

## 1. 核心定义

训练后量化（Post-Training Quantization，PTQ）在预训练或微调结束后，对既有模型权重和/或激活的表示做量化压缩，通常不通过完整任务训练再优化全部参数。它可结合校准集估计数值范围、通道敏感度和 outliers；可有少量局部误差最小化优化，但不应因此把它误称为完整的 QAT。

## 2. 形象理解

一本已完成的高精度地图准备压缩印刷：先观察常见路径和重要细节，决定哪些坐标可以舍入。地图没有重新测绘，只是在现有结果上做压缩；太激进会使关键转弯处丢失精度。

## 3. 技术原理与核心内容

常见流程：选择目标硬件支持的量化格式 → 加载 FP16/BF16/FP32 权重 → 选有代表性的 calibration 样本 → 收集 activation 统计或分析量化误差 → 推导 per-group scale/zero-point → 生成 INT8/INT4/FP8 表示 → 在目标 backend 测正确性/性能。Weight-only PTQ 可以不需要 activation 统计，也可用 AWQ/GPTQ 等校准/局部优化方法，方法的学习步骤与约束不完全相同。量化后模型还需维护 tokenizer、输出头、嵌入和 KV 精度的兼容边界。

## 4. 工程实践与设计权衡

对生产模型先按真实提示词长度、语言与任务组成校准集，包含异常长序列或 rare tokens 做压力回归。比较 BF16 基线与 PTQ 模型在准确率、困惑度、事实性、吞吐、TTFT/ITL、总显存上的变化，核对量化算法版本、group_size、scale metadata 和推理 kernel。即使静态权重减小，也可能出现 activation outliers 导致的局部退化。

## 5. 易混概念与边界

PTQ 的关键在**训练已完成后**做表示压缩；QAT 在训练/微调过程中显式模拟量化误差，使权重可适应量化。PTQ 既可 weight-only，也可同时量化 activation；不能把两者当同义词。

## 6. 中等难度面试题（含参考答案）

1. **问：为什么校准样本集不具代表性会造成 PTQ 模型质量退化？** 答：估算的 scale/clip 范围可能忽略线上 outliers 或长尾 token 分布，导致重要激活饱和。按真实输入分布分桶并做保留集回归。

2. **问：PTQ 一定不需要任何优化过程吗？** 答：不一定。GPTQ 等可在局部做近似误差最小化以选择权重表示，但不等于带完整任务损失的端到端 QAT。需清楚描述优化变量与数据。

## 7. 中等难度考试题（含解析）

1. **题：BF16 权重体积 6GB、理想 INT8 payload=3GB，忽略 scale metadata，权重裸字节减少比例？** 解：`(6−3)/6=**50%**`；整机显存还包括 KV、activation 等。

2. **题：校准样本有 75 条短请求与 25 条长请求，长请求比例？若线上长请求占 60%，该校准分布是否匹配？** 解：校准长请求比例 `25/100=**25%**`，显著低于线上 60%；应按目标分布重采样或分层覆盖，不能仅因数量达到 100 就视作代表性。
