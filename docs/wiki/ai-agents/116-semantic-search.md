# Semantic Search（语义检索）

> AI Agents · 专题：检索与知识增强 · 信息检索基础与 Agent 工程实践；计算示例为教学题设

## 1. 核心定义

**Semantic Search（语义检索）**：Semantic Search（语义检索）是试图依据查询表达的意义和用户意图而非单纯表面词项重合，找到相关文档或对象的检索方式。现代实现经常使用 Embedding + Vector Search，也可能使用稀疏语义模型或其他语义匹配策略。

**适用边界：**语义相关性不代表真实事实一致；尤其对法律上的‘不得’、精确 SKU、时间和金额，纯语义相似可能忽略决定性细节。不要把 Semantic Search 与某一种向量数据库技术定义为严格同义。

## 2. 形象理解

有人问‘手机没电怎么办’，即使文档写的是‘电池电量耗尽的解决方案’，语义搜索仍可能找到它。

**类比的局限：**文档相似不意味着处理方法适合当前机型或已授权；型号与地区限制仍需精确匹配。

## 3. 技术原理与核心内容

查询 q 经语义编码器转换为表示 e(q)，候选 d 的相似度可由 `cos(e(q),e(d))` 近似；也可经多阶段模型估计相关性。基础设施可以使用 ANN 扩展规模，必要时配合关键词实体过滤与 reranker。要报告召回率、首条相关排名、延迟与不同语言/产品编号上的失效情况；编码模型升级需重建兼容索引。

## 4. 工程实践与设计权衡

**工程案例：**技术支持团队检索‘登不上去’时可以召回‘身份认证失败和 MFA 故障排查’，但最终操作前仍需核对账户、环境和服务状态，不把另一系统的修复脚本应用于当前用户。

**失败模式与验证：**否定句/数字识别失误、语义相近而版本相反、低资源语言召回下降、ANN 漏检精确文档。用包含同义改写、否定、型号和版本的标注测试集对比关键词和混合方法。

## 5. 关联知识与易混辨析

Semantic Search 是按意义匹配的目标；Vector Search 是按向量距离执行的技术；Keyword Search 依词项匹配；Hybrid Search 把两种信号组合。

## 6. 中等难度面试题（含参考答案）

1. **问：为什么同义词查询常适合语义检索？** 答：查询与文档可能字面不同但意思相近，embedding 或语义匹配可以弥补词项不重合，仍需核对实体精确性。
2. **问：一个‘禁止访问’与‘允许访问’文档在向量空间接近，该怎么办？** 答：补充关键词、权限和否定规则过滤，并用 reranker/业务规则验证，不能只信语义距离。

## 7. 中等难度考试题（含解析）

1. **题：查询与三份文档的语义分数分别 0.82、0.68、0.91，按降序第一名是谁？** 解：分数 0.91 的文档；这是相关度排序，不是 91% 事实正确率。
2. **题：top-5 结果中 3 个相关且实际共有 12 个相关文档，precision@5 与 recall@5？** 解：precision@5=3/5=60%，recall@5=3/12=25%。
