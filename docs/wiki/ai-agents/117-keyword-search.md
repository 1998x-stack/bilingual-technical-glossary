# Keyword Search（关键词检索）

> AI Agents · 专题：检索与知识增强 · 信息检索基础与 Agent 工程实践；计算示例为教学题设

## 1. 核心定义

**Keyword Search（关键词检索）**：Keyword Search（关键词检索）依靠查询与文档的词项、词组或字段匹配来查找内容，常使用倒排索引、布尔过滤与 BM25 等词项相关性算法。它特别擅长精确标识符、错误代码、专有名称和必须出现的术语。

**适用边界：**纯词项检索可能漏掉同义改写、拼写变化和跨语言语义关联；不同分词器、停用词及字段权重会影响效果。BM25 是相关性排序函数，不是对文档真假的判定。

## 2. 形象理解

像查图书索引中的精确章节名或产品编号，字面字符一致时通常定位直接。

**类比的局限：**同一概念可能有不同说法，目录里没写相同字词不等于不存在相关知识。

## 3. 技术原理与核心内容

倒排索引将 token 映射到包含它的文档 posting list；查询时求交/并集和词项分数。BM25 综合 term frequency、inverse document frequency 与文档长度等因素，适合检索包含精确词语的段落。对订单号/错误码可采用精确匹配与 filter；对中文应明确分词或 n-gram 策略。生产搜索需配置 ACL，查询排名不能跳过授权。

## 4. 工程实践与设计权衡

**工程案例：**数据库排障 Agent 需要查 `ORA-00060` 错误，关键词索引比普通语义近邻更可靠地命中该精确错误代码；然后结合知识文档的版本与操作系统信息判断处理方式。

**失败模式与验证：**中文分词切坏技术名词、词项太常见使排序失真、不同语言的同义表达漏召回、匹配到了已过期或无权文档。通过精确代码召回、同义改写测试、字段权重及安全过滤验收。

## 5. 关联知识与易混辨析

Keyword Search 依字面词项；Semantic Search 依意义匹配；Hybrid Search 将两者结合。Reranking 是后续候选重排序，既能消费关键词候选也能消费向量候选。

## 6. 中等难度面试题（含参考答案）

1. **问：为什么搜索错误码适合关键词检索？** 答：错误码精确字符重要，相似代码可能含义完全不同；倒排索引与字段精确匹配容易保证约束。
2. **问：关键词搜索为什么可能漏掉‘退款’与‘退钱’的对应文档？** 答：若没有同义词扩展或语义模型，字面词项不一致会导致召回不足；可引入术语词典或混合搜索。

## 7. 中等难度考试题（含解析）

1. **题：1000 篇文档中包含专有词 X 的有 20 篇，若忽略平滑，IDF 近似 ln(1000/20)≈？** 解：ln(50)≈3.91；实际 BM25 常使用平滑 IDF 公式。
2. **题：必须同时包含 A、B 两词，A 出现在 80 篇、B 出现在 50 篇，交集有 20 篇，AND 查询返回几篇？** 解：20 篇；不能将 80+50 当作交集数量。
