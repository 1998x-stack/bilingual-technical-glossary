# Ground Truth（黄金答案）

> AI Agents · 专题：评测体系与常见基准 · 依据独立证据、实际任务状态与明确的评价边界

## 1. 核心定义

**Ground Truth（黄金答案）**：Ground Truth（黄金答案/真值）是用于评价任务输出的参考事实、目标状态或标注结果，可以来自可执行测试、已核验数据库、领域专家与经过审查的样例。它不必总是一段唯一固定文本，复杂 Agent 任务常以满足一组业务谓词作为真值。

**适用边界：**标注的标准答案不等于永远正确：软件版本、时间事实、币种和政策更新后，旧标签可能失效。对于开放任务常存在多个合法结果，必须明确容差、评分证据与争议处理，不能机械地用 exact match。

## 2. 形象理解

像地理测量用经校准的基准点作为对照，而不能把一张旧地图上已经搬迁的地址当永恒事实。

**类比的局限：**专家也可能标错或存在分歧，真值来源与适用时间都需要记录。

## 3. 技术原理与核心内容

GroundTruthRecord={task_id,oracle_type,expected_state,source_refs,valid_at,version,annotator_ids,consensus_status}。确定性 oracle 检查代码测试/DB 目标状态/数值容差；主观文本用多评审 rubric 和仲裁。测模型时冻结参考集，发现事实变化后采用 versioned reannotation，分别发布老、新基准成绩，避免同一分数在不同答案集上混用。对无法核定的样例标 unclear，不靠模型自评强行制造标签。

## 4. 工程实践与设计权衡

**工程案例：**项目管理 Agent 的任务是‘创建带指定标签的 Issue’，真值并非‘回复里有 issue 编号’，而是测试仓库里存在正确 title、labels、owner 的实际记录及权限合规证据。

**失败模式与验证：**假设黄金答案只有一个字符串、标注者泄漏测试答案、陈旧规则把正确新行为判错、不同语言答案不一致。以双人复核、原始证据追踪和标注版本迁移验证。

## 5. 关联知识与易混辨析

Ground Truth 是参考目标；Human Annotation 是产生其中一种标签的过程；Rubric 是判定标准；Judge 是一个可能不准确的判定工具。

## 6. 中等难度面试题（含参考答案）

1. **问：为什么 Agent 工具任务的 Ground Truth 更适合使用后置条件？** 答：任务真正目标是环境变化，文本自述可伪造；业务谓词能检查资源状态与授权。
2. **问：标注答案随软件规范更新失效，怎样保持可比较性？** 答：保留旧版并注明 valid_at，重标新版并分别重测或给出映射，不能静默替换 oracle。

## 7. 中等难度考试题（含解析）

1. **题：10 个任务中 8 个有可核验真值、2 个标注冲突，真值可用覆盖率？** 解：8/10=80%；冲突项应复核或单独标注。
2. **题：标准答案允许数值误差±0.02，输出与目标差为 0.03，能算通过吗？** 解：不能，误差超过容差。
