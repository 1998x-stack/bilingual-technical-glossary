# Foundation Model（基础模型）

> AI Agents · 专题：基础概念与角色 · 适用范围：通用智能体系统设计；具体 SDK 与平台版本以对应文档为准

## 1. 核心定义

**Foundation Model（基础模型）**：Foundation Model 是通过大规模广泛数据训练、可通过提示、微调或适配服务多种下游任务的基础模型；可包含语言、视觉、多模态等类别。

**适用边界：**基础模型不是特定厂商产品，也不等价于必然具有工具调用或自主执行能力。

## 2. 形象理解

像通识教育基础：已有共通知识，但应用到医学审校或财务操作仍需专业流程与授权。

**类比的局限：**广泛适用不代表所有领域都可靠、无偏差或已具备特定业务资质。

## 3. 技术原理与核心内容

典型路径为通用预训练 → 任务适配（提示、微调或检索）→ 评测 → 部署。Agent 使用其作为推断组件，运行器负责工具执行和安全策略。模型能力迁移受训练分布与任务数据影响。

## 4. 工程实践与设计权衡

企业文档助理先测通用模型在真实 FAQ 的证据引用与错误率，再比较提示+RAG 与微调；不要默认添加记忆或多 Agent 就能修复知识缺口。

## 5. 关联知识与易混辨析

Foundation Model（训练与迁移范式）与 LLM（语言模型类别）不是上下位完全相等；一些基础模型为非语言模态。

## 6. 中等难度面试题（含参考答案）

1. **问：为什么不应把模型能力直接视为业务合规能力？** 答：业务合规依赖数据权限、审计、人工流程与法规范围；预训练任务广泛并不能保证特定行为安全。
2. **问：业务数据更新很快时先试微调还是检索？** 答：优先检索可更新的权威知识并做引用核验；微调可用于格式和行为适配，但不应被当成实时知识库。

## 7. 中等难度考试题（含解析）

1. **题：题设无适配模型正确 70/100 题，RAG 后 82/100，准确率提升几个百分点？相对提升多少？** 解：绝对提升 12 个百分点；相对提升 12/70≈17.1%；须说明测试集、误差区间和成本才可比较。
2. **题：解释一个图文多模态基础模型为什么不必属于 LLM。** 解：基础模型强调通用预训练与迁移，多模态处理可能包含语言也可能以非语言任务为主；是否属于 LLM 取决于具体建模目标。
