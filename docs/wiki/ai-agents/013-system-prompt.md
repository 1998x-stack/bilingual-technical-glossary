# System Prompt（系统提示词）

> AI Agents · 专题：基础概念与角色 · 适用范围：通用智能体系统设计；具体 SDK 与平台版本以对应文档为准

## 1. 核心定义

**System Prompt（系统提示词）**：System Prompt 是在某些聊天模型 API 中承载较高优先级行为指引的消息内容，用于规定模型角色、约束、表达风格和任务边界；它是模型输入，不是访问控制系统。

**适用边界：**不同 API 可能使用 system、developer、instructions 或其他字段；优先级规则由具体提供方规定。

## 2. 形象理解

像教师写在试卷开头的考试规则，影响作答，却不会自行锁住考场的门。

**类比的局限：**提示无法保证模型抵御所有注入，也不代替执行层的权限校验。

## 3. 技术原理与核心内容

运行器将受信任消息与用户、工具上下文按 API 约定组织；模型根据整体上下文生成。对于授权、金额限制、出站目标白名单，应在模型外使用验证器强制执行。

## 4. 工程实践与设计权衡

财务问答 Agent 的高优先级指令规定只读、说明不确定性；实际银行 API 凭证也必须是只读，并在服务端拒绝转账请求，即使模型误选写工具也不可执行。

## 5. 关联知识与易混辨析

System Prompt 不等于 User Prompt：前者由应用方配置行为框架，后者表达用户任务；具体层级和职责要按 API 文档解释。

## 6. 中等难度面试题（含参考答案）

1. **问：System Prompt 变得很长会出现什么工程问题？** 答：增大输入开销、增加冲突与维护难度，并可能遮蔽关键要求；分离固定策略、上下文数据和工具约束，使用回归评测核对效果。
2. **问：为什么强制安全规则应放到 Runtime？** 答：模型仍可能生成违反指令的调用；执行器的权限校验可在不可控模型输出之后强制拦截越权动作。

## 7. 中等难度考试题（含解析）

1. **题：模型误生成一条退款 1000 元的调用，但系统授权上限 200 元，是否允许？** 解：不允许；参数由服务端校验并拒绝。system 提示写了限额不能作为唯一保护。
2. **题：识别消息：应用方预置“使用中文答题”和用户输入“查询明天天气”，各属于什么？** 解：前者为应用行为指引（可能置于 system/developer 字段），后者为用户请求，具体优先级取决于 API 契约。
