# Agentic System（智能体系统）

> AI Agents · 专题：基础概念与角色 · 适用范围：通用智能体系统设计；具体 SDK 与平台版本以对应文档为准

## 1. 核心定义

**Agentic System（智能体系统）**：Agentic System 是支撑智能体可靠运行的端到端系统，包括决策模型、工具接口、任务状态、控制流、权限、观测日志和人工接管机制。

**适用边界：**模型只是系统的一层，业务数据库、执行器与运行环境也影响最终行为。

## 2. 形象理解

像机场航班运行系统：驾驶员负责判断，但塔台、航线、维修、通信与安全流程共同决定能否安全到达。

**类比的局限：**系统组件不必都是独立服务；在原型中也可由单进程组织。

## 3. 技术原理与核心内容

输入层规范化目标及权限；规划/决策层选择动作；执行层验证工具参数并调用；状态层存储检查点；监控层记录轨迹；停止层验收成功、安全拒绝或超预算。系统应在副作用与读操作之间设置不同的保护。

## 4. 工程实践与设计权衡

研发助手自动开 PR：模型提议 patch；运行器在隔离工作区执行；测试和策略检查通过才允许提交，写入主分支则要求额外审批。日志关联 trace_id，重复消息避免重复建 PR。

## 5. 关联知识与易混辨析

Agent 与 Agent Runtime：前者指面向任务的行为实体；后者是其执行基础设施。系统比 Runtime 范围更广。

## 6. 中等难度面试题（含参考答案）

1. **问：为什么只优化模型分数无法保证系统质量？** 答：失败可能在工具超时、错误权限、检索数据陈旧、状态丢失和终止策略；需要端到端故障注入与追踪。
2. **问：如何拆分只读与写入工具？** 答：按最小权限分域，写入使用强参数校验、确认、幂等键与审计；不要仅凭 prompt 作为安全边界。

## 7. 中等难度考试题（含解析）

1. **题：题设四个串行阶段耗时 120、80、300、100 ms，总延迟多少？若工具阶段从 300 降至 180 ms，新总延迟？** 解：初始 600 ms，优化后 480 ms，减少 120 ms（20%）；端到端指标区别于某单阶段加速。
2. **题：日志显示模型正确选工具但执行没有任何结果，优先排查哪些系统层？** 解：检查工具注册/网络、参数校验、超时重试、权限、执行环境与 trace_id；不能仅用更多模型推理解决。
