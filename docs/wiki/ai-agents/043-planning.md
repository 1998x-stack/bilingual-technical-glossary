# Planning（规划）

> 适用领域：AI Agents · 专题：任务规划与决策 · 相关理论与具体产品能力应依据所引来源和版本区分

## 1. 核心定义

**Planning（规划）**：Planning（规划）是根据初始状态、目标、可执行动作及其前置条件，选择可达且满足约束的后续行动序列或部分有序行动结构的过程。Agent 规划必须同时考虑权限、成本、依赖与环境变化。

**适用边界：**经典确定性规划通常假设动作模型可描述；LLM 生成的文字计划不能自动保证满足前置条件和资源约束，真实执行需要验证。

## 2. 形象理解

像组织搬家：先订车、打包、搬运、交钥匙，每一步都受时间、资源和先后顺序约束。

**类比的局限：**现实中车辆可能迟到、钥匙可能丢失；静态计划不等于实际可执行。

## 3. 技术原理与核心内容

形式上给定状态 s0、目标谓词 G(s)、动作集合 A 和状态转移 T。寻找序列 `(a1,…,ak)` 满足前置条件 `pre(ai,si)`，并使 `G(T(...T(s0,a1),...,ak))=true`；还可最小化总成本。工业流程必须分离生成、约束校验、执行与结果验证。

## 4. 工程实践与设计权衡

**工程案例：**财务月结 Agent 先拉账单再对账，异常单据人工审批后才归档；依赖可以用 DAG 约束，而工具返回异常需要修订后续步骤。比较计划可执行率、完成率、重规划次数和关键路径时延。

**失败模式与验证：**仅靠模型输出一张“看起来合理”的计划可能忽略权限、资源冲突、不可逆动作与截止日期。规划器应使用业务规则检查，并执行前后再核对状态。

## 5. 关联知识与易混辨析

Planning 是寻找可执行路径的整体问题；High-level Plan 是抽象阶段；Action Plan 是可操作的具体步骤；Task Decomposition 是规划中的一类拆分方法。

## 6. 中等难度面试题（含参考答案）

1. **问：LLM 列出 10 步计划，怎样判定它能执行？** 答：按每步前置条件、依赖、时间/资源、工具权限与成功谓词检查；先在受控环境模拟或验证，执行后对照实际状态。
2. **问：确定性工作流与动态 Agent 规划如何选择？** 答：稳定、可预知的业务流程优先固定控制；当任务分支和外部条件频繁变化时考虑动态规划，但增加验证、权限及回退成本。

## 7. 中等难度考试题（含解析）

1. **题：初始无票据，动作 A 下载票据，B 对账要求票据存在，C 归档要求对账完成。顺序 B→A→C 合法吗？** 解：不合法，B 的前置条件不满足；可行顺序 A→B→C，前提是其他约束满足。
2. **题：有两条到达目标的路径：方案 X 成本 5+4+7 元，方案 Y 成本 8+6 元。均可执行时最小成本多少？** 解：X 总成本 16 元，Y 总成本 14 元；选择 Y。只有两方案都满足安全和前置条件才可比较成本。
