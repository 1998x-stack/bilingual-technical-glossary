# Latency（延迟）

> AI Agents · 专题：工程化、成本与可观测性 · 运行时观测、性能和可核验业务结果

## 1. 核心定义

**Latency（延迟）**：延迟是从明确定义的起点到终点所经历的墙钟时间；Agent 既有端到端任务延迟，也有模型首 token 时间、生成时间、检索/工具耗时与人审等待。没有计时口径就不能可靠比较延迟。

**关键边界：**统计、记录和推导应围绕具体组件、时间窗口、资源范围与数据来源展开。对同一指标，模型级、工具级和端到端任务级的计数范围不同；不能把某个厂商的指标名或日志约定误作所有框架的标准。指标异常不必然表示恶意攻击，正常值也不保证业务目标已成功。

## 2. 形象理解

**类比：**像快递从下单到签收的时间，与配送途中每个站点用时并非同一概念。

**类比的局限：**多个站点可能并行处理或等待人工，分段时间相加未必等于用户经历的实际总时长。 Agent 还涉及异步执行、不可逆副作用和跨组件故障，必须回到真实时间线及权威状态核验。

## 3. 技术原理与核心内容

用单调时钟测 `t_end-t_start`，定义 TTFT 与完整响应/任务完成的区别。耗时可拆排队、检索、模型、工具、网络、重试与用户审批，但并行路径不能直接求和；关注 P50、P95、P99 和超时比率。对 streaming 场景分开首字节与最后 token；计算必须声明是否包含网络及等待时间。

**工程不变量。**模型生成“完成”不等于业务系统提交成功。任务级事件需要和权威后置状态、幂等请求号以及租户范围关联；统计前必须声明计量单位、时间范围、分母与抽样方式。低信任外部内容不可作为系统配置指令，日志/指标不得存放明文凭据。并发执行的时间线应遵循真实因果关系而非简单求和。

**数据路径。**入口生成任务/追踪上下文，模型与工具分别输出带时间和状态的事件；记录系统可作采样、聚合与索引。对失败重试需标注逻辑任务与单次尝试的区别。对隐私敏感字段做 allowlist 和脱敏；对于来源不可信的数据保留标记，不允许它重新定义权限和用户目标。

## 4. 工程实践与设计权衡

**真实工程类型的案例：**一个浏览器 Agent 花 200ms 检索，900ms 模型生成，两个并行工具分别 700ms 与 500ms；若顺序是检索→模型→并行工具，理想耗时约 200+900+max(700,500)=1800ms，而非 2300ms。

**测试与排障。**为每个概念构造正常、超时、重试、并发、队列积压和返回成功但业务未落库的场景，检查模型建议、实际工具请求、权限判定、后端结果及观测信号是否一致。建立固定数据集与时间窗，独立复算计算题；对于采样数据说明不确定性。可观测性增强有日志/指标存储成本和敏感数据面扩大等代价，应基于服务级别目标和故障价值进行最小化采集。

**权衡。**准确定位问题需要信号足够丰富，但全量记录模型输入可能暴露隐私，过多高基数标签会提高成本。对高影响操作保留必要审计，普通可观测数据按合理抽样、保留与访问策略处理。一个工具返回 200 不意味着整个 Agent 任务成功；必须检查业务层结果。

## 5. 关联知识与易混辨析

Latency 是时间指标；Throughput 是单位时间任务量。吞吐提升可能造成排队，反而增加尾延迟；TTFT 仅代表开始输出，不是业务完成。

需要区分事件、持续时间、聚合率与因果关系这四类信息。构建跨术语查询时应从任务目标→服务行为→运行数据→业务后置条件逐级定位，不可只因为名称相近就混用指标或用 tracing ID 充当权限凭证。

## 6. 中等难度面试题（含参考答案）

1. **问：为什么只优化模型生成速度可能改善不了用户体验？** 答：Agent 还包括网络、RAG、工具重试、人工等待和业务确认，需用 Trace 找关键路径。
2. **问：如何检查一个模型服务的 P95 延迟变差是排队还是执行造成？** 答：分别埋点排队时间、模型执行与工具调用，并按流量、并发分组分析，避免用均值掩盖尾部。

优秀回答不仅提出技术机制，还应指出适用范围、失败模式、用户感知结果和能在生产上观察到的验证信号。

## 7. 中等难度考试题（含解析）

1. **题：100 次延迟中排序第 95 个为 2.4 秒，按 nearest-rank 定义 P95 是多少？** 解：P95=2.4 秒；nearest-rank 索引为 ceil(0.95×100)=95。 **计算口径：**数据、单位和边界均由题设给出；若非随机抽样或存在遗漏，不得外推为真实系统质量。
2. **题：一个 1000ms 的父 Span 包含并行 700ms 与 600ms 子 Span，为什么总延迟不等于 2300ms？** 解：子 Span 会并行且包含于父区间，墙钟延迟应取实际入口/出口差值，不能简单累加。 **评分重点：**原理、推导步骤、关键反例与可操作的验收方式，而非单句术语记忆。
