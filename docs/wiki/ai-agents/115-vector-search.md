# Vector Search（向量检索）

> AI Agents · 专题：检索与知识增强 · 数学原理、检索架构与工程权衡；具体参数随产品和版本变化

## 1. 核心定义

**Vector Search（向量检索）**：Vector Search（向量检索）是把查询和候选内容映射到同一向量空间后，按距离或相似度寻找最近邻的检索方式。它通常用于语义召回，也用于图像、多模态和推荐场景；实际可采用 exact kNN 或 ANN。

**适用边界：**向量邻近并非直接证明事实一致，特别对产品型号、订单号、否定词与精确日期，关键词/结构化过滤可能更可靠。ANN 通过近似换取速度，存在召回与延迟权衡。

## 2. 形象理解

在地图上寻找离目标最近的几个点，优先探索相似内容，但距离本身不说明内容是否可信。

**类比的局限：**语义近邻和实际地理近邻一样可能不适合目标任务，例如距离近但没有访问权限。

## 3. 技术原理与核心内容

设查询向量 q、文档向量 d_i，计算如 `score_i = cos(q,d_i)`，取 top-k；若使用余弦与 L2，要说明是否已单位归一化。ANN 常通过图索引或量化减少全量扫描；候选返回后按 ACL、版本和业务实体 ID 过滤并可重排序。评价 recall@k、p95 latency、吞吐、索引更新滞后与任务相关性。

## 4. 工程实践与设计权衡

**工程案例：**客服 Agent 用‘无法取消自动续费’检索到‘订阅取消失败’帮助文档；但如果用户指定产品 SKU-204，应配合该精确 SKU 过滤，避免另一产品的相似说明导致错答。

**失败模式与验证：**向量模型将‘允许’与‘禁止’映射过近、过滤策略在 ANN 下漏掉合法候选、索引维度更换后残留旧向量。对同义改写和硬编码实体设计分层测试，必要时使用混合检索。

## 5. 关联知识与易混辨析

Vector Search 以向量近邻为核心； Semantic Search 是面向意义的检索目标，可能用其他方法实现；Keyword Search 采用词项匹配；Hybrid Search 可以组合两种信号。

## 6. 中等难度面试题（含参考答案）

1. **问：为什么准确型号搜索不能只依赖向量相似度？** 答：相似型号可能被编码得很近，但业务需要精确实体匹配；应加结构化 filter/关键词条件。
2. **问：ANN 比 exact kNN 更快，是否必然质量更高？** 答：不是。ANN 一般以计算效率换取可能的邻居遗漏，应比较相对精确基线的 recall@k 和业务效果。

## 7. 中等难度考试题（含解析）

1. **题：三个候选与查询的余弦相似度分别 0.92、0.75、0.81，按降序 top-2 是哪两个？** 解：分数 0.92 与 0.81 的两个候选；分数是相关性，不是正确率。
2. **题：精确 top-5 与 ANN top-5 有 4 个重合，ANN recall@5？** 解：4/5=80%，这不代表最终答案 80% 正确。
