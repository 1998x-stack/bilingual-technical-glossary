# Semantic Memory（语义记忆）

> AI Agents · 专题：上下文、记忆与状态 · 概念与实际框架行为以来源和版本为准

## 1. 核心定义

**Semantic Memory（语义记忆）**：Semantic Memory（语义记忆）是将一般事实、概念、关系与知识作为可检索单元保存的一类记忆，侧重‘知道什么’，而非事情如何发生。工程上可以存储为结构化三元组、带引用的文档片段或知识索引。

**适用边界：**事实可能随时间、地区与版本改变；检索到的语义记忆不自动代表最新事实，也不代表有权读取业务系统或采取外部动作。

## 2. 形象理解

像百科词条记录某术语定义、概念之间关系和公式，而不是记录作者哪天学到它。

**类比的局限：**百科内容仍可能有过时条款、错误解释或不适用的条件，不能替代当前设备手册。

## 3. 技术原理与核心内容

知识单元可表示为 (subject,predicate,object,provenance,valid_from,valid_to,confidence)，查询时先做用户/租户授权及有效期过滤，再进行向量、关键词或图关系检索，必要时根据来源核验。冲突条目保留版本和适用范围，不能让模型的最新回答直接覆盖高权威证据。

## 4. 工程实践与设计权衡

**工程案例：**设备诊断 Agent 保存‘型号 X 需要额定电压 Y’的知识，但部署到不同地区/硬件修订版时应查当前铭牌和正式技术文档，验证这条知识是否适用。

**失败模式与验证：**跨版本冲突、来源缺失、过期库存数被误当实时事实、跨租户泄露。测试包含事实支持率、时间有效性、冲突消解、权限过滤和删除后不可召回。

## 5. 关联知识与易混辨析

Semantic Memory 保存一般知识；Episodic Memory 保存特定经历；Procedural Memory 保存执行步骤。真正的业务库存/支付状态应从权威源读取。

## 6. 中等难度面试题（含参考答案）

1. **问：语义记忆冲突时能否只取最新插入的那条？** 答：不能。需核对生效时间、适用对象、原始权威来源和版本；最新写入也可能是错误记录。
2. **问：模型从一次英语对话推测用户永久喜欢英语，能直接写语义记忆吗？** 答：不能，仅凭一次对话不足以确认稳定偏好，且需遵守用户授权与更正机制。

## 7. 中等难度考试题（含解析）

1. **题：80 条知识项中 10 条过期、5 条撤回且互不重叠，剩余可用多少？** 解：80−10−5=65 条，具体用户仍须进一步过滤权限。
2. **题：语义记忆说上月库存 20 件，用户问今天库存，能直接回答 20 吗？** 解：不能。旧记忆记录历史值，必须查询当前权威库存。
