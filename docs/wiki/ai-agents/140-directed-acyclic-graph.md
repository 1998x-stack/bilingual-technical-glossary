# Directed Acyclic Graph (DAG)（有向无环图 · DAG）

> AI Agents · 专题：工作流与编排模式 · 系统架构与执行依赖；技术语义依具体工具契约验证

## 1. 核心定义

**Directed Acyclic Graph (DAG)（有向无环图）**：Directed Acyclic Graph（DAG，有向无环图）是边有方向且不存在任何有向环的图结构，常表示任务间先后依赖。DAG 允许用拓扑排序找出可执行次序，并根据前置依赖并行调度部分任务。

**适用边界：**DAG 不能直接在图内表达 A→B→A 这样的循环；实际 Agent 系统可使用状态图或把每一轮展开为新的执行实例。DAG 不是所有编排器唯一合法的图结构。

## 2. 形象理解

像装修依赖清单：先铺管线再封墙；多个互不相关房间的施工可以并行，但整体不能形成互相等待的闭环。

**类比的局限：**依赖表没有环不意味着资源充足、业务权限有效或外部写入可重放。

## 3. 技术原理与核心内容

G=(V,E)，若存在拓扑序列 v1,…,vn，使每条边 (u,v) 都满足 order(u)<order(v)，即为 DAG。Kahn 算法反复提取入度为 0 的节点、移除其出边，若最终处理节点数少于 |V| 则存在环；时间复杂度 O(|V|+|E|)。执行器以入度/完成依赖为门槛，失败节点应阻断依赖后继而不影响独立分支。

## 4. 工程实践与设计权衡

**工程案例：**CI Agent 的编译节点先完成后才执行单测与静态检查，两者可并行；全部完成后进入部署审批。若静态检查失败，部署不可运行，即使测试成功。

**失败模式与验证：**把循环依赖当 DAG 导致死锁、错误依赖边让工作错序、只用入度为零忽略审批权限、重复运行已完成的写节点。用拓扑排序、随机 DAG 生成、注入失败和竞态测试验收。

## 5. 关联知识与易混辨析

DAG 是无环依赖图；Control Flow Graph 可有环；State Graph 表达状态转换和循环；Fan-out/Fan-in 是常见 DAG 中的分支与汇聚形态。

## 6. 中等难度面试题（含参考答案）

1. **问：如何快速判断工作流依赖图是否有环？** 答：用 Kahn 拓扑排序或 DFS 环检测；若无法输出全部节点的拓扑序，则存在环。
2. **问：DAG 中可以并行运行哪些任务？** 答：依赖均已满足、资源与副作用不冲突的就绪节点可并行，不必按拓扑序逐个串行。

## 7. 中等难度考试题（含解析）

1. **题：DAG 节点 A=2、B=3、C=5 秒，A→B、A→C，B/C 并行，总最短关键路径时间？** 解：2+max(3,5)=7 秒，忽略调度开销。
2. **题：图有 A→B、B→C、C→A，能找到拓扑排序吗？** 解：不能，存在有向环；应修改依赖或改用允许循环的控制模型。
