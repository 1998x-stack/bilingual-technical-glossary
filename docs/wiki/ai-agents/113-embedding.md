# Embedding（嵌入向量）

> AI Agents · 专题：检索与知识增强 · 数学原理、检索架构与工程权衡；具体参数随产品和版本变化

## 1. 核心定义

**Embedding（嵌入向量）**：Embedding（嵌入向量）是将文本、图片等对象映射到固定维度或定义维度的数值向量空间的表示，使检索系统能通过几何距离或相似度近似比较语义关系。文本嵌入模型通常将相关表述编码到相近区域。

**适用边界：**几何相似度不是概率或事实正确率；不同 embedding 模型、版本、归一化方法和任务领域的向量不应未经验证直接混排。向量中可能泄漏敏感信息，存储与使用也需按权限管理。

## 2. 形象理解

像把每段文字放进一个多维地图，‘退款到账’和‘退款完成时间’可能比‘天气’更近。

**类比的局限：**地图邻近只表示模型认为意义相似，不保证两段文字是同一事实或同一客户的资料。

## 3. 技术原理与核心内容

编码器产生 `e(x) ∈ R^d`，常用余弦相似度 `cos(u,v)=u·v/(||u||||v||)`，只有同一模型空间下的向量比较才有可解释一致性。在线时对 query 编码、近邻检索并过滤 ACL；索引重建或更换模型时应识别 embedding_model_version、dimension 与向量归一化策略。对准确 ID、数字和否定词，单靠语义向量通常不足。

## 4. 工程实践与设计权衡

**工程案例：**技术支持 Agent 将‘订单取消失败’检索到‘撤销购买未成功’相关知识条目，但需要用订单号/用户权限二次过滤，避免把另一用户的真实订单响应给当前请求。

**失败模式与验证：**模型升级导致分布漂移、混合不同维度索引、数字/否定词的语义失真、向量库无权限过滤造成泄露。用同一查询集比较 recall@k、延迟、误匹配类别和跨语种性能。

## 5. 关联知识与易混辨析

Embedding 是数据表示；Vector Search 使用表示执行近邻召回；Vector Database 管理向量与索引；Semantic Search 侧重自然语言意图/意义匹配，可能采用 embedding 但不必只靠它。

## 6. 中等难度面试题（含参考答案）

1. **问：cosine similarity=0.9 是否能理解为 90% 正确率？** 答：不能。它是向量几何关系分数，未经独立标注与校准不能当概率或正确率。
2. **问：更换 embedding 模型后为什么可能需要重建索引？** 答：新旧空间、维度和向量统计不同，直接比较可能失效；需按模型版本迁移并做召回评测。

## 7. 中等难度考试题（含解析）

1. **题：向量 u=(1,0)、v=(0,1)，二者余弦相似度是多少？** 解：点积为 0，范数均为 1，cos=0，表示在二维空间正交。
2. **题：模型 A 输出 768 维、B 输出 1024 维，是否可以直接计算它们的欧氏距离？** 解：不能直接对不同维度向量计算标准距离，需在兼容空间中重新编码或明确映射。
