# Structured Logging（结构化日志）

> AI Agents · 专题：工程化、成本与可观测性 · 运行时观测、性能和可核验业务结果

## 1. 核心定义

**Structured Logging（结构化日志）**：结构化日志把日志事件按稳定字段与类型输出为 JSON 等可机器解析的记录，便于聚合、检索和关联 Agent 的模型、工具与业务步骤。字段的可解析性不自动保证真实性和访问授权。

**关键边界：**统计、记录和推导应围绕具体组件、时间窗口、资源范围与数据来源展开。对同一指标，模型级、工具级和端到端任务级的计数范围不同；不能把某个厂商的指标名或日志约定误作所有框架的标准。指标异常不必然表示恶意攻击，正常值也不保证业务目标已成功。

## 2. 形象理解

**类比：**像机场行李标签统一记录航班号、目的地和行李 ID，机器便能分拣。

**类比的局限：**标签被伪造或贴错仍会误导；JSON 合法不代表数据可信，也不能随意放入私人信息。 Agent 还涉及异步执行、不可逆副作用和跨组件故障，必须回到真实时间线及权威状态核验。

## 3. 技术原理与核心内容

推荐字段 event_name、timestamp、trace_id、task_id、tool_name、attempt、duration_ms、status、error_code。为动态用户输入做转义与长度上限；字段值保留类型，比如 429 是 status_code 的数值，不把异常对象直接序列化。用 schema version 管理变更，避免依赖自由文本的 regex 去提取重要指标。

**工程不变量。**模型生成“完成”不等于业务系统提交成功。任务级事件需要和权威后置状态、幂等请求号以及租户范围关联；统计前必须声明计量单位、时间范围、分母与抽样方式。低信任外部内容不可作为系统配置指令，日志/指标不得存放明文凭据。并发执行的时间线应遵循真实因果关系而非简单求和。

**数据路径。**入口生成任务/追踪上下文，模型与工具分别输出带时间和状态的事件；记录系统可作采样、聚合与索引。对失败重试需标注逻辑任务与单次尝试的区别。对隐私敏感字段做 allowlist 和脱敏；对于来源不可信的数据保留标记，不允许它重新定义权限和用户目标。

## 4. 工程实践与设计权衡

**真实工程类型的案例：**浏览器 Agent 的 JSON 日志显示 `tool=payment`, `attempt=2`, `status=timeout`。日志消费者按幂等键找到第一次 attempt 并查真实付款状态，不把“超时”当作失败事实。

**测试与排障。**为每个概念构造正常、超时、重试、并发、队列积压和返回成功但业务未落库的场景，检查模型建议、实际工具请求、权限判定、后端结果及观测信号是否一致。建立固定数据集与时间窗，独立复算计算题；对于采样数据说明不确定性。可观测性增强有日志/指标存储成本和敏感数据面扩大等代价，应基于服务级别目标和故障价值进行最小化采集。

**权衡。**准确定位问题需要信号足够丰富，但全量记录模型输入可能暴露隐私，过多高基数标签会提高成本。对高影响操作保留必要审计，普通可观测数据按合理抽样、保留与访问策略处理。一个工具返回 200 不意味着整个 Agent 任务成功；必须检查业务层结果。

## 5. 关联知识与易混辨析

Structured Logging 是日志的编码与语义组织；Trace Context 是跨组件传播的关联信息。结构化日志不替代业务 Audit Trail，后者可能要求防篡改和更长期保留。

需要区分事件、持续时间、聚合率与因果关系这四类信息。构建跨术语查询时应从任务目标→服务行为→运行数据→业务后置条件逐级定位，不可只因为名称相近就混用指标或用 tracing ID 充当权限凭证。

## 6. 中等难度面试题（含参考答案）

1. **问：如何从自由文本日志迁移到结构化日志而不破坏旧查询？** 答：定义版本化 schema、明确必需/可选字段、双写过渡并观察解析失败率；保持稳定事件名称。
2. **问：字段中有用户提供的换行和引号，如何避免日志注入？** 答：使用成熟 JSON 序列化而非字符串拼接，对长度、控制字符和敏感字段做约束，并保持来源可信度。

优秀回答不仅提出技术机制，还应指出适用范围、失败模式、用户感知结果和能在生产上观察到的验证信号。

## 7. 中等难度考试题（含解析）

1. **题：50,000 条 JSON 日志中 250 条缺少必需 task_id，字段完整率？** 解：完整数 49,750；完整率 49,750/50,000=99.5%。 **计算口径：**数据、单位和边界均由题设给出；若非随机抽样或存在遗漏，不得外推为真实系统质量。
2. **题：日志中 `duration_ms` 从整数变成字符串会影响什么？** 解：数值聚合、排序和阈值可能错误，应校验 schema version，禁止静默类型漂移。 **评分重点：**原理、推导步骤、关键反例与可操作的验收方式，而非单句术语记忆。
