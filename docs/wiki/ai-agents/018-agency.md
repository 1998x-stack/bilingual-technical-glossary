# Agency（能动性）

> AI Agents · 专题：基础概念与角色 · 适用范围：通用智能体系统设计；具体 SDK 与平台版本以对应文档为准

## 1. 核心定义

**Agency（能动性）**：Agency 是一个系统根据目标与环境信息进行选择、发起行动并产生外部影响的能力或能动性；在 AI 工程中更适合按可观察行为定义，而非推断模型有意识。

**适用边界：**哲学和社会科学中的 agency 含义不同；AI Agent 语境下应避免把其拟人化为独立意愿。

## 2. 形象理解

像受托办理事务的代办员：在授权范围内能作出若干选择并采取行动。

**类比的局限：**代办人有法律身份和责任归属，模型没有因此获得人格、主观体验或独立的法定授权。

## 3. 技术原理与核心内容

可用目标选择权、动作集合、行动影响范围、观察反馈与可中止性描述操作上的能动性。实现时以动作策略和工具许可定义边界，确保人类可审计、可停机。

## 4. 工程实践与设计权衡

网络运维 Agent 可读监控、选择诊断命令并提出重启建议，但是否执行生产重启应由明确授权和门控控制；判断依据是实际可执行操作而非模型自述。

## 5. 关联知识与易混辨析

Agency 强调作出选择并产生影响；Autonomy 强调过程中无需人工干预的程度。有能动性的系统也可能每次写入前都需人工批准。

## 6. 中等难度面试题（含参考答案）

1. **问：能否从 Agent 自称“我想这样做”证明其有意识？** 答：不能；工程中的 agency 是行为性概念，自然语言拟人表述不足以证明主观体验。
2. **问：为什么应把 Agency 与责任划分分开？** 答：实际责任在运营者、开发者及授权主体的治理体系，技术系统的动作能力不自动产生法律主体资格。

## 7. 中等难度考试题（含解析）

1. **题：智能体能从三个只读诊断工具中自主选一个，但重启必须审批，能否说具有操作性 Agency？** 解：能；它有选择并影响信息获取路径的能力，敏感动作受权限约束。
2. **题：比较能力范围相同但必须逐步人工指挥的系统与可自行选择步骤的系统。** 解：二者 Capability 可相同；后者通常 Autonomy 更高。Agency 需进一步看是否真实能选择和执行动作。
