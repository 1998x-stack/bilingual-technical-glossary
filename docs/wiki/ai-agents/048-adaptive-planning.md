# Adaptive Planning（自适应规划）

> 适用领域：AI Agents · 专题：任务规划与决策 · 相关理论与具体产品能力应依据所引来源和版本区分

## 1. 核心定义

**Adaptive Planning（自适应规划）**：Adaptive Planning（自适应规划）指智能体在执行过程中利用最新观测、约束变化和行动结果更新后续路线，而不是一开始生成计划就不再调整。它特别适合工具结果不可预测的开放环境。

**适用边界：**自适应不意味着每一步都需要完全重新规划；只在新信息实质影响可行性、风险或效用时修订可以减少波动。

## 2. 形象理解

像导航遇到封路后修改接下来的路线，而已经走过的街道不会因此倒退。

**类比的局限：**频繁改路线可能让系统原地绕圈；导航也必须遵守交通规则和目的地限制。

## 3. 技术原理与核心内容

循环为 `observe s_t → check current_plan.preconditions → choose continue/local_repair/replan/stop → execute → verify`。可追踪剩余计划可行性与预算，保持用户目标和权限不变量。未知副作用需先查询执行记录，不能把重新规划理解为重新执行所有动作。

## 4. 工程实践与设计权衡

**工程案例：**销售 Agent 询价过程中发现供应商缺货，保留已核实的其他报价，仅为缺货节点选择新供应商并调整交付时间。让采购负责人核对上限后才提交新订单。

**失败模式与验证：**如果模型每见到新文档就重写全计划，会导致上下文漂移、重复任务和无限循环。记录版本差异、触发原因和最后有效计划，设置重规划次数上限。

## 5. 关联知识与易混辨析

Adaptive Planning 是对动态信息持续做决策的能力；Plan Revision 是某次对既有计划的具体修改；Replanning 通常指重新生成有效计划，可作为自适应的一种实现。

## 6. 中等难度面试题（含参考答案）

1. **问：何时适合局部调整而不是全量重规划？** 答：只有某一动作前置条件失效且其他已验收成果不受影响时，局部替换成本低；若目标与约束系统性变化才重做高层计划。
2. **问：重规划时如何避免重复付款？** 答：将已执行副作用与业务事务 ID 固化到外部状态，重规划只操作未完成节点，检查幂等与是否需要补偿。

## 7. 中等难度考试题（含解析）

1. **题：初始路线还需 10 min，突发封路后当前路线预计 17 min；替代路线需 12 min，重新规划开销 1 min。按时间最小应否重规划？** 解：替代路线端到端 1+12=13 min，低于继续原路线 17 min，因此按仅耗时目标应改道；安全权限仍需满足。
2. **题：任务 A 已支付成功，B 缺货，能否重新跑 A+B？** 解：不能无条件重新支付 A；保留 A 的已确认状态与请求 ID，仅针对 B 调整，必要时执行经批准的退款/补偿流程。
