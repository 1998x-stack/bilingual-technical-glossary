# SMOTE（合成少数类过采样技术）

> 领域：机器学习 · 专题：数据预处理与特征工程 · 定义、原理、数学与真实工程边界

## 1. 核心定义

SMOTE（Synthetic Minority Over-sampling Technique）是少数类过采样算法：在特征空间选取某少数类样本与其少数类邻居，按线性插值合成新样本。它不等于真实收集数据，尤其不保证离散/结构化特征或跨群体数据插值具有实际业务意义。

## 2. 形象理解

像在少数类两个相近点之间取中间点，补充模型见到的局部区域，而不是简单复制一个原点。

**类比的局限：**两条合法病历之间的数值中间值不一定是一位合法患者；不同医院或时间窗的样本不能随便混插。

## 3. 技术原理与核心内容

经典 SMOTE 对少数类 x_i 及其少数邻居 x_nn 构造 x_new=x_i+λ(x_nn−x_i)，其中 λ∈[0,1]。k_neighbors 控制邻域，少数样本少于 k+1 时需调整；欧氏距离受尺度与特征类型影响。包含类别变量时需考虑 SMOTENC/SMOTEN；必须放在交叉验证每个训练折内部执行，绝不可先全库 SMOTE 后再切分。

## 4. 工程实践与设计权衡

恶意交易检测只有 2% 正类，可在用户级切分训练集后采用 SMOTE 与类权重做对照；检测新合成数据是否违反金额非负、整数计数、类别共现约束，同时在自然先验测试集看误报成本。

## 5. 关联知识与易混辨析

SMOTE 是合成插值过采样，RandomOverSampler 是复制样本，Class Weight 不生成新数据。ADASYN 倾向强调某些难学区域，可能放大噪声；方法需按业务验证。

## 6. 中等难度面试题（含参考答案）

1. **问：为什么 SMOTE 应在分折之后执行？** 答：如果先对全数据生成合成样本，验证折可能出现与训练折高度近邻或源自验证点的合成信息，从而抬高离线指标。

2. **问：为什么 SMOTE 不适合直接对任意 one-hot 与交易 ID 插值？** 答：插值可能生成 0.4 类别、非整数 ID 或跨业务约束的伪样本；应使用支持类别结构的方法或其他学习策略。

## 7. 中等难度考试题（含解析）

1. **题：x_i=(2,4)、x_nn=(6,8)，λ=0.25，SMOTE 合成点？** 解：(2,4)+0.25×(4,4)=(3,5)，在两个少数类点连线上。

2. **题：若训练少数类 100 条，目标将其扩充至 250 条，需要合成多少条？** 解：250−100=150 条；测试集仍保留原有类别比例，合成数不等于新独立采集的真实样本。
