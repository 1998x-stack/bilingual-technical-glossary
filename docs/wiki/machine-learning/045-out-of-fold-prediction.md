# Out-of-fold Prediction (OOF)（折外预测 · OOF）

> 适用领域：机器学习 · 专题：数据、样本与数据集划分 · 可信验证、偏差与防泄漏

## 1. 核心定义

折外预测（OOF）是交叉验证时让每个训练样本由未在该样本上拟合的折模型预测得到的结果。常用于生成训练级 meta 特征、诊断误差或计算整体评分，但不能自动替代最终测试集。

## 2. 形象理解

像让每个学生被一位从未参与教自己训练的老师评分，而不是用背过的答案自评。

**类比局限：**OOF 不保证所有折完全统计独立：各折的训练集大量重叠，而且若预处理先看全量数据仍可能泄漏。

## 3. 技术原理与核心内容

对第 k 折，在 D\F_k 拟合 f_k，并为 F_k 生成 p_i=f_k(x_i)。完整 OOF 预测与原训练行一一对齐。Stacking 时第二层模型应使用这些 OOF 作为训练特征；如果用基模型对自身训练样本的 in-sample 预测训练第二层，会发生严重过拟合。cross_val_predict 的整体度量仅在恰当可加性条件下能直接与逐折评分均值对应。

## 4. 工程实践与设计权衡

营销模型堆叠两种分类器：按同一分折生成各自的概率 OOF，再拟合 meta 模型；最终测试时应由仅使用训练部分拟合的基模型对测试集提供概率，避免用测试标签参与融合。

## 5. 关联知识与易混辨析

OOF 是训练数据上的折外产物；Holdout 是隔离子集；外部 Test Set 没参与调参。OOF 不等于完全独立的外部测试预测。

## 6. 中等难度面试题（含参考答案）

1. **问：Stacking 为何必须采用 OOF 构造二层特征？** 答：若基模型对自身训练样本评分，二层会学到基模型过度乐观的分数结构。OOF 至少避免每行对应的基模型直接训练过该行。

2. **问：为什么各折预测概率列必须按类别对齐？** 答：某折缺少类别时 predict_proba 输出维度或顺序可能不同；构造 OOF 矩阵需使用统一 classes 和一致标签编码。

## 7. 中等难度考试题（含解析）

1. **题：100 条样本做 5 折，每折验证 20 条，完整 OOF 预测有几条？** 解：100 条；每条由该行未参与训练的一个折模型预测（单轮 KFold）。

2. **题：某样本 in-sample 预测概率 0.99、OOF 概率 0.60，应该把哪个作为训练 meta 模型的特征？** 解：使用 0.60 的 OOF 值，避免直接复用该样本在基模型训练期间的过拟合预测；仍需整体流程无泄漏。
