# Min–Max Scaling（最小最大缩放）

> 领域：机器学习 · 专题：数据预处理与特征工程 · 数理解释和工程实用边界

## 1. 核心定义

最小最大缩放用训练集特征最小值与最大值构造仿射映射，常将训练范围映射到 [0,1]。它保持次序与相对线性间距，对极值和分布漂移敏感，测试样本可以超出目标区间。

## 2. 形象理解

把最小考试分数画在尺子 0 处，最大分数画在尺子 1 处，其余分数按线性位置缩放。

**类比的局限：**新考试分数可超过原最大值；其变换不必落在 0 到 1 之间。

## 3. 技术原理与核心内容

目标区间 [a,b] 时，x'=a+(x−xmin_train)/(xmax_train−xmin_train)×(b−a)。常数列须做安全处理；MinMaxScaler 的 clip=True 会截断范围外样本，但损失极端变化信息。绝不能将验证/测试极值用于 fit；对后续极值扩展应采取监控与版本化方案。

## 4. 工程实践与设计权衡

电压模型可用固定物理上下限或训练极值作缩放，输入越界应检查是否硬件更新、单位错误或真实异常，而非无声改写整个模型映射。

## 5. 关联知识与易混辨析

它不提供均值 0 或标准差 1；StandardScaler、RobustScaler 在不同分布下有不同性质。

## 6. 中等难度面试题（含参考答案）

1. **问：为什么要仅在训练集 fit MinMaxScaler？** 答：使用测试最小最大值会把未来分布信息带进训练特征尺度，破坏评估隔离。

2. **问：为什么 clip 不是处理漂移的完整方案？** 答：多个超界值被压到同一端点，丢失大小信息并可能遮蔽故障；应监测超界比例和分布原因。

## 7. 中等难度考试题（含解析）

1. **题：训练最小 10 最大 30，x=25 到 [0,1] 的结果？** 解：(25−10)/20=0.75。

2. **题：沿用上述训练极值，测试 x=40 输出多少？** 解：(40−10)/20=1.5；不开启 clip 时大于 1 是合法结果。
