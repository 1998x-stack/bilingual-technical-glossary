# Model Complexity（模型复杂度）

> 领域：机器学习 · 专题：统计学习与泛化理论 · 推导、理论前提与工程设计

## 1. 核心定义

模型复杂度是对预测器可表达函数丰富程度、结构大小或描述长度的度量族，而非单一且普适的数字。参数个数、树深、非零特征数、假设类 VC 维、范数约束和最小描述长度均可刻画不同方面；计算开销不是统计复杂度的严格同义词。

## 2. 形象理解

像比较两台机器：零件总数是一个维度，能完成多少操作是另一个维度，耗电量又是第三个维度；无法只看一个数决定所有表现。

**类比的局限：**拥有较多参数的受强约束模型可能比参数较少却可任意记忆输入的模型泛化更好；复杂度与泛化关系依赖数据和学习算法。

## 3. 技术原理与核心内容

统计模型选择可用 AIC=2k−2ln(L̂) 或 BIC=k ln n−2ln(L̂)，其中 k 是参数数量、n 为样本数、L̂ 为最大似然（满足相应统计前提）；这些不是任意深度神经网络的通用泛化保证。结构学习理论常使用增长函数、VC 维、Rademacher 复杂度等，更贴近函数类的可拟合行为。需要明确损失、编码参数、约束和有效独立样本数。

## 4. 工程实践与设计权衡

比较营销回归中的 5 项与 50 项交互模型时同时看独立时间测试风险、推理延迟与特征维护成本。若使用 AIC/BIC，核对观测独立性、似然模型及参数自由度而不是直接套任意指标。

## 5. 关联知识与易混辨析

Model Complexity 是模型或假设类的多面属性；Capacity 是可拟合函数类丰富程度；VC Dimension 衡量分类假设类的打散能力；Regularization 是限制有效复杂度的手段之一。

## 6. 中等难度面试题（含参考答案）

1. **问：为什么不能仅以神经网络参数数目证明它一定过拟合？** 答：函数约束、训练路径、数据增强、参数共享和优化隐式偏好都会影响实际有效复杂度；参数数量不等于最终泛化误差。

2. **问：AIC、BIC 可直接替代独立测试集吗？** 答：不能；它们基于特定概率建模与渐近条件，有任务边界。跨时间、机构分布偏移仍需独立评估。

## 7. 中等难度考试题（含解析）

1. **题：同一数据上模型 A：k=2、ln L̂=−20；模型 B：k=5、ln L̂=−18。AIC 各是多少？** 解：AIC_A=2×2−2×(−20)=44；AIC_B=2×5−2×(−18)=46，按 AIC 选 A。

2. **题：树深为 3 的满二叉树最多有多少叶节点？** 解：若根深度为 0 且每内部节点分为两个子节点，最多 2³=8 片叶子；叶数仅是特定结构复杂度指标。
