# Target / Label（目标变量／标签）

> 适用领域：机器学习 · 专题：数据、样本与数据集划分 · 统计单位、采集与数据协议

## 1. 核心定义

目标变量／标签是预测任务希望估计的输出，可以是类别、连续响应、排序偏好或结构化对象。目标应具有明确的定义、观察窗口、采集方式和噪声边界。

## 2. 形象理解

像射箭靶心：你必须先规定要瞄准“明日是否违约”，不能训练到一半改成“本月是否违约”。

**类比局限：**标签有噪声或定义模糊时，模型学到的是标注流程的规律，不一定是外部真实状态。

## 3. 技术原理与核心内容

训练集记作 (x_i,y_i)。分类 y_i∈{0,…,K−1}，回归 y_i∈R；常以条件概率 p(y|x) 或期望 E[Y|X=x] 建模。创建标签需要指定判定规则、成熟窗口、删失处理、标注置信度和时点对齐；不能把尚未成熟的负例当真实负例。

## 4. 工程实践与设计权衡

预测 30 天内是否发生退货，应只将观察满 30 天的订单标注为最终负例，或采用适当删失建模；线上风险阈值需要与业务处置成本相匹配。

## 5. 关联知识与易混辨析

Target 是建模目标的变量，Label 常指每条样本的观测目标值；Ground Truth 是作为评价参考的权威值，可能并非无误。

## 6. 中等难度面试题（含参考答案）

1. **问：为什么正类定义一旦改变必须重训或至少复测？** 答：标签含义改变就是目标分布与损失目标改变，旧模型概率不再对应新事件。应版本化标签规则并独立评估。

2. **问：有 7 天延迟标签的数据，如何避免把近 7 天全部当负样本？** 答：以已成熟时间窗口构造训练集，未成熟样本保持未知或使用生存分析/延迟反馈模型，记录回填机制。

## 7. 中等难度考试题（含解析）

1. **题：标签为 [1,0,1,1,0]，正类比例多少？** 解：正类 3 条，共 5 条，比例 3/5=60%。这只是数据集先验，不必等于目标总体先验。

2. **题：真实连续目标 [2,4]，预测 [3,6]，MAE 是多少？** 解：绝对误差 [1,2]，平均 (1+2)/2=1.5 单位；标签若有噪声还需分离测量误差。
