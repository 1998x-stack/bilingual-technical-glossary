# Ground Truth（真实标注／参考真值）

> 适用领域：机器学习 · 专题：数据、样本与数据集划分 · 统计单位、采集与数据协议

## 1. 核心定义

真实标注／参考真值（Ground Truth）是训练或评测时采用的可信参考结果，可能来自专家共识、独立仪器、人工审查或有审计记录的业务事件。它是操作性标准，不天然等于绝对事实。

## 2. 形象理解

像考试的标准答案：必须有出题依据、阅卷准则与争议处理机制。

**类比局限：**不同专家可能对含糊病例意见不同；把多数投票当真理会隐藏系统偏差。

## 3. 技术原理与核心内容

参考标签生成可通过多标注者复核、仲裁和黄金样本；分类标签可计算一致性（如 Cohen's κ），连续标签可比较误差或一致性区间。数据标注协议需明确版本和证据来源；评估模型时也要估算参考标签误差带来的性能上界或不确定性。

## 4. 工程实践与设计权衡

病理影像金标准可由多名病理医生及更高级检测综合建立。对难例保留意见分歧与审计轨迹，不宜只保留单个绝对标签。

## 5. 关联知识与易混辨析

Label 是存入样本的目标值；Ground Truth 是对其可信性的评价地位。高质量参考可有噪声，训练标签可以是弱监督且不适合作独立金标准。

## 6. 中等难度面试题（含参考答案）

1. **问：为何多位专家投票一致也不必然保证标签可靠？** 答：专家可能共享同一信息缺口或系统偏差。应评估标注指南、盲审、仲裁和独立验证来源。

2. **问：如何处理参考真值存在争议的样本？** 答：保留原始多标注者结果、置信度与争议原因，按应用代价决定排除、软标签或专门的人工复核通道。

## 7. 中等难度考试题（含解析）

1. **题：两位评估者对 100 项中有 90 项一致，观察一致率是多少？** 解：90/100=90%；它不是 κ，需要还知道类别边际概率的偶然一致率。

2. **题：若观察一致率 p_o=0.9，偶然一致率 p_e=0.6，计算 Cohen's κ。** 解：κ=(p_o−p_e)/(1−p_e)=(0.9−0.6)/0.4=0.75，表示超出偶然的协议一致性，不等于标签真实率。
