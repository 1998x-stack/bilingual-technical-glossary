# Zero-shot Learning（零样本学习）

> 适用领域：机器学习 · 专题：基础概念与学习范式 · 算法机制与适用边界

## 1. 核心定义

零样本学习要求模型在目标类别没有带标签训练示例的情况下，借助类别名称、文字描述、属性或预训练的跨模态语义知识执行识别。它不是“从未见过任何相关训练数据”，而是未见目标类别的直接监督示例。

## 2. 形象理解

像未见过独角兽照片，但凭“有角、像马”的文字描述从图像中寻找最相符对象。

**类比局限：**语义描述不精确或含歧义时，模型可能依赖表面共现而非真正理解新类别。

## 3. 技术原理与核心内容

常见方法将图像编码成 z_x，将类别文本说明编码成 z_c，计算相似度 sim(z_x,z_c) 并选择最高分；可做带温度的 softmax 形成候选集条件概率。训练往往已用大规模图文配对，且 zero-shot 评价必须排除目标基准类别的直接训练标注泄漏。类描述质量、类先验和候选类别集合会改变结果。

## 4. 工程实践与设计权衡

图像审核希望临时增加新标签，可先在固定描述集上做 zero-shot 初筛，再按误判成本引入少量人工标注。应检查不同提示措辞的敏感度和开放集未知类别拒识。

## 5. 关联知识与易混辨析

zero-shot 不提供目标类别的标注样本；few-shot 给每类少量支持示例。领域自适应可有无标注目标数据，并不等价于零样本识别。

## 6. 中等难度面试题（含参考答案）

1. **问：为何不能把零样本高准确率理解为没学过相关知识？** 答：预训练可能包含类别名称、文本描述和同义表述；“零”只针对目标评测协议中的标注支持样本。应核对预训练数据与测试集污染可能。

2. **问：为什么改变候选标签清单会改变 zero-shot 预测？** 答：模型通常在候选描述间比较相似度，新增相近类会改变最高分与归一化概率，甚至同一图像的预测。应固定模板与候选集进行可复现评估。

## 7. 中等难度考试题（含解析）

1. **题：图像与三类文字的相似度分别为 0.8、0.5、0.6，按最大余弦相似度分类应选择哪类？** 解：选第 1 类，因 0.8 最大。前提是各向量已归一化且使用相同编码器。

2. **题：两个候选类别温度缩放后的 logits 为 2 和 1，按 softmax 计算第一类概率。** 解：e²/(e²+e¹)=1/(1+e^−1)≈0.731。该概率只针对给定候选集，未必已经校准。
