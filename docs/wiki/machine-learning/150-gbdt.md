# GBDT（梯度提升决策树）

> 领域：机器学习 · 专题：树模型与集成学习 · 理论、数学与工业决策

## 1. 核心定义

梯度提升决策树（GBDT，Gradient Boosted Decision Trees）是使用回归树作为基学习器的梯度提升实现，通过串行拟合当前损失的负梯度/相应叶值增量，累加多棵树形成非线性预测。它适用于高质量结构化表格数据，但需控制树的容量、轮数、学习率与泄漏风险。

## 2. 形象理解

像先用一棵简单树做粗略判断，再让下一棵树学习前一轮没解释好的样本规律，连续多轮把修正叠加到最终预测。

**类比的局限：**GBDT 与随机森林不是相同训练方法：前者每轮依赖先前模型，后者通常并行训练多棵随机树再平均；树越多不保证测试更好。

## 3. 技术原理与核心内容

模型形式 F_M(x)=F_0(x)+νΣ_{m=1}^M γ_m h_m(x)，h_m 为相对较浅的回归树。每一轮计算伪残差 r_im=−∂L(y_i,F)/∂F|_{F=F_{m−1}(x_i)}，拟合树的分裂与叶响应并更新集成；分类任务常在 logit 空间累加后经 sigmoid/softmax 转概率。`GradientBoostingClassifier` 与 `HistGradientBoostingClassifier` 均属于此家族，但后者先分箱并可支持原生缺失值和类别特征，具体性能、API 和默认参数依版本而异。

## 4. 工程实践与设计权衡

反欺诈模型可比较 sklearn GBDT、Histogram GBDT 与 RandomForest，在用户时间分割下调叶数量、树深、学习率、轮次和 early stopping；监控类别变化、缺失值走向、推理 P95 延迟与模型校准。

## 5. 关联知识与易混辨析

GBDT 是 Gradient Boosting 以树为弱模型的特化；XGBoost、LightGBM、CatBoost 提供各自工程实现与优化，并非与 sklearn GBDT 算法/超参严格等价；Random Forest 采用聚合而非串行修正。

## 6. 中等难度面试题（含参考答案）

1. **问：为何 GBDT 的新一棵树通常要拟合伪残差而不是重新拟合原 y？** 答：当前模型已解释部分信号，新树应沿损失负梯度方向补充剩余误差；直接每轮拟合原 y 无法对应阶段式函数下降。

2. **问：为什么学习率变小往往需要更多树？** 答：每轮对预测函数的增量被缩小，需要更长加性路径才能达到相近训练拟合；这不是保证泛化改善的数学定理。

## 7. 中等难度考试题（含解析）

1. **题：初始预测 F0=10，两个弱树在某点输出 2、−1，学习率 ν=0.1、每轮 γ=1，最终 F2 是多少？** 解：F2=10+0.1×2+0.1×(−1)=10.1。

2. **题：平方半损失下真实 y=7、当前预测 F=4，GBDT 此点的负梯度是多少？** 解：r=y−F=3；具体树的叶输出还取决于同叶其他样本与优化规则。
