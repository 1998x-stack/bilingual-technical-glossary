# Multi-task Learning（多任务学习）

> 适用领域：机器学习 · 专题：基础概念与学习范式 · 数理机制与应用边界

## 1. 核心定义

多任务学习联合优化两个或多个相关预测任务，让模型共享参数或表征以利用任务间互补信息。共享能形成正向归纳迁移，但不相关的任务可能导致梯度冲突和负迁移。

## 2. 形象理解

像医学团队共同学习心率、血压与住院风险的基础规律，同时为各项决策保留独立专家。

**类比局限：**共享并不总是有益；任务目标冲突时强制共享会损害某一任务。

## 3. 技术原理与核心内容

常用共享编码器 h=g_θ(x) 配各任务头 ŷ_t=f_{φ_t}(h)，总目标 L=Σ_t λ_t L_t。任务损失尺度、标签缺失模式与抽样频率必须处理；可选硬共享、软共享、梯度投影或动态损失加权。任务拆分后的数据协议必须防止同一实体跨训练与验证泄漏。

## 4. 工程实践与设计权衡

搜索平台联合学习点击概率与停留时长。点击标签密集、时长稀疏时需考虑缺失机制和尺度；监控各任务独立指标，不能只以总损失下降确认有效。

## 5. 关联知识与易混辨析

多任务学习同时训练多个目标；迁移学习常先学源再适配目标；多输出模型不一定包含有效的共享归纳迁移。

## 6. 中等难度面试题（含参考答案）

1. **问：为何训练损失都下降，业务关键任务仍可能变差？** 答：优化目标权重、分布与线上效用不一致，某一任务可能被辅助任务主导。应做单任务基线、梯度相似度分析和每任务独立验证。

2. **问：如何处理辅助任务标签缺失？** 答：使用任务掩码仅在有标签样本上计算对应损失，并按有效样本规模校正权重；不能将缺失标签硬编码为负类。

## 7. 中等难度考试题（含解析）

1. **题：两任务损失 L1=0.3、L2=1.2，权重 λ1=2、λ2=0.5，求总损失。** 解：L=2×0.3+0.5×1.2=1.2。权重反映训练设计，不保证两任务效用等价。

2. **题：共享编码器 100 万参数，两头各 10 万参数，联合模型总参数多少？相比分别建两个独立 110 万参数模型节省多少？** 解：联合 100+10+10=120 万；两个独立模型 220 万，节省 100 万（约 45.5%）。节省参数不等于无额外任务代价。
