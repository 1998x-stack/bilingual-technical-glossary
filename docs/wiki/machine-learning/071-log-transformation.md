# Log Transformation（对数变换）

> 领域：机器学习 · 专题：数据预处理与特征工程 · 数理原理、适用条件与生产风险

## 1. 核心定义

对数变换将正值或经定义平移后的非负数映射到对数尺度，用于压缩较大的数值动态范围、缓和右偏长尾并将某些乘法关系转为加法关系。它不是自动“正态化”，且原始非正值需要明确约定。

## 2. 形象理解

收入从 1000 增长到 2000 与从 10000 增长到 20000 在对数尺度上有同样的倍数增量。

**类比的局限：**对数尺度强调相对变化，可能弱化业务需要关注的绝对金额差异；负数和零不能直接取自然对数。

## 3. 技术原理与核心内容

对 x>0 定义 z=ln x；对于非负 x 常取 ln(1+x)，但 +1 的单位和基准必须有语义（计数特征最自然）。ln(ab)=ln a+ln b，可将乘法效应线性化；若把 log(y) 当回归目标，逆变换 exp(ŷ) 对应对数中心，不自动给出原尺度条件均值，需考虑 Jensen 偏差和误差分布。

## 4. 工程实践与设计权衡

电商交易额跨度数个数量级时可考虑 log1p 变换，使线性模型不被少数大额主导；同时按金额区间报告原尺度误差，防止掩盖高额订单业务成本。

## 5. 关联知识与易混辨析

LogTransformation 是单调非线性压缩；StandardScaler 为仿射尺度变换；Box–Cox 在正值域提供可调的幂变换，λ→0 时趋向对数。

## 6. 中等难度面试题（含参考答案）

1. **问：为什么把预测 log(y) 后简单 exp 回去可能低估原尺度均值？** 答：指数是凸函数，E[exp(Z)]≥exp(E[Z])；对数条件均值的指数不必等于 y 的条件均值，需要误差分布或校正因子。

2. **问：什么时候 log1p 比 ln(x) 更合适？** 答：非负计数或金额包含 0 时，ln(1+x) 有定义且小值数值稳定；负值需重新审视字段语义，不能盲目平移。

## 7. 中等难度考试题（含解析）

1. **题：x=9，使用 ln(1+x) 的变换结果？** 解：ln(10)≈2.3026。

2. **题：x 从 5 变到 10，若用 ln x，差是多少？** 解：ln10−ln5=ln2≈0.6931，倍数翻倍产生固定对数差。
