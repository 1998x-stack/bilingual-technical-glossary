# Holdout Set（留出集）

> 适用领域：机器学习 · 专题：数据、样本与数据集划分 · 验证协议与模型选择

## 1. 核心定义

留出集是从指定拟合过程排除的一批样本，用于验证、选择或最终评估。‘留出’描述数据分割角色而不是自动授予绝对独立性，须声明它究竟是开发集还是锁定测试集。

## 2. 形象理解

像为试验保留一批未使用材料，至于是用于试配方还是最终验收，取决于实验规程。

**类比局限：**只是从原数据随机留 20%，无法阻止同用户重复、未来信息或非代表性抽样。

## 3. 技术原理与核心内容

常见 holdout 按预定比例划分 I_train 与 I_holdout，二者索引不重叠；如按业务实体分组，还需 group_train∩group_holdout=∅。可以进行一次训练/留出评估，但估计方差较高；交叉验证通过多折复用开发数据降低对某次切分的敏感度。

## 4. 工程实践与设计权衡

设备预测模型保留某一批设备作为全新设备 holdout；若换成同设备晚期样本，则评估的问题变成未来预测。选择切分策略要先写目标场景，不以分数最高为原则。

## 5. 关联知识与易混辨析

Holdout 是分割概念；Validation 与 Test 是用途角色。留出集用于反复调参时只能称验证，不能事后改称未经使用的测试集。

## 6. 中等难度面试题（含参考答案）

1. **问：数据量很小时留出法与交叉验证如何选择？** 答：留出法操作简单但估计依赖某次划分，CV 可用于开发选型；最终独立评估仍宜保留业务适配的测试数据。

2. **问：为什么 holdout 不能盲目采用随机切分？** 答：若同一用户或同一生产批次高度相关，就会高估泛化；预测未来任务则应顺序留出后续时期。

## 7. 中等难度考试题（含解析）

1. **题：500 个独立样本留出 20%，训练和留出各多少？** 解：留出 100，训练 400，前提是行样本近似独立且能按比例划分。

2. **题：200 个患者每人 3 次访问，患者级保留 40 位作 holdout，留出访问记录有多少？** 解：40×3=120 条，训练 160 位患者对应 480 条。按患者划分能防止同患者跨集，但不能自动防止时间泄漏。
