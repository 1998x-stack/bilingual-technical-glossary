# Target Vector (y)（目标向量）

> 适用领域：机器学习 · 专题：数据、样本与数据集划分 · 统计单位、采集与数据协议

## 1. 核心定义

目标向量 y 是与特征矩阵 X 行一一对应的学习目标序列；单输出回归常为实值向量，单标签分类为离散编码向量。若为多输出任务，目标可能是二维矩阵而非单个向量。

## 2. 形象理解

像点名册每位学生对应一条分数记录，错位以后题目和答案就配不上。

**类比局限：**y 有时表示类别编号、连续实数、概率或时间序列，不能见到数字就将其视作连续回归目标。

## 3. 技术原理与核心内容

对于 n 个样本，单输出 y∈R^n 或离散集合^n；训练损失 L=1/n Σℓ(f(x_i), y_i)。数组拼接、采样与分折都必须同步变换 X 和 y，尤其避免 pandas 对齐或 NumPy 原地打乱导致样本错配。

## 4. 工程实践与设计权衡

模型训练流水线按唯一 event_id 连接 X 和 y，并对齐事件/标签成熟时间；若过滤异常样本应同时过滤对应 y，保留可追溯 ID。

## 5. 关联知识与易混辨析

Target Vector 是目标组织形式，Target/Label 是语义定义；多标签时 Y 可为 n×k 二值指示矩阵，不能强作互斥多类。

## 6. 中等难度面试题（含参考答案）

1. **问：随机打乱 X 后为何必须用同一索引打乱 y？** 答：损失函数默认第 i 行输入对应第 i 个正确答案，错位将破坏监督信号且可能导致训练或评估无意义。

2. **问：如何判断分类 y 应当用整数编码还是独热编码？** 答：看模型和损失接口：多类交叉熵可能接收整数类索引或概率向量；不能未经接口核实就更换形状。

## 7. 中等难度考试题（含解析）

1. **题：X 有 120 个样本、7 个特征，单输出 y 长度应多少？** 解：120，与 X.shape[0] 一致；y.shape=(120,) 常见。

2. **题：二输出连续回归有 80 个样本，Y 应有多少个目标元素？** 解：80×2=160 个；常见形状 (80,2)，并需定义两个输出损失的单位和权重。
