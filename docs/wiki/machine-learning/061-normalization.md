# Normalization（归一化）

> 领域：机器学习 · 专题：数据预处理与特征工程 · 数理解释和工程实用边界

## 1. 核心定义

归一化指按特定规则使数据满足标准尺度或几何约束。在 scikit-learn 的 Normalizer 中它专指对每个样本行进行 L1、L2 或最大范数缩放；其他文献也可能用该词指 min-max 特征缩放，因此必须交代具体约定。

## 2. 形象理解

把长短不一的箭头改为长度为 1，比较的是方向而非原始长度。

**类比的局限：**归一化可能丢掉绝对幅度；零向量不能直接除以范数。

## 3. 技术原理与核心内容

对非零样本向量 x，L2 归一化为 x'=x/||x||₂；L1 为 x'=x/Σ|x_j|。Normal­izer 是样本级无状态变换，跟随输入逐行计算；而 MinMaxScaler 是特征级需在训练集学习极值的变换。单位范数后，非零向量点积等于余弦相似度。

## 4. 工程实践与设计权衡

文本检索可对 TF-IDF 做 L2 行归一化，比较文档方向而非总词频；金额预测则可能需要保留交易规模，不能无条件移除向量长度。

## 5. 关联知识与易混辨析

Normalization 不是严格等同 Standardization；也不同于逐列 Min–Max Scaling。选择取决于下游距离、尺度与业务约束。

## 6. 中等难度面试题（含参考答案）

1. **问：为什么单位 L2 范数向量的点积等于余弦相似度？** 答：余弦=(x·y)/(||x||||y||)，各向量范数均为 1 时分母为 1。

2. **问：零向量怎么归一化？** 答：不能除以零，应按实现定义返回零向量或额外保护；同时解释零向量与其它向量的相似度。

## 7. 中等难度考试题（含解析）

1. **题：x=(3,4)，L2 归一化输出？** 解：||x||₂=5，得到 (0.6,0.8)。

2. **题：x=(2,−2)，L1 归一化输出？** 解：范数为 4，输出 (0.5,−0.5)，绝对值和为 1。
