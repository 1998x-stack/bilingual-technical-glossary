# Kernel Trick（核技巧）

> 领域：机器学习 · 专题：支持向量机、核方法与近邻 · 数学形式、优化条件与独立评估

## 1. 核心定义

核技巧（Kernel Trick）是将算法中只需要内积的计算，以核函数 K(x,z)=⟨φ(x),φ(z)⟩替代，从而无需显式构造可能非常高维甚至无限维的特征映射 φ。它既能支持核 SVM 的非线性边界，也可用于核岭回归、核 PCA 和高斯过程等方法。

## 2. 形象理解

像比较两本书的复杂特征，不先列出所有可能的短语组合，而使用一个可直接计算的‘相似性函数’得到这些隐含特征的内积。

**类比的局限：**不是任意相似度都能直接做凸 SVM 的有效核；Gram 矩阵的对称与半正定性质很重要，核技巧也不自动消除二次规模内存。

## 3. 技术原理与核心内容

定义 φ:X→H 并令 K(x,z)=⟨φ(x),φ(z)⟩_H。核化 SVM 对偶仅依赖 K_ij，使 f(x)=Σ_{i∈SV}α_i y_i K(x_i,x)+b。对称半正定核对任意有限样本产生 PSD Gram 矩阵，可保证对应的内积表示与凸对偶结构；任意定义的距离转相似度未必 PSD。核矩阵完整存储需 O(n²) 空间，核近似 Nyström、随机 Fourier 特征等用于大规模折中。

## 4. 工程实践与设计权衡

小样本非线性设备故障数据可先尝试 RBF SVC 并用时间/设备分组 CV 选 C、gamma；当样本升至百万级时评估核矩阵开销并改用显式特征映射近似与线性分类器。

## 5. 关联知识与易混辨析

Kernel Trick 是算法替代内积的机制；Kernel Function 是实现该内积的具体函数；RBF、Polynomial 与 Linear Kernel 是具体核；Nearest Neighbor 的任意相似度不要求 SVM 对偶所需的 PSD。

## 6. 中等难度面试题（含参考答案）

1. **问：为什么核技巧不表示所有计算都自动从高维变为低成本？** 答：隐式 φ 避免高维坐标，但存储 n×n Gram 仍需 O(n²)，求解和推理还可能依赖样本数与支持向量数量。

2. **问：任意计算方便的相似度函数都能作为核 SVM 核吗？** 答：不能保证。需要对称 PSD 等性质来保持通常的核内积与凸优化结构；不合法核可能得到不稳定或不同性质的算法。

## 7. 中等难度考试题（含解析）

1. **题：有 n=1000 个样本，完整 float64 Gram 矩阵仅存数值需要多少字节？** 解：1000²×8=8,000,000 字节（十进制约 8 MB），不计求解器开销。

2. **题：若显式映射 φ(x)=(x,x²)，x=2、z=3，则核 K(x,z)=⟨φ(x),φ(z)⟩是多少？** 解：φ(2)=(2,4)、φ(3)=(3,9)，内积 2×3+4×9=6+36=42。
