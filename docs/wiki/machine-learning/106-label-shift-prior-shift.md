# Label Shift / Prior Shift（标签偏移／先验偏移）

> 领域：机器学习 · 专题：统计学习与泛化理论 · 定义、条件、推导与工程适用边界

## 1. 核心定义

标签偏移／先验偏移（Label Shift / Prior Shift）指目标总体的类别先验 P(Y) 变化，同时保持类条件特征分布 P(X|Y) 不变。它经贝叶斯公式改变 P(Y|X)，但不能只凭观察正类比例变化就认定类条件不变。

## 2. 形象理解

像不同季节流感患者比例变化：同种流感病例的症状分布不变，但医院总体患流感的先验概率改变。

**类比的局限：**现实中新病毒株也可能改变症状特征；此时 P(X|Y) 不再稳定，单纯按先验校准会失效。

## 3. 技术原理与核心内容

用 P_s 与 P_t 表示源/目标域，假设 P_t(X|Y)=P_s(X|Y) 且 π_t(y)≠π_s(y)。贝叶斯校正得到 p_t(y|x) ∝ p_s(y|x)·π_t(y)/π_s(y)，最后要对所有类别重新归一化。目标域标签先验未知时，可由目标无标签预测和已验证的分类器混淆矩阵估计（BBSE 等）；混淆矩阵可辨识性、类支持与估计误差至关重要。

## 4. 工程实践与设计权衡

远程筛查服务部署到患病率不同地区时，可先评估检验手段在各病种条件下的稳定性；若符合先验偏移假设，再调整概率或决策阈值，并以真实延迟标签复核校准。

## 5. 关联知识与易混辨析

Label Shift 假设 P(X|Y) 不变；Covariate Shift 假设 P(Y|X) 不变；Concept Drift 指关系变化。先验变化不能仅靠“重新设置阈值”总是完全解决。

## 6. 中等难度面试题（含参考答案）

1. **问：为何在标签偏移下源域模型概率需要重标定？** 答：后验依赖先验，通过贝叶斯法则会随 π(y) 变化；若保持源概率直接部署，预测概率可能系统失准。

2. **问：如果类别先验 p_t(y) 不可直接观测，如何估计？** 答：可用目标无标签样本预测分布与源域验证混淆矩阵估计先验，但要求矩阵可辨识、稳定的 P(X|Y) 及足够样本。

## 7. 中等难度考试题（含解析）

1. **题：源先验正类为 0.2、目标先验正类为 0.4，正类未归一权重倍率？** 解：w_+=0.4/0.2=2；负类倍率为 0.6/0.8=0.75。若校正后验必须再按类别归一化。

2. **题：某样本源后验 p_s(+|x)=0.5，权重正类 2、负类 0.75，目标后验是多少？** 解：未归一分数 1 和 0.375，总和 1.375；目标正类后验 1/1.375≈0.7273，假设标签偏移成立。
