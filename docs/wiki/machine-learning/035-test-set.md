# Test Set（测试集）

> 适用领域：机器学习 · 专题：数据、样本与数据集划分 · 验证协议与模型选择

## 1. 核心定义

测试集是模型开发方案确定后，用于估计未知数据泛化表现的隔离样本。测试集必须在拟合、预处理估计、超参选择、阈值确定和错误驱动的模型迭代之外保留。

## 2. 形象理解

像真正的闭卷考试：见过答案再重新答，即使名义上仍叫考试，也失去独立评价意义。

**类比局限：**测试集结果仍受抽样代表性、组依赖、时间漂移与有限样本方差限制，不是永远正确的生产 KPI。

## 3. 技术原理与核心内容

测试风险估计 R̂_test=(1/n_test)Σ_iℓ(f(x_i),y_i)；固定模型时可据样本生成置信区间，但需考虑样本相关性。测试报告应包括目标分布、切分协议、指标的选择和误差分层。若用测试结果修改模型，此集合将逐渐退化为验证集。

## 4. 工程实践与设计权衡

欺诈检测必须对未参与开发的后续月份测试并报告各商户/人群表现；测试集中同一个客户与训练集共享历史时，需说明评估针对已知客户还是全新客户。

## 5. 关联知识与易混辨析

Test Set 是特定最终评价用途；Holdout Set 泛指从某训练过程留出的数据，其中可做验证或最终测试，名称不能保证使用纪律。

## 6. 中等难度面试题（含参考答案）

1. **问：测试集只看一次，仍有哪些泄漏途径？** 答：全局插补或标准化先 fit 了全量数据、训练与测试重复实体、测试时间之后的特征生成，都可能在测试前已经泄漏。

2. **问：测试通过后上线分数下降就证明测试造假吗？** 答：不一定；目标数据分布、行为反馈或评估口径变化会导致性能漂移，应排查样本代表性与运行条件。

## 7. 中等难度考试题（含解析）

1. **题：固定模型在 400 条独立测试样本中正确 320 条，测试准确率多少？** 解：320/400=80%；不确定性仍需按独立统计单位与置信水平估计。

2. **题：若正类测试样本只有 10 条且正确召回 8 条，召回率？为何不稳定？** 解：Recall=8/10=80%，但分母仅 10，两个样本变化就影响 20 个百分点；应报告区间与分层样本量。
