# Feature Selection（特征选择）

> 领域：机器学习 · 专题：数据预处理与特征工程 · 原理、数理条件与工程设计

## 1. 核心定义

特征选择从现有候选变量中确定一个子集，在尽量保留预测信息的同时降低计算、过拟合和解释成本。它不同于将特征映射到新空间的降维或特征提取。

## 2. 形象理解

像从一百支工具里挑出维修该机器真正需要的十支，而不是把工具熔成另一种材料。

**类比的局限：**变量间的协同作用可能使单独评分较弱的特征组合很有效；单变量筛选无法保证全局最优。

## 3. 技术原理与核心内容

常见方法有 Filter（如训练折内互信息、F 检验）、Wrapper（如递归特征消除 RFE）及 Embedded（如 L1 正则）。令 S⊆{1,…,d} 为所选列，拟合 f(X_S)；全部选择操作必须包入每个 CV 折，否则选择算法可能读取验证标签。对相关特征，应检查选择稳定性和因果可用性。

## 4. 工程实践与设计权衡

医疗模型有 500 个候选实验室指标，但收集每个指标需付费。按组级 CV 选择 20 个低成本且稳定的指标；模型评测必须计入检验成本和缺失率。

## 5. 关联知识与易混辨析

Feature Selection 选原列；PCA 创造新线性组合；L1 稀疏系数可以做嵌入式选择但在高度相关变量间结果可能不稳定。

## 6. 中等难度面试题（含参考答案）

1. **问：为什么在全量数据上用 SelectKBest 之后再做交叉验证会高估性能？** 答：特征评分已使用验证折标签，分折模型没有真正隔离验证信息；应把选择器放进 Pipeline 并对每折训练部分重新 fit。

2. **问：两组高度相关特征为什么 Lasso 可能不稳定？** 答：近似替代变量之间惩罚会偏向随机选择其中一个，样本扰动可能改变结果；可考虑稳定性选择、组正则或保留业务解释。

## 7. 中等难度考试题（含解析）

1. **题：初始 40 个特征，SelectKBest 保留 12 个，删除比例多少？** 解：删除 28/40=70%，保留比例 30%。

2. **题：3 次重复选择结果分别为 {A,B,C}、{A,C,D}、{A,B,D}，特征 A 的选择频率？** 解：A 在 3/3 次中出现，频率 100%；B、C、D 各为 2/3≈66.7%，频率不是因果重要性。
