# Label Encoding（标签编码）

> 领域：机器学习 · 专题：数据预处理与特征工程 · 数理原理、适用条件与生产风险

## 1. 核心定义

标签编码通常指为离散监督目标 y 的每个类别分配稳定的整数索引，便于分类损失和模型 API 使用。它是目标标签表示形式的变化，而不是对原本无序的输入特征随意施加可比较的数值距离。

## 2. 形象理解

给球队名称分配参赛编号，编号方便系统检索，但第 10 号队伍不比第 2 号队伍“多八份实力”。

**类比的局限：**标签数字是索引不是物理量；错误的类别映射和训练/上线编码不一致会直接破坏评价。

## 3. 技术原理与核心内容

建立从原始类名到 {0,…,K−1} 的单射映射 e(y)，训练时把标签按稳定字典转换，推断时将预测整数 inverse_transform 还原为业务标签。scikit-learn LabelEncoder 文档限定主要用于目标 y 而非输入 X；若有未知目标类需要重新定义模型输出空间，而不是随意追加类别。多标签目标需要 MultiLabelBinarizer 或合适的二维表示。

## 4. 工程实践与设计权衡

工单意图分类将“退款”“退换”“物流”绑定到模型版本中明确的整数映射，部署时保持一致，并对新增的业务意图做模型变更审批。若训练中类别顺序不同，混淆矩阵和概率列也可能被误解。

## 5. 关联知识与易混辨析

LabelEncoding 通常作用于 y；OrdinalEncoder 用于输入 X；OneHotEncoder 为输入类别建指示列。数字类索引不代表连续目标，交叉熵的 target class index 与 one-hot target 也是接口差异。

## 6. 中等难度面试题（含参考答案）

1. **问：为什么使用整数标签不等于做回归任务？** 答：类别索引不具有连续数值意义，分类交叉熵优化的是离散标签概率；真正任务类型由目标与损失决定，不由存储 dtype 决定。

2. **问：为什么训练阶段和生产阶段必须保存 classes_ 顺序？** 答：输出概率的每一列对应某个固定类别，映射改变会把概率或预测标签错位，造成静默的业务错误。

## 7. 中等难度考试题（含解析）

1. **题：原始类别按 [猫,狗,鸟] 定义映射 [0,1,2]，标签 [狗,鸟,猫] 编码结果是什么？** 解：[1,2,0]，假设映射由业务固定，不依赖自动字母排序。

2. **题：单标签 4 类分类器输出形状 (30,4)，有多少个类别得分？** 解：30×4=120 个；每行 4 个类别的概率若使用 softmax 则加和为 1。
