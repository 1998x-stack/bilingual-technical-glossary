# Tree Depth（树深度）

> 领域：机器学习 · 专题：树模型与集成学习 · 树结构、训练准则与统计边界

## 1. 核心定义

树深度（Tree Depth）通常指节点从根沿路径经过的边数，根深度为 0，一棵树最大深度是所有叶深度的最大值。它限制树可表达的交互规则和模型复杂度，却不能单独决定实际叶数或泛化能力。

## 2. 形象理解

像问诊时最多允许连续问多少个问题：问得越多能区分更细的情况，也越可能根据偶然样本做出过细决定。

**类比的局限：**深度小不保证公平或可解释，深度大也不一定过拟合；叶节点样本量、分裂准则、数据和集成方式同样重要。

## 3. 技术原理与核心内容

满二叉树在最大深度 d（根深度 0）时最多有 2^d 个叶、2^{d+1}−1 个节点，但实际 CART 可能因早停远少于上界。scikit-learn `max_depth=None` 表示不设显式深度上限，仍受纯度、min_samples_split 等停止规则影响。单树增加深度通常降低训练不纯度并提高容量，独立测试风险可能出现 U 形。对 GBDT 中的弱树，较小深度刻画低阶特征交互，但整体提升模型容量还受树的数量和学习率影响。

## 4. 工程实践与设计权衡

信用评分可从深度 2–6 的树做分组交叉验证，并同时限制叶最小支持量。若要给用户展示可解释规则，应同时报告对应叶覆盖量和错误率，而非只宣称‘深度 3 很简单’。

## 5. 关联知识与易混辨析

Tree Depth 衡量最长路径；Leaf Count 是终端区域数量；Node Count 包含内部与叶；max_depth 是正则超参数，但不等同成本复杂度剪枝 α。

## 6. 中等难度面试题（含参考答案）

1. **问：深度 3 的树是否一定有 8 个叶？** 答：不一定。8 只是完整二叉树的最大值，有些分支因停止条件提前到叶；最小叶数取决于树是否真正达到该深度。

2. **问：为什么 GBDT 的弱树 max_depth=2 也能构成复杂整体模型？** 答：多轮树的加性组合叠加大量非线性分段函数，整体容量随树数和学习率累积，不只由单树深度决定。

## 7. 中等难度考试题（含解析）

1. **题：一棵根深度 0 的满二叉树最大深度为 4，最多多少片叶和总节点？** 解：叶最多 2^4=16，总节点 2^5−1=31。

2. **题：某根到最深叶经过 6 条边，最大深度是多少？** 解：最大深度 6；如果按节点数计算该路径共有 7 个节点。
