# Capacity（模型容量）

> 领域：机器学习 · 专题：统计学习与泛化理论 · 推导、理论前提与工程设计

## 1. 核心定义

模型容量（Capacity）是某一假设类能够表达或拟合的预测规律的范围和丰富程度。容量可通过自由参数、函数类大小、VC 维或约束范数等间接刻画。较高容量可能降低逼近误差，但在有限样本上也可能提升对噪声的适应能力。

## 2. 形象理解

像画图工具：只能画直线的尺子容量小，能画任意曲线的工具容量大；工具越强仍不保证画出真实规律。

**类比的局限：**模型表达范围大不等于实际训练一定实现全部表达能力；优化器、正则、数据量与初始化可能限制有效容量。

## 3. 技术原理与核心内容

对于分类假设类 H，其在固定 n 个点上能够实现的二值标记组合数由增长函数 m_H(n) 表示，VC 维为可打散的最大点数。有限 |H| 时，m_H(n)≤|H|，而经验风险均匀收敛项常与 ln|H|、样本数 n 和置信度 δ 有关；无限 H 也可有有限 VC 维。模型容量随特征表示、激活、树深、正则约束改变，并非单看可训练参数计数。

## 4. 工程实践与设计权衡

制造缺陷检测从线性分类器升级复杂 CNN 前，应先验证在独立设备测试上是否仍存在可纠正偏差；容量增加后还应比较学习曲线、种子敏感度和推理成本。

## 5. 关联知识与易混辨析

Capacity 是可表达规律的集合性质；Model Complexity 包括结构或描述长度等指标；VC Dimension 是分类类容量的理论度量；Overfitting 是可能出现的训练/测试失败表现。

## 6. 中等难度面试题（含参考答案）

1. **问：为什么无限个分类函数的假设类仍可能具有有限 VC 维？** 答：函数参数可取连续值而形成无限候选，但对有限点集能实现的标记组合受到结构限制，例如实数直线上的定向阈值类。

2. **问：模型容量增大、训练误差降低，能据此断言泛化变差吗？** 答：不能，训练数据、正则与真实函数复杂度决定测试结果；容量高可能消除欠拟合，也可能提升方差，需要可靠验证。

## 7. 中等难度考试题（含解析）

1. **题：若一个有限分类假设类只有 8 个不同函数，它不可能打散多于多少个点？** 解：若打散 d 点需至少 2^d 种标记；2^d≤8，所以 d≤3，VC 维最多 3。

2. **题：若假设类在某组 3 个点上仅能实现 6 种二值标记，能说它打散了这 3 点吗？** 解：不能。要打散 3 点须实现全部 2³=8 种标记；6 种不足。
