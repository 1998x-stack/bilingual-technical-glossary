# Linear Regression（线性回归）

> 领域：机器学习 · 专题：回归、分类与线性模型 · 监督目标、优化公式和工程条件

## 1. 核心定义

线性回归（Linear Regression）在参数上采用线性可加形式预测连续目标，通常写为 ŷ=β₀+β₁x₁+…+β_dx_d。它既是回归模型类，也是可用多种损失或正则来拟合的基础表示；“线性”主要指参数形式而不必是原始特征中的纯直线。

## 2. 形象理解

像估算房价时给每平方米面积、楼龄和交通距离分别赋权，合计得到预测价格。

**类比的局限：**观测关联不是因果：某变量回归系数显著并不代表改变它就会按该系数改变结果。

## 3. 技术原理与核心内容

矩阵形式 ŷ=Xβ+β₀1；最小二乘选择 min_β||y−Xβ||²，若满列秩可得正规方程解。加入多项式特征 φ(x) 后仍可对参数线性。统计解释常需要线性均值关系、适当误差结构、可识别性等假设；作为纯预测器则更关注数据切分、外推风险、残差、共线性和稳健性。

## 4. 工程实践与设计权衡

建筑能耗基线可使用面积、气温、建筑年龄做线性模型；先按月份隔离测试并检查单位、变量相关性与异常值。可用残差随温度的系统曲线判断需要非线性项。

## 5. 关联知识与易混辨析

Linear Regression 是函数形式和模型家族；OLS 是拟合该家族的平方损失原则；Ridge/Lasso 改变惩罚约束；Logistic Regression 名称带回归，却处理分类概率。

## 6. 中等难度面试题（含参考答案）

1. **问：为什么多项式回归也能算线性回归？** 答：把 x²、x1x2 看作已经计算好的特征后，模型对这些特征的系数仍线性；它对原始 x 非线性。

2. **问：系数 β=2 能被直接解释为变量对结果的因果效应吗？** 答：不能。除非具备严格的因果识别条件，否则系数是观测条件关联，可因混杂和选择偏差改变。

## 7. 中等难度考试题（含解析）

1. **题：模型 ŷ=5+2x1−3x2，x1=4、x2=2，预测是多少？** 解：5+8−6=7。

2. **题：设计矩阵 X 形状 (200,5)，不包含截距列，β 的形状是什么？** 解：β 为 (5,)，Xβ 是长度 200 的预测向量，另加标量截距广播。
