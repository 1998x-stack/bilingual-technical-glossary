# Manhattan Distance（曼哈顿距离）

> 领域：机器学习 · 专题：支持向量机、核方法与近邻 · 数学、工程实践及邻域检索

## 1. 核心定义

曼哈顿距离（Manhattan Distance），又称城市街区距离或 L1 距离，是两个多维向量逐维差的绝对值之和：d₁(x,z)=Σ_j|x_j−z_j|。它符合 metric 公理，在特征尺度一致时可用于 KNN、聚类或某些绝对偏差优化。

## 2. 形象理解

像棋盘城市里只能横平竖直沿街行走，从一个路口到另一个路口必须把水平和竖直位移加起来。

**类比的局限：**高维空间里每维的绝对差权重同样依赖特征单位；真实城市有单行道或障碍物，L1 不能完整表示实际导航最短路。

## 3. 技术原理与核心内容

给定 x,z∈R^d，d₁(x,z)=Σ_j|x_j−z_j|，是 Minkowski p=1；而 d₂ 为平方和开根号。对同一差值向量 v，满足 ||v||₂≤||v||₁≤√d||v||₂。L1 由坐标轴决定，旋转特征空间一般会改变距离；欧氏距离对正交旋转不变。在高维稀疏离散向量中 L1 也可解释为绝对权重总差，但与二值 Jaccard 等度量不应混淆。

## 4. 工程实践与设计权衡

仓储系统如果对库存、供货时间等变量做 KNN 相似商品检索，L1 可降低某一个大差值被平方放大的效应；需对高量纲变量进行合理缩放并用最终业务召回/预测误差评估。

## 5. 关联知识与易混辨析

Manhattan 是 L1 距离，与 L1 Regularization 使用同一范数但作用对象不同；Euclidean 是 L2，RBF Kernel 通常使用其平方；Cosine Similarity 关注夹角，向量长度改变不影响同向相似。

## 6. 中等难度面试题（含参考答案）

1. **问：为什么 Manhattan 距离对坐标旋转不具一般不变性？** 答：L1 是沿当前坐标轴求绝对位移之和，旋转会重新分配差值坐标；L2 的正交旋转保持平方和。

2. **问：为什么不能因 L1 距离名字与 L1 正则相同就认为它们作用相同？** 答：前者衡量两个样本的输入差，后者惩罚模型参数绝对值和；数学范数类似但参与目标与任务不同。

## 7. 中等难度考试题（含解析）

1. **题：x=(1,2)、z=(4,6)，L1 距离多少？** 解：|4−1|+|6−2|=3+4=7。

2. **题：在二维 x=(0,0)、z=(1,1) 时，L1 与 L2 距离分别多少？** 解：L1=|1|+|1|=2；L2=√(1²+1²)=√2≈1.414。
