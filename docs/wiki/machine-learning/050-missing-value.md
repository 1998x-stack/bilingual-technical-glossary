# Missing Value（缺失值）

> 适用领域：机器学习 · 专题：数据、样本与数据集划分 · 可信验证、偏差与防泄漏

## 1. 核心定义

缺失值是原本应出现的特征观测未记录或无法确定的状态，可以由传感器故障、数据管道缺口、用户选择不回答或字段不适用导致。缺失不是普通的零，也不等同异常值。

## 2. 形象理解

像体检表中‘体温未测’与‘体温 0 度’是完全不同的信息。

**类比局限：**有时缺失本身包含重要预测信号，但模型也可能借此学到医院流程、收费差异等不稳定的捷径。

## 3. 技术原理与核心内容

缺失机制常区分 MCAR（缺失与变量无关）、MAR（给定已观测变量后可解释）与 MNAR（仍依赖未观察值或其机制）；不能仅从数据形态证明 MAR。处理包括删除、简单填补、多重插补、模型原生缺失支持和缺失指示器；在每个训练折内拟合填补参数，并检查各组缺失模式。

## 4. 工程实践与设计权衡

工业设备温度缺测可能因设备断电，也可能是采集服务中断。应记录设备在线状态、缺失比例和时间连续段；使用训练统计填补并可提供 missing_indicator，但不能用验证期未来均值回填。

## 5. 关联知识与易混辨析

Missing Value 是信息未提供；Outlier 是已有观测显著偏离；Imputation 是对缺失的估计处理。0、NaN、空字符串和‘不适用’须按字段语义区分。

## 6. 中等难度面试题（含参考答案）

1. **问：为什么均值填补可能使部署表现下降？** 答：它降低方差且掩盖群体条件差异，若缺失非随机还可能产生系统偏差。应对比缺失指示器、分组填补或原生缺失模型，并按部署分布评估。

2. **问：训练和验证缺失率差很多，该怎么办？** 答：先核验数据采集流程与人群变化；填补器只用训练集拟合，分别报告缺失机制/质量指标，并在生产设置采集告警。

## 7. 中等难度考试题（含解析）

1. **题：列 [2,4,缺失,6] 用观测均值填补，缺失值填多少？** 解：均值 (2+4+6)/3=4；只在题设观测值来自训练折时可以用于拟合填补器。

2. **题：100 个样本某字段缺失 25 个，缺失率？若拆分后验证集 20 个样本缺失 10 个？** 解：全体 25%，验证集 10/20=50%，两者差异提示可能的分布或采集机制改变；不应直接用全体均值填补。
