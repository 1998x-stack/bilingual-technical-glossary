# Decision Boundary（决策边界）

> 领域：机器学习 · 专题：回归、分类与线性模型 · 模型与数学定义、业务应用和边界条件

## 1. 核心定义

决策边界（Decision Boundary）是分类规则在输入空间中改变预测类别的区域或集合。对二分类概率模型常由得分达到阈值决定；对多类 argmax 则由竞争类别的得分相等且为最大值的位置形成。边界位置依赖特征表示、阈值与业务成本。

## 2. 形象理解

像地图上两支救援队的负责区域分界线：在线两侧由不同队伍服务，但地图的标尺和道路规则改变后边界也会变。

**类比的局限：**决策边界不是模型对样本是否可信的完整度量；远离边界的样本也可能由于分布偏移或概率失准被高置信地误判。

## 3. 技术原理与核心内容

二分类线性分类器得分 s(x)=wᵀx+b，默认零阈值时边界为 wᵀx+b=0 的超平面。Logistic 模型若采用 p≥τ 的阈值，等价边界 wᵀx+b=log[τ/(1−τ)]，仅 τ=0.5 时为 0。多类 Softmax 的相邻边界满足 z_i=z_j 且两者不小于其他类 logit；核模型或深度模型可形成曲线/非线性区域。

## 4. 工程实践与设计权衡

信用审核使用校准 Logistic 概率并根据误报/漏报与人工复核容量调整阈值，边界随策略改变；应分别版本化模型权重和阈值，关注边界附近的校准、亚群公平性和漂移。

## 5. 关联知识与易混辨析

Decision Boundary 是离散决策的分界；Margin 是到边界的函数或几何距离概念，需明确尺度；Probability Calibration 是分数与真实频率的一致性；线性与非线性分类器可以有不同边界形状。

## 6. 中等难度面试题（含参考答案）

1. **问：为什么改变分类阈值会移动 Logistic Regression 的决策边界？** 答：阈值 τ 对应 logit(τ)，边界不再固定 s=0；业务策略即使不重训模型也会改变决策区域。

2. **问：为什么只用距离线性边界远近来断言模型确定性可能有问题？** 答：距离度量依赖特征尺度、w 范数和数据分布，且概率可能未校准；分布外样本远离边界也可能错误。

## 7. 中等难度考试题（含解析）

1. **题：分类规则 s(x)=2x1−x2+1，默认零阈值，边界的方程是什么？** 解：2x1−x2+1=0，即 x2=2x1+1。

2. **题：Logistic 模型使用 τ=0.8，边界的 logit 得分是多少？** 解：ln(0.8/0.2)=ln4≈1.3863，而非 0；假设分数为 log-odds。
