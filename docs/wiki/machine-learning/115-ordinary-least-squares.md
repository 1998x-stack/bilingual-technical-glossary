# Ordinary Least Squares (OLS)（普通最小二乘法 · OLS）

> 领域：机器学习 · 专题：回归、分类与线性模型 · 监督目标、优化公式和工程条件

## 1. 核心定义

普通最小二乘法（OLS）通过最小化训练样本残差平方和估计线性模型系数。它是拟合准则与估计方法，并非线性关系本身；在高相关、秩亏或异常值占比较高时，需要关注数值稳定性和估计行为。

## 2. 形象理解

像给一堆散点找一条直线，让每个点到直线的纵向距离平方相加最小，特别大的误差被更重惩罚。

**类比的局限：**纵向最小平方不是点到直线的正交距离最小；平方损失会突出异常观测，而不自动生成因果解释。

## 3. 技术原理与核心内容

令设计矩阵 X 包含所需截距列，目标 β̂=argmin_β ||y−Xβ||₂²。满列秩时 β̂=(XᵀX)^(−1)Xᵀy；秩亏则可能有无穷多最优系数解，预测的某些部分仍可确定。实际数值算法倾向 QR、SVD 或最小二乘求解器，而不是显式求逆 XᵀX。若要对系数作置信推断，还需误差假设与识别条件。

## 4. 工程实践与设计权衡

给业务交易额建立 OLS 基线时监控高杠杆点、异方差、多重共线性；可比较 Huber/Quantile Regression。若训练样本存在用户重复，应采用合适的分组验证。

## 5. 关联知识与易混辨析

OLS 是目标为平方残差和的估计方法；Ridge 加 L2 惩罚，Lasso 加 L1；LinearRegression API 常实现 OLS，但与使用统计软件求置信区间不同。

## 6. 中等难度面试题（含参考答案）

1. **问：为什么实际工程里不推荐先计算 (XᵀX)^(-1) 再拟合？** 答：矩阵近奇异时显式求逆不稳定且会放大条件数，QR/SVD 更稳定，并能检测秩亏。

2. **问：X 的两列完全相同意味着什么？** 答：X 秩亏，线性系数不可唯一识别；可使用 SVD 最小范数解、删除冗余列或正则化。

## 7. 中等难度考试题（含解析）

1. **题：观测 (x,y) 为 (0,1)、(1,3)，拟合带截距直线且恰好通过两点，截距与斜率各是多少？** 解：截距 1，斜率 (3−1)/(1−0)=2；此两点残差平方和为 0。

2. **题：一组残差为 [1,−2,3]，RSS 与 MSE 各多少？** 解：RSS=1+4+9=14，训练 MSE=14/3≈4.667。
