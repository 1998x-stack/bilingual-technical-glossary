# Representation Learning（表征学习）

> 适用领域：机器学习 · 专题：基础概念与学习范式 · 实践、理论与边界

## 1. 核心定义

表征学习通过数据驱动方式学习映射 z=f_θ(x)，使原始输入转换成更有利于后续任务的特征表示。目标不仅是降维，还可能是去除无关变化、保留语义结构、提高线性可分性或支持迁移。

## 2. 形象理解

像把复杂地图整理成只保留道路连通关系的地铁图，以方便规划路线。

**类比局限：**简化后的地图对换乘很有用，却不适合计算建筑面积；好的表征总是相对于任务和信息需求而言。

## 3. 技术原理与核心内容

学习目标可来自重构损失、对比学习、预测代理任务或监督下游标签。表示质量可通过冻结编码器的线性探测、微调、最近邻检索和跨域稳健性检验。高维表征不自动优于低维；无约束对比学习还需防止塌缩、伪负例和 shortcut。

## 4. 工程实践与设计权衡

音频检索用同一个编码器将声片段映射到向量空间；从原始波形中学到不受音量变化干扰的表示，适合近邻搜索。需控制噪声、设备差异、数据版权与向量更新一致性。

## 5. 关联知识与易混辨析

表征学习是学会特征映射；特征工程通常更依赖人工指定变换；嵌入向量是表征的常见形态，但表征不一定低维、稠密或完全可解释。

## 6. 中等难度面试题（含参考答案）

1. **问：为什么预训练表示常用线性探测来评测？** 答：固定编码器只训练简单线性头，可更直接地衡量表示中任务信息的可分离性，减少复杂下游模型掩盖表示缺陷的风险；仍需公平划分数据。

2. **问：什么是表示塌缩，如何发现？** 答：不同输入被编码成几乎同一个向量，导致方差与区分能力低。可检查向量协方差谱、类间距离和检索表现，结合训练目标防止退化。

## 7. 中等难度考试题（含解析）

1. **题：嵌入向量 v=(3,4)，求 L2 范数和归一化向量。** 解：||v||₂=sqrt(9+16)=5，归一化为 (0.6,0.8)；余弦相似度要求分母处理零向量。

2. **题：100 个样本原始特征每个 128 维，表示映射后每个 10 维，若都用同精度浮点数表示，元素数压缩比多少？** 解：原始 12,800 元素，表示 1,000 元素，比例 1000/12800=7.8125%，元素减少约 92.19%；不计编码器参数及计算成本。
