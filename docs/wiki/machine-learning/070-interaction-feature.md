# Interaction Feature（交互特征）

> 领域：机器学习 · 专题：数据预处理与特征工程 · 数理原理、适用条件与生产风险

## 1. 核心定义

交互特征显式表示两个或多个输入变量的共同作用，使模型能够区分“同时出现”与两个特征独立相加的情形。常见构造是乘积项 x₁x₂，也可以是交叉类别、比率或经过业务验证的逻辑组合。

## 2. 形象理解

雨天与堵车单独都会影响送达时间，两者叠加可能比简单相加更严重；交互项试图表达这种额外影响。

**类比的局限：**数学乘积可能只是一种表达假设，并不等于真正因果相互作用；更不能凭观察相关证明两个因素共同导致结果。

## 3. 技术原理与核心内容

在线性回归加入 ŷ=β₀+β₁x₁+β₂x₂+β₁₂x₁x₂ 后，x₁ 的边际预测变化是 β₁+β₁₂x₂，随 x₂ 变化。类别交互可形成联合哑变量，维度可能等于两类别基数的乘积。使用模型训练折进行筛选与组合验证，避免无约束创建海量高阶特征。

## 4. 工程实践与设计权衡

点击率模型加入“设备类型×时段”帮助学习不同设备在夜间的响应差异。应检查稀有组合的覆盖、参数估计稳定性以及新组合的冷启动处理。

## 5. 关联知识与易混辨析

Interaction Feature 是专门刻画联合作用的特征；PolynomialFeatures 可系统化产生交互；Feature Hashing 可对高维联合类别做固定维度压缩但存在碰撞。

## 6. 中等难度面试题（含参考答案）

1. **问：为什么只用两个加性主效应不能表达协同作用？** 答：加性模型使一个变量的边际影响不随另一变量改变；交互项允许这种条件差异。

2. **问：高维交叉类别为什么容易过拟合？** 答：组合类别可能极稀疏甚至只出现一次，导致参数估计方差大；应限制交互、合并罕见值或正则化。

## 7. 中等难度考试题（含解析）

1. **题：模型 y=1+2x₁+3x₂+4x₁x₂，x₁=1、x₂=2，预测值？** 解：1+2+6+8=17。

2. **题：有一个 3 类变量和一个 4 类变量，完全交叉 one-hot 有多少个联合类别？** 解：3×4=12 个潜在组合；训练中未出现的组合需要既定未知处理。
