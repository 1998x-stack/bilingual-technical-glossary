# Box–Cox Transformation（Box–Cox 变换）

> 领域：机器学习 · 专题：数据预处理与特征工程 · 数理原理、适用条件与生产风险

## 1. 核心定义

Box–Cox 变换是对严格正值数值变量的一族参数化幂变换，通过选择 λ 调整数据偏态与方差形态。它常用于使某些统计模型的残差或变量分布更符合假设，但并不保证生成正态分布。

## 2. 形象理解

像一个带旋钮的可调压缩镜头：λ 改变数据的大值被压缩的程度，λ=0 的极限对应取对数。

**类比的局限：**原始值必须严格大于 0；含零或负数时不能直接使用 Box–Cox，随意加常数会改变方法含义。

## 3. 技术原理与核心内容

当 x>0 且 λ≠0，T_λ(x)=(x^λ−1)/λ；λ=0 时 T₀(x)=ln x。训练时根据分布或似然选择 λ，仅将这个训练参数用于测试/线上。PowerTransformer(method='box-cox') 会估计 λ，并可能在变换后额外标准化；Yeo–Johnson 则适用于非正值数据。

## 4. 工程实践与设计权衡

实验响应值严格为正且长尾时，可比较 Box–Cox 与简单对数/稳健回归；评估须回到业务原始量纲，并记录 λ 的版本与非正输入的失败路径。

## 5. 关联知识与易混辨析

Box–Cox 要求正值；Yeo–Johnson 允许零和负值；LogTransform 是 λ→0 的特例；MinMaxScaler 不调整偏态的非线性形状。

## 6. 中等难度面试题（含参考答案）

1. **问：为什么不能对含负值的列直接使用 Box–Cox？** 答：定义依赖正值幂与对数，非正值下公式不具有相同实数意义；可以研究 Yeo–Johnson 或基于业务理由的数据重定义。

2. **问：为什么估计 λ 时也必须遵守训练折边界？** 答：λ 是从样本分布学习的统计参数，用验证/测试参与估计会使变换携带评估集信息，造成泄漏。

## 7. 中等难度考试题（含解析）

1. **题：x=4、λ=1，Box–Cox 变换值是多少？** 解：(4^1−1)/1=3。

2. **题：x=e²、λ=0，Box–Cox 的极限值是多少？** 解：T₀(x)=ln(e²)=2；此例 x 为严格正值。
