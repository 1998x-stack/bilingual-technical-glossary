# Soft Margin（软间隔）

> 领域：机器学习 · 专题：支持向量机、核方法与近邻 · 数学形式、优化条件与独立评估

## 1. 核心定义

软间隔（Soft Margin）是在支持向量机最大间隔优化中允许个别训练样本进入间隔带或被误分类，并通过松弛变量/合页损失为违规付出成本的机制。其核心权衡由 C 调节：增大 C 往往更严厉惩罚违规，但不保证测试风险单调降低。

## 2. 形象理解

像两群人之间划出一条安全通道，允许少数特殊情况暂时跨入通道，但每次跨越都付出代价，以避免因一个错误标注令全局无法规划。

**类比的局限：**有容忍度不等于随意忽略少数群体；违规样本可能是重要真实边界，也可能是标签错误，需结合业务审查。

## 3. 技术原理与核心内容

原始问题 min_{w,b,ξ} 0.5||w||²+CΣ_i ξ_i，约束 y_i(wᵀx_i+b)≥1−ξ_i、ξ_i≥0。固定 w,b，最优 ξ_i=max(0,1−y_if_i)，因此与 L2 正则加 Hinge Loss 等价。功能间隔 m_i≥1 不违规；0<m_i<1 虽分类正确但在间隔内；m_i≤0 表示落在边界上或错分。scikit-learn SVC 的 C 定义与其他模型的平均 loss 系数不同，跨 API 比较需换算。

## 4. 工程实践与设计权衡

不平衡缺陷检测可比较 `class_weight`、C、核参数与不同误报/漏报成本。对相关设备分组验证，防止学习到机器 ID 之类的近似记忆特征。

## 5. 关联知识与易混辨析

Soft Margin 是允许训练间隔违规的 SVM 机制；Hinge Loss 是其惩罚实现；Hard/Maximum Margin 只适合严格可分；Regularization 限制权重范数但不等于直接调决策阈值。

## 6. 中等难度面试题（含参考答案）

1. **问：C 增大意味着模型会容忍更多错误吗？** 答：通常相反：同样的 ξ 更昂贵，因此优化倾向减小违规，但可能牺牲宽间隔并增加过拟合风险。

2. **问：正确分类但 f 的规范功能间隔只有 0.2，属于哪种情形？** 答：0<m=0.2<1，符号判对但违反规范间隔；最小松弛 ξ=1−0.2=0.8。

## 7. 中等难度考试题（含解析）

1. **题：y=+1、f=−0.5，最小 ξ 是多少？** 解：ξ=max(0,1−(−0.5))=1.5；该点被错分。

2. **题：固定 w 的范数平方为 4，两样本 ξ 分别 0.5、1，C=2，目标值？** 解：0.5×4+2×(0.5+1)=2+3=5。
