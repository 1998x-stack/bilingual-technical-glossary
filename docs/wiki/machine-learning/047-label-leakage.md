# Label Leakage（标签泄漏）

> 适用领域：机器学习 · 专题：数据、样本与数据集划分 · 可信验证、偏差与防泄漏

## 1. 核心定义

标签泄漏是目标值、目标生成过程或其后验代理变量在预测时间之前不可获得，却被不当用作模型输入或训练辅助信息的情况。它通常导致虚高分数，尤其在业务流程产出字段中隐蔽。

## 2. 形象理解

像预测患者是否需要住院时，把‘出院时结算费用’输入模型；几乎直接从结果读答案。

**类比局限：**某变量与标签强相关并非充分证据；只有确认预测时点和变量生成链后才能断定泄漏。

## 3. 技术原理与核心内容

判断标准是特征 x_j 的可用时间 t_available≤t_prediction，且其构造不依赖目标的未来结果或保留测试标签。标签编码或 target encoding 使用当前行的标签进行自身编码也可能造成泄漏，应采用训练折内交叉拟合。泄漏会污染概率校准与重要性解释，不能只靠正则化修复。

## 4. 工程实践与设计权衡

保险索赔风险系统如果‘最终赔付额’只在案件结束后填写，就不能用于受理时的风险预测；把该字段从测试集删除不够，训练与推理都必须按同一时点重构。

## 5. 关联知识与易混辨析

Label Leakage 是 Data Leakage 的子类；合法的历史目标统计（如用户过去三个月退货率）在严格的时间截断和交叉拟合下可能允许使用。

## 6. 中等难度面试题（含参考答案）

1. **问：高重要性字段是标签泄漏吗？如何审查？** 答：不是必然。调查字段何时、由谁、基于何种事件产生，进行真实预测时点回放；若只能事后得到则必须排除。

2. **问：Target Encoding 如何避免目标泄漏？** 答：训练阶段使用 out-of-fold 统计给每条训练行编码，对验证/测试使用仅在训练子集上估计的类别统计与平滑，防止用该行自己的 y。

## 7. 中等难度考试题（含解析）

1. **题：某特征在第 20 天才生成，而预测发生第 5 天；该字段可用吗？** 解：不可用：20>5，违反预测时点信息约束。即使离线样本文件内存在，也属标签/未来信息泄漏风险。

2. **题：对类别 A 的 4 个标签 [1,1,0,0]，若用该组包含当前样本的均值 0.5 给所有行做 target encoding 是否完全无风险？** 解：不完全无风险：每个样本自身标签参与编码，尤其稀有类别会自泄漏。需交叉拟合或使用严格历史数据。
