# Elastic Net Regularization（弹性网络正则化）

> 领域：机器学习 · 专题：统计学习与泛化理论 · 推导、理论前提与工程设计

## 1. 核心定义

弹性网络正则化（Elastic Net Regularization）同时使用 L1 和 L2 惩罚，兼顾稀疏变量选择与相关特征稳定性。它是一种惩罚形式而不只是单一回归模型；具体应用时要核对 α、L1 比率和损失归一化约定。

## 2. 形象理解

像招募小团队时既要求岗位数量简洁，又避免把全部责任压在一个人身上，综合控制稀疏程度和参数大小。

**类比的局限：**两种惩罚组合不保证最佳结果，相关特征也并非总能一起入选；参数网格和标准化会显著改变选择。

## 3. 技术原理与核心内容

典型目标 J(w)=R̂(w)+λ₁||w||₁+(λ₂/2)||w||₂²。scikit-learn ElasticNet 写成 (1/(2n))||y−Xw||₂²+α·l1_ratio||w||₁+0.5α(1−l1_ratio)||w||₂²；λ₁=αr，λ₂=α(1−r)。r=1 时形式退化为 Lasso，r=0 时纯 L2，但具体求解器可能不鼓励 r=0 的 ElasticNet 调用。强相关特征可得到比纯 L1 更平滑的选择；需要两维超参交叉验证。

## 4. 工程实践与设计权衡

用线上客户行为预测流失时，重叠的近 7 天和近 14 天活跃度特征高度相关，可以比较 Elastic Net 与 Ridge/Lasso，在客户级验证中观察性能和特征保留稳定性。

## 5. 关联知识与易混辨析

Elastic Net 是同时包含 L1/L2 的正规化策略；Lasso 为 L1，Ridge 为 L2。不要把求解器叫 Elastic Net 就假定原始模型本身能自动处理未来泄漏。

## 6. 中等难度面试题（含参考答案）

1. **问：为何 Elastic Net 常被用于相关特征组？** 答：L2 部分抑制单个系数剧烈波动，L1 部分保留稀疏性；但能否成组保留依赖数据、系数与超参，不是普遍保证。

2. **问：同一个 α 下调整 l1_ratio 会发生什么？** 答：r 增大通常加强 L1 相对比例并降低 L2 比例，可能增加稀疏；数值实际效果还取决于损失标度与特征标准化。

## 7. 中等难度考试题（含解析）

1. **题：α=0.4、l1_ratio=0.75，对应 L1 罚项系数 λ₁ 和平方项写成 (λ₂/2)||w||² 时 λ₂ 各是多少？** 解：λ₁=αr=0.3；λ₂=α(1−r)=0.1，即 L2 平方项前系数 0.05。

2. **题：标量目标 1/2(w−3)²+1|w|+(1/2)1·w²，求最优 w。** 解：对正解，导数 (w−3)+1+w=2w−2=0，得 w=1；也等于 soft(3,1)/(1+1)=1。
