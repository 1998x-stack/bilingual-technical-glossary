# L1 Regularization（L1 正则化）

> 领域：机器学习 · 专题：统计学习与泛化理论 · 推导、理论前提与工程设计

## 1. 核心定义

L1 正则化在目标中惩罚系数绝对值之和，典型为 λΣ_j|w_j|。由于在零点不可微，其最优解可恰好出现零系数，常用于稀疏线性建模和特征选择；它不是所有模型都自动稳定选出“真正因果特征”的保证。

## 2. 形象理解

像给每使用一个大小的参数都收费，模型为了减少账单可能主动将不重要的参数关停到零。

**类比的局限：**相关度很高的两列可能轮流被选择；稀疏不等于可解释的因果机制，强正则还可能遗漏弱但重要的变量。

## 3. 技术原理与核心内容

在 Lasso 回归中常见目标为 min_w [1/(2n)||y−Xw||₂²+α||w||₁]，通常截距另处理。标量问题 min_w 1/2(w−a)²+λ|w| 的解为 soft-threshold(a,λ)=sign(a)max(|a|−λ,0)。当 |a|≤λ 时 w*=0，说明稀疏来自 L1 范数零点不可微的几何性质。梯度近端法可使用 soft-threshold；学习前通常需要适当数值尺度处理。

## 4. 工程实践与设计权衡

对数百个财务比率做风险预测时，Lasso 可构造简洁基线，但遇强相关列需报告稳定性选择频率；若法律或业务要求某些信息不得使用，仍要独立审查特征允许性而不能只信 L1 自动剔除。

## 5. 关联知识与易混辨析

L1 罚绝对值，可产生精确 0；L2 罚平方，常连续收缩但通常不直接令系数恰为 0；Elastic Net 结合两者；Lasso 特征选择不等于基于因果的选择。

## 6. 中等难度面试题（含参考答案）

1. **问：为什么 L1 会比 L2 更容易产生零系数？** 答：L1 惩罚在 0 点有次梯度区间，优化最优性可使小幅梯度被该区间覆盖并固定系数为 0；平方惩罚梯度在 0 为 0，通常连续缩小。

2. **问：L1 特征选择在强共线性数据上有哪些风险？** 答：多个等价预测变量可能被任意保留其一，结果随样本波动；宜结合重采样稳定性分析、Elastic Net 或领域约束。

## 7. 中等难度考试题（含解析）

1. **题：标量目标 1/2(w−3)²+1|w|，最优 w 是多少？** 解：软阈值 soft(3,1)=3−1=2。可验证 w=2 正侧导数 (2−3)+1=0。

2. **题：同一目标中 a=0.5、λ=1，最优 w 是多少？** 解：因为 |a|≤λ，soft(0.5,1)=0，确实被压为零。
