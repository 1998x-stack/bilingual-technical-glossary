# Statistical Learning（统计学习）

> 适用领域：机器学习 · 专题：基础概念与学习范式 · 核心概念、理论与工程边界

## 1. 核心定义

统计学习研究如何依据有限的随机样本选择预测函数，并量化估计误差、模型复杂度和对未知总体的风险。核心是区分经验风险与期望风险，并在可陈述的数据生成假设下论证泛化。

## 2. 形象理解

像用少数抽样民调估计总体倾向：样本拟合得再好，也要讨论抽样机制和不确定性。

**类比局限：**理论边界依赖独立同分布、函数类和损失有界等假设；碰到相关样本和分布漂移时不能机械套用。

## 3. 技术原理与核心内容

给定未知分布 P(X,Y)，真实风险 R(f)=E_P[ℓ(f(X),Y)]，经验风险 R̂(f)=1/n Σℓ(f(x_i),y_i)。算法常求 argmin_f R̂(f)+λΩ(f)。容量控制可由正则化、假设空间复杂度、早停等实现；仅对训练集中被选择出的最佳超参报告未经校正的验证表现会产生选择偏差。

## 4. 工程实践与设计权衡

医疗风险评分应按患者分组并报告区间估计；若采集机构与目标医院差异明显，应单独验证迁移性。训练样本少时模型复杂度与先验假设同样重要。

## 5. 关联知识与易混辨析

统计学习强调风险、样本和泛化性质，ML 包含更广的算法与工程实践；统计显著性不等同预测价值。

## 6. 中等难度面试题（含参考答案）

1. **问：为什么需要独立测试集，而不是把验证集得分作为最后结论？** 答：反复尝试超参等价于对验证集进行隐式拟合，使最佳分数乐观偏置。独立测试集能提供更接近真实的最终泛化评估，但同样依赖抽样代表性。

2. **问：偏差—方差权衡是固定定律吗？** 答：它对平方损失下预测误差有经典分解，但现代过参数模型可出现双下降现象。实际仍需结合任务、模型、噪声和训练过程检验。

## 7. 中等难度考试题（含解析）

1. **题：候选模型 A 的验证损失 0.18、复杂度惩罚 0.08；B 的验证损失 0.22、惩罚 0.02。按两项和选哪个？** 解：A 的总分 0.26，B 为 0.24，选 B。说明这里是指定的教学评分准则，不自动等同真实泛化风险。

2. **题：若 n=100 且独立有界 0/1 损失，Hoeffding 给固定模型的误差偏差上界 ε=sqrt(ln(2/δ)/(2n))，δ=0.05，求 ε。** 解：ε=sqrt(ln 40/200)≈sqrt(0.01844)≈0.136。仅对固定模型和适用假设成立；用同一数据挑选很多模型需另作控制。
