# Support Vector（支持向量）

> 领域：机器学习 · 专题：支持向量机、核方法与近邻 · 数学形式、优化条件与独立评估

## 1. 核心定义

支持向量（Support Vector）是训练出的支持向量机中拥有非零对偶系数、对决策函数有直接贡献的训练样本。在线性可分硬间隔设置中它们通常位于规范间隔边界；在软间隔或重叠类别数据中也可以位于间隔内或误分类区域。

## 2. 形象理解

像用两侧最靠近安全走廊的锥桶确定走廊边界：远离走廊的普通锥桶通常不会直接参与最终边界的支撑。

**类比的局限：**支持向量不等于样本中最重要的因果实例，也不必然恰位于几何间隔面上；样本重复或退化优化会改变解的细节。

## 3. 技术原理与核心内容

对偶 SVM 决策函数 f(x)=Σ_i α_i y_i K(x_i,x)+b，在典型 C-SVC 中 0≤α_i≤C。α_i=0 的样本不参与预测和 w 的构造，0<α_i<C 的支持向量通常在功能间隔 y_if_i=1 的规范边界；α_i=C 的样本可能违反或恰好满足间隔。支持向量个数 n_SV 影响核 SVM 推理成本：一次查询通常需要对这些样本求核，内存也可能随之增大。

## 4. 工程实践与设计权衡

文本二分类核 SVM 如果有数万支持向量，线上单次推理可能较慢；可对比线性 SVM 或核近似。分析支持向量的标注错误比例和类别/群体覆盖，不得仅按其身份自动删除难样本。

## 5. 关联知识与易混辨析

Support Vector 是最终非零对偶系数样本；Margin 是函数或几何间隔；Nearest Neighbor Search 按查询距离取邻居，与通过最大间隔优化挑选支持向量不是同一机制。

## 6. 中等难度面试题（含参考答案）

1. **问：为什么软间隔 SVM 的支持向量不一定在间隔边界上？** 答：间隔内或错分样本可使 α 达到上界 C，仍直接参与对偶解；只有特定内点条件下才满足 y_if=1。

2. **问：为什么核 SVM 在线推理速度与支持向量数相关？** 答：对查询点需要与每个支持向量计算 K(x_i,x) 并加权求和；核昂贵或 n_SV 很大时成本上升。

## 7. 中等难度考试题（含解析）

1. **题：三个训练样本的 α 分别为 0、0.4、1.0（C=1），按 α>0 计支持向量数多少？** 解：有 2 个（第二和第三）；α=C 的第三个也可以是支持向量。

2. **题：如果两个支持向量的 αy 为 0.5、−0.25，查询点核值为 2、4，b=0.1，f(x)=多少？** 解：f=0.5×2+(−0.25)×4+0.1=0.1；得分符号正，不等于概率 0.1。
