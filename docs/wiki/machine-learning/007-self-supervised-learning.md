# Self-supervised Learning（自监督学习）

> 适用领域：机器学习 · 专题：基础概念与学习范式 · 术语机制、工程边界与评价

## 1. 核心定义

自监督学习从数据内部构造训练目标，如预测被遮盖的词、判断两次增强是否来自同一样本，从而在不依赖人工逐条任务标签的条件下学习可迁移表征。它通常是预训练策略，不保证直接解决所有下游任务。

## 2. 形象理解

像做完形填空：题目和答案都来自原书，不用老师先为每个句子贴分类标签。

**类比局限：**会填空不意味着知道真假，或一定擅长病理诊断、法律判断等下游任务。

## 3. 技术原理与核心内容

掩码建模以未遮盖上下文预测被遮盖 token，最小化条件负对数似然；对比学习构造正样本视图 z_i,z_i⁺，使用 InfoNCE 类损失 −log[exp(sim(z_i,z_i⁺)/τ)/Σ_j exp(sim(z_i,z_j)/τ)]。表示是否保留语义取决于增强策略、模型容量、数据及预训练目标。

## 4. 工程实践与设计权衡

大量未标注设备振动信号可预训练编码器，再用少量故障标签进行线性探测或微调。需比较冻结与微调，避免把未来设备日志混入历史时点评估。

## 5. 关联知识与易混辨析

自监督目标是数据派生的代理任务；无监督学习泛指没有人工任务标签的结构发现；半监督用业务标签与无标签共同训练目标任务，三者可能组合。

## 6. 中等难度面试题（含参考答案）

1. **问：为何自监督预训练损失下降，下游分类仍未改善？** 答：代理任务可能强调了无关细节，或增强破坏目标所需的信息。用线性探测、多任务/跨域基准和消融试验核查表征质量。

2. **问：对比学习的负样本选择为何重要？** 答：错误地把同类语义样本作为负例会形成 false negative；批量、温度、负例质量和增强强度都会影响表示。

## 7. 中等难度考试题（含解析）

1. **题：训练序列共有 1,000 个 token，若抽样 15% 作为掩码预测目标，期望多少个？** 解：期望 1000×0.15=150 个（独立随机采样时实际数量可浮动）。

2. **题：InfoNCE 正例相似度 2，两个候选负例相似度 1、0，τ=1，计算正例 softmax 概率与损失。** 解：p=e²/(e²+e¹+e⁰)≈7.389/11.107=0.665；−ln p≈0.407。分母约定包含正例和候选负例。
