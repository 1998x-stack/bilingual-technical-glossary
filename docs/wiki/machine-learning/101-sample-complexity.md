# Sample Complexity（样本复杂度）

> 领域：机器学习 · 专题：统计学习与泛化理论 · 定义、条件、推导与工程适用边界

## 1. 核心定义

样本复杂度（Sample Complexity）是学习算法为达到指定泛化误差与置信度所需的训练样本数量，通常写成 n(ε,δ,H)。它取决于假设类、分布/噪声假设、损失与学习目标，不能理解成训练任意模型所需的固定条数。

## 2. 形象理解

像测量一批零件的合格率：希望允许误差越小、保证越可靠，就需要更多独立抽检，而不是只增加同一零件的重复测量。

**类比的局限：**理论下界和上界所需假设不同；从同一患者复制许多记录不会使独立样本数量同比增加。

## 3. 技术原理与核心内容

在可实现二分类、有限假设类 H、iid 且存在零风险目标时，一致 ERM 的并合界给出 n≥[ln|H|+ln(1/δ)]/ε 的充分条件。一般不可实现（agnostic）设置还涉及超额风险与通常 1/ε² 量级。VC 维可替代有限类 log|H| 控制复杂度，但具体系数与 log 因子依定理而异。理论充分界不等于实际最小样本量，也不能直接处理概念漂移。

## 4. 工程实践与设计权衡

罕见故障检测需按设备或生产批次统计独立观测，再确定可接受漏报、误报和置信要求；分层报告正例数量与区间，避免把上百万重复传感器读数当作独立实验。

## 5. 关联知识与易混辨析

Sample Complexity 研究达到误差保证所需 n；Learning Curve 是经验观察样本量变化的得分；PAC Learning 指定误差与置信形式；VC Dimension 是控制容量的一种理论量。

## 6. 中等难度面试题（含参考答案）

1. **问：为何同一用户的 100 次重复交易不等于 100 个独立样本？** 答：事件存在用户内相关性，iid 理论前提可能不成立，有效样本量取决于组间结构。应分用户训练和验证并考虑聚类置信区间。

2. **问：理论样本复杂度上界为 500 就能保证工业上线只需 500 条数据吗？** 答：不能。界要求假设类、目标分布、标签噪声和独立性等前提；此外目标风险、置信度和训练算法都要与定理匹配。

## 7. 中等难度考试题（含解析）

1. **题：有限 H 有 20 个假设，ε=0.1、δ=0.05，在可实现一致 ERM 界下需要多少条样本？** 解：n≥(ln20+ln20)/0.1≈59.915，因此至少 60 条独立样本；这是充分界。

2. **题：保持 |H|、δ 不变，把 ε 从 0.2 改成 0.1，此充分界的样本要求倍数？** 解：分母减半，所需连续下界约翻倍；最终整数取上整可能有细微差别。
