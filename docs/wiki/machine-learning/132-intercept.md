# Intercept（截距）

> 领域：机器学习 · 专题：回归、分类与线性模型 · 数学原理、技术约束与工程实践

## 1. 核心定义

截距（Intercept）是线性预测器在全部输入特征取参考零值时的基线常数项，常写 b 或 β₀。它允许模型不必通过原点；当输入做中心化、类别基准编码或交互时，截距含义也会随之变化。

## 2. 形象理解

像价格表里的固定起步费：即使使用量为零，也可能有基础费用，之后各变量增加额外金额。

**类比的局限：**如果原始零值不可能出现，如年龄=0、收入=0 的组合，截距仅是数学外推值，不宜直接赋予真实业务解释。

## 3. 技术原理与核心内容

线性回归 ŷ=b+wᵀx；含截距且普通 OLS 时最优 b=ȳ−wᵀx̄。若把所有特征中心化到均值 0，截距约为训练目标均值。二分类 Logistic 的 b 是参考输入对应的 log-odds，基准概率为 sigmoid(b)，不是 b 本身。截距通常与正则系数分开处理，但不同 solver（例如合成偏置特征）可能有所差异，应核对 API 实现。

## 4. 工程实践与设计权衡

在保险风险模型里，一旦改变性别或地区类别的参考组，截距将发生变化；模型必须保存训练类别字典、特征中心化统计量和截距版本，并审查参考组的解释。

## 5. 关联知识与易混辨析

Intercept 为基准常量项，Coefficient 为各特征的增量权重；Bias 在神经网络中常指可训练偏置参数，在统计学中 Bias 还指估计的系统偏差，注意消歧。

## 6. 中等难度面试题（含参考答案）

1. **问：为什么给线性回归加入截距通常会降低训练 RSS？** 答：有截距的假设类包含 b=0 的无截距模型，所以不受其他约束时训练 RSS 不会更高；但泛化不保证改善。

2. **问：标准化输入后为什么截距可能改变而预测保持不变？** 答：坐标平移由截距吸收，权重按尺度调整；只要转换参数与新系数一致，预测函数可以保持相同。

## 7. 中等难度考试题（含解析）

1. **题：带截距模型 ŷ=b+2x，数据均值 x̄=3、ȳ=10，在 OLS 最优且斜率固定为 2 时 b 为多少？** 解：b=ȳ−2x̄=10−6=4。

2. **题：Logistic 模型截距 b=0 且 x=0，基线预测正类概率？** 解：σ(0)=0.5；若 b=ln3，则基线概率为 3/4。
