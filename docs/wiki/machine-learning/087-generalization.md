# Generalization（泛化）

> 领域：机器学习 · 专题：统计学习与泛化理论 · 数理条件、训练与泛化能力

## 1. 核心定义

泛化是从有限训练数据学到的预测规则在未参与训练且符合目标部署条件的新观测上仍保持有效表现的能力。它涉及对新样本、新实体、新时间或新领域的不同推广目标，不能仅由训练集高分断言。

## 2. 形象理解

像学生理解数学方法后能解没见过的新题，而不只是背熟练习答案。

**类比的局限：**真正“新题”的定义很重要：换了一道题但用了相同答案模板，可能仍是记忆；跨学校考试还包含分布变化。

## 3. 技术原理与核心内容

理论上可比较训练经验风险 R̂_S(h) 与目标期望风险 R_P(h)，并在 iid、容量和损失假设下研究 R_P(h) 的上界。工程上根据泛化目标选择 GroupSplit（新用户）、TemporalSplit（未来）或外部机构保留集；固定测试集只能估计该测试分布的表现。高训练准确率而显著较低的独立测试准确率通常警示泛化不足。

## 4. 工程实践与设计权衡

疾病预测应区分对同医院新患者泛化、对新医院泛化以及对未来诊疗流程泛化，并为每个目标设计对应保留数据。AUC 也要搭配阈值决策成本与校准检查。

## 5. 关联知识与易混辨析

Generalization 是能力与目标；Generalization Gap 是训练与评估差异；Distribution Shift 是分布改变的现象；Overfitting 是模型过度适配训练数据的一种失败模式。

## 6. 中等难度面试题（含参考答案）

1. **问：为什么随机分割同一用户的多笔记录不能证明新用户泛化？** 答：模型可利用用户稳定习惯或设备指纹，独立性被破坏；应以用户为组隔离训练和测试。

2. **问：如果未来月份性能下降，一定是过拟合吗？** 答：不一定，也可能是概念漂移、特征不可用、标注定义变化或新群体采样偏差；需要分布、质量与时间分析。

## 7. 中等难度考试题（含解析）

1. **题：模型在训练集准确率 98%，独立测试集准确率 88%，准确率差多少百分点？** 解：98%−88%=10 个百分点；需要进一步核实指标口径、样本量和独立性。

2. **题：某模型在 A 群 90% 准确、B 群 70%，部署中 A/B 各占 50%，总体准确率多少？** 解：0.5×0.9+0.5×0.7=0.8，即 80%；不能沿用训练集的群体比例计算。
