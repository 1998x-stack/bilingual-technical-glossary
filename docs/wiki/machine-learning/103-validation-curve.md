# Validation Curve（验证曲线）

> 领域：机器学习 · 专题：统计学习与泛化理论 · 定义、条件、推导与工程适用边界

## 1. 核心定义

验证曲线通过改变一个指定超参数、重复训练与交叉验证，比较训练及验证分数随参数变化的趋势。它协助识别过强约束、过大模型或过拟合区域，但一次仅扫一维不能揭示全部超参交互。

## 2. 形象理解

像调节收音机旋钮，同时记录音量和杂音，在不同旋钮值下找平衡，而不是不断增加训练样本。

**类比的局限：**最佳验证点在反复搜索后存在选择偏差，不能将同一条曲线的最高分当成未见测试的无偏结果。

## 3. 技术原理与核心内容

选择候选 λ₁,…,λ_K，对每个 λ 用相同合适 CV folds 拟合并计算 s_train(λ)、s_val(λ)。在正则化强度增加时，训练损失常上升而测试损失可能先降后升，具体要区分得分越高/损失越低的指标口径。`validation_curve` 只改变一个参数，其他参数与预处理应作为 Pipeline 固定；多维搜索宜 GridSearchCV/RandomizedSearchCV 并保留最终测试集。

## 4. 工程实践与设计权衡

对 Ridge α 在 [0.01,0.1,1,10,100] 扫描，展示每折的时间测试或组级分折结果，并审查尺度变换；不用测试集反复挑选最优 α，避免下游报告偏乐观。

## 5. 关联知识与易混辨析

Validation Curve 看某个超参对指标的影响；Learning Curve 看训练样本量；Grid Search 是搜索过程，可以包含曲线，但不等于一维曲线。

## 6. 中等难度面试题（含参考答案）

1. **问：为什么验证曲线通常建议在跨数量级的正则强度上取点？** 答：惩罚强度作用可能跨多个量级，线性均匀取值会错过低 α 区域；但应结合模型接口的超参定义与计算预算。

2. **问：为什么在 CV 前进行全量特征选择会让曲线失真？** 答：选择器已利用验证折标签，所有超参点被污染；必须把特征选择器置于每折重新拟合的 Pipeline。

## 7. 中等难度考试题（含解析）

1. **题：α=0.1、1、10 的验证 MSE 分别为 4、3、5，按 MSE 选择哪个？** 解：α=1，MSE=3 最低；最终评估应在未参与模型选择的独立测试集。

2. **题：验证准确率 0.91、训练准确率 0.99，准确率差是多少百分点？** 解：0.99−0.91=0.08，即 8 个百分点；这只是当前候选配置的观察差距。
