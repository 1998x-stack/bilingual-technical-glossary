# Inductive Bias（归纳偏置）

> 领域：机器学习 · 专题：统计学习与泛化理论 · 推导、理论前提与工程设计

## 1. 核心定义

归纳偏置是学习算法在仅观察有限训练样本时为预测未见数据而引入的假设、偏好或结构约束。它可以是线性可加、局部平滑、稀疏、卷积平移等变、低维表征或模型类选择；没有归纳偏置，有限样本无法唯一决定所有未见点的行为。

## 2. 形象理解

像只见过几只天鹅之后，要预测下一只的颜色，必须在“观察到的案例具有某种代表性”的假定下外推。

**类比的局限：**偏置不必然错误或有害；偏好与目标分布匹配时会帮助泛化，不匹配时产生系统性错误。它不等于偏差—方差分解中的数值 Bias。

## 3. 技术原理与核心内容

设数据 S 与多个同样匹配 S 的假设 h₁,h₂。学习器 A(S) 通过 H、正则项 Ω、初始化、优化路径或训练数据增强等机制在它们间选择，即归纳偏置。线性回归优先线性组合；CNN 通过局部共享权重引入平移结构；KNN 倾向邻域相似。No-Free-Lunch 类型结果提醒：不指定目标问题分布，对任意算法无法保证普遍优越。偏置通常结合统计假设而不是固定标签真值。

## 4. 工程实践与设计权衡

用时间序列预测生产线能耗时，物理约束和非负性可能比无限自由函数空间更稳健；需要通过跨设备和时间验证检查先验是否符合实际。若强制错误的单调性，模型即使训练顺利也会持续欠拟合。

## 5. 关联知识与易混辨析

Inductive Bias 是算法设计的先验偏好；Statistical Bias 是预测均值与真实目标差；Regularization 是表达归纳偏置的手段之一；Capacity 是可表达函数集合规模。

## 6. 中等难度面试题（含参考答案）

1. **问：为什么“没有偏置的通用模型”不一定更好？** 答：有限数据无法指定未见输入的全部输出。没有针对任务的假设可能导致高方差或不可辨识；合适偏好帮助泛化，但跨域可能失效。

2. **问：模型在训练上拟合相同却跨域表现不同，如何利用归纳偏置解释？** 答：两模型可能偏好不同的函数或不变性；目标域只保持其中某些结构，需通过业务机制和外部测试检查而不是仅比较训练误差。

## 7. 中等难度考试题（含解析）

1. **题：已知 f(x)=ax+b 与 f(x)=ax²+b 都穿过 x=0、y=1 的训练点，是否仅凭这一点能选出唯一未见 x=2 的预测？** 解：不能：b=1，a 任意时两族都拟合该点；选线性或平方族是归纳偏置，更多训练信息或先验约束才可识别。

2. **题：算法 A 默认预测常量 0，B 默认预测常量 1，在完全没有观测样本且目标对二者无任何偏好的情况下，能证明 A 全分布更好吗？** 解：不能。构造所有目标为 1 的分布使 B 完美、A 全错；反过来构造全 0 则 A 更好。
