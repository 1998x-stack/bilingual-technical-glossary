# Overfitting（过拟合）

> 领域：机器学习 · 专题：统计学习与泛化理论 · 数理条件、训练与泛化能力

## 1. 核心定义

过拟合是学习器过度适应训练样本的偶然噪声、重复结构或特有模式，造成训练表现很好但独立目标数据表现变差。它通常与容量、噪声、样本量、训练轮次和选择流程有关，不是“模型复杂”这一事实的自动同义词。

## 2. 形象理解

像学生记住历年卷子的每一道答案，却不能理解换数字后的同类题目。

**类比的局限：**若评估测试集已泄漏，即使分数很高也可能掩盖过拟合；过拟合还可能发生在反复试验验证集的超参数选择阶段。

## 3. 技术原理与核心内容

在固定训练/验证协议下，随着复杂度上升，训练风险常继续下降，而验证风险可能先降后升。控制手段包括增加有效独立样本、数据增强、L1/L2 正则、限制树深、早停和减少超参搜索的选择偏差。对时间/用户相关样本需使用合适划分；简单数据泄漏会制造比过拟合更严重的假象。

## 4. 工程实践与设计权衡

视觉模型训练 99.9%、跨相机测试 70% 时，应先排除相机型号分布偏移与近重复图像，再检验数据增强、模型容量和正则化；评估目标是跨设备而非同设备随机切分。

## 5. 关联知识与易混辨析

Overfitting 是低训练损失而泛化下降的现象；Underfitting 是学习不足；Data Leakage 是信息边界违规，两者可能同时存在但不是同一机制。

## 6. 中等难度面试题（含参考答案）

1. **问：为什么训练精度持续提高但验证精度下降时应该关注模型选择偏差？** 答：验证集反复被挑选与调参也会产生适配，最佳 checkpoint 的开发指标不是无偏终极结果；需封存测试集，必要时嵌套 CV。

2. **问：如何区分训练时欠拟合与过拟合？** 答：同时检查训练和验证损失：两者均高偏欠拟合；训练低、验证显著高偏过拟合；再核实评估与数据质量。

## 7. 中等难度考试题（含解析）

1. **题：训练错误率 1%，验证错误率 12%，二者差多少百分点？** 解：12%−1%=11 个百分点，是明显训练/验证差距但仍需检查划分是否合乎目标。

2. **题：模型随训练轮次的验证损失为 [0.42,0.30,0.28,0.35]，若按最小验证损失早停选哪轮？** 解：第三轮（从 1 开始），验证损失 0.28；最后仍需未参与早停的测试集作正式评估。
