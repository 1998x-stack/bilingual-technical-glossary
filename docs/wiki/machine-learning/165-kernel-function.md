# Kernel Function（核函数）

> 领域：机器学习 · 专题：支持向量机、核方法与近邻 · 数学形式、优化条件与独立评估

## 1. 核心定义

核函数（Kernel Function）是定义在两个输入对象上的实值函数 K(x,z)，在正半定核设置中可表示为某特征空间的内积 ⟨φ(x),φ(z)⟩。它定义算法眼中的相似结构，并通过 Gram 矩阵参与训练；核值大不一定表示原始距离近或物理语义相同。

## 2. 形象理解

像为资料库设计一套可比较不同对象的‘隐含共同特征分数’，而不是在原始坐标里仅测一把直尺。

**类比的局限：**核值可以为负（如线性内积），核对角线不一定是 1；‘相似度’一词在数学上不自动要求非负、对称或 PSD。

## 3. 技术原理与核心内容

对任意样本 x₁,…,x_n 构造 Gram 矩阵 G_ij=K(x_i,x_j)。有效实 PSD 核要求 G 对称，且对任意实系数 c 满足 cᵀGc≥0。常见线性核 K=xᵀz、非负整数度多项式核 (γxᵀz+r)^d（适当 γ,r）、RBF 核 exp(−γ||x−z||²)（γ>0）。合法核可相加、非负缩放等构造新核，但自定义函数不能仅凭名称判为合法。

## 4. 工程实践与设计权衡

分子表征 SVM 可以从线性与 RBF 核作简单对照，检查 Gram 数值精度、train/test 核矩阵维度和参数缓存；线下独立验证目标指标与在线成本，不把训练核相似度最高的样本直接当因果解释。

## 5. 关联知识与易混辨析

Kernel Function 是数学函数；Kernel Trick 是用核内积替换的计算策略；Cosine Similarity 是角度相似性，在归一化且适当定义时可联系线性核，但与 RBF 的距离衰减机制不同。

## 6. 中等难度面试题（含参考答案）

1. **问：为什么 Gram 矩阵半正定是核 SVM 中重要性质？** 答：它使核可表示成内积并保证典型 SVM 对偶二次项半正定，关联凸优化；任意相似度矩阵可能不满足。

2. **问：为什么 RBF 核的 K(x,x)=1 而线性核一般不为 1？** 答：RBF 由零距离 exp(0) 得 1；线性核自相似为 ||x||²，随输入范数变化。

## 7. 中等难度考试题（含解析）

1. **题：线性核 x=(1,2)、z=(3,4)，K 值多少？** 解：K=xᵀz=1×3+2×4=11。

2. **题：对称核 Gram=[[1,2],[2,1]] 是否半正定？** 解：否，特征值 3 和 −1，存在负特征值；因此不能作为通常的 PSD Gram 使用。
