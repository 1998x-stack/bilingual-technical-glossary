# Decision Tree（决策树）

> 领域：机器学习 · 专题：树模型与集成学习 · 树结构、训练准则与统计边界

## 1. 核心定义

决策树（Decision Tree）是一类通过递归划分输入特征空间形成分段常数或简单预测规则的监督模型。分类叶节点通常按训练类别频率给出概率，回归叶节点按目标损失选均值或中位数；树可解释但对小扰动可能不稳定。

## 2. 形象理解

像按一张问答流程图处理贷款申请：先问收入是否超过阈值，再问是否逾期，最后落到某个决策结果。

**类比的局限：**流程中的问题是从训练样本贪心挑出来的，不等于因果规则；深树可能记住训练细节而不能适应新用户。

## 3. 技术原理与核心内容

在节点 t 对候选特征 j 与阈值 s 形成左右子集，最小化加权不纯度 (n_L/n_t)H(L)+(n_R/n_t)H(R) 或最大化父子不纯度减少。分类 H 可为 Gini 或 entropy，回归常用 MSE/MAE。CART 通常构造二叉分裂，贪心局部最优不保证整树全局最优。max_depth、min_samples_leaf、ccp_alpha 控制复杂度；连续变量阈值与缺失值路径行为需依具体库版本检查。

## 4. 工程实践与设计权衡

电商退款拒付预测可用浅树给合规团队提供可读规则，但也应在不同时间和客户群测试分裂稳定性，监控稀有类别导致的微小叶节点和新输入缺失路径。

## 5. 关联知识与易混辨析

Decision Tree 是整个分段模型；Root/Internal/Leaf Node 是结构元素；Random Forest 是并行随机树集成；GBDT 是逐轮提升树集成，不能等同单棵树。

## 6. 中等难度面试题（含参考答案）

1. **问：为什么不应把某决策树第一层阈值解释成真正的业务因果规律？** 答：分裂依据训练集的风险减少，可能受到相关变量、样本偏差与泄漏影响；它只是预测规则。

2. **问：为什么单棵无约束深树方差通常较大？** 答：小训练变化可能改变顶层分裂并影响大量下游节点，产生不稳定预测；可限制深度、剪枝或用集成降低方差。

## 7. 中等难度考试题（含解析）

1. **题：父节点有 20 条训练样本，左右子节点分别 8 和 12，按训练条数计算加权不纯度权重？** 解：左 8/20=0.4，右 12/20=0.6；实际有样本权重时需用加权计数。

2. **题：一棵树的根在第 0 层，两条样本路径各经 2、4 次分裂到叶，树最大深度是多少？** 解：最大深度为 4（按根深度 0 和沿边数定义）；叶的数量不能直接据此唯一确定。
