# Robust Scaling（稳健缩放）

> 领域：机器学习 · 专题：数据预处理与特征工程 · 数理解释和工程实用边界

## 1. 核心定义

稳健缩放以训练数据的中位数为位置、四分位距 IQR=Q3−Q1 为尺度进行转换，减少少数离群观测对缩放参数的影响。它不会自动剪除异常数据，也不能保证结果被限制在固定区间。

## 2. 形象理解

班级成绩用中位分和中间 50% 分数跨度建立标尺，让极高分不独占整个量尺。

**类比的局限：**若 IQR 为零或列分布高度离散，量尺可能失去意义。

## 3. 技术原理与核心内容

典型公式 z=(x−median_train)/(Q3_train−Q1_train)，分位数由训练折估计。RobustScaler 的分位数范围可配置，unit_variance 选项会改变数值尺度。稀疏数据中心化依然有密集化风险；异常值只是降低其对参数的影响，转换后仍可能远超常规范围。

## 4. 工程实践与设计权衡

长尾消费金额预测中比较 RobustScaler 与 StandardScaler 的分层验证得分和模型收敛速度，并监控过高金额是业务真实值还是币种转换错误。

## 5. 关联知识与易混辨析

RobustScaler 对位置与尺度统计稳健；Winsorization 修改样本值；MinMaxScaler 依赖极值，与稳健方法不同。

## 6. 中等难度面试题（含参考答案）

1. **问：为什么 RobustScaler 不能替代离群检测？** 答：只使用稳健统计量进行缩放，不改变数据本身；极端观测依然存在，可能得到很大的 z 值。

2. **问：当 IQR=0 时如何处理？** 答：需要实现定义的安全尺度或另选特征处理；可能因为常数列或离散集中，需判断该列是否有业务信息。

## 7. 中等难度考试题（含解析）

1. **题：median=10，Q1=6，Q3=14，x=18 的 z 值？** 解：IQR=8，(18−10)/8=1。

2. **题：沿用相同参数，极值 x=98 的 z 值？** 解：(98−10)/8=11，说明稳健缩放没有裁剪异常值。
