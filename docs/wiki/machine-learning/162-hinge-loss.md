# Hinge Loss（合页损失）

> 领域：机器学习 · 专题：支持向量机、核方法与近邻 · 数学形式、优化条件与独立评估

## 1. 核心定义

合页损失（Hinge Loss）是最大间隔分类中常用的凸替代损失，对 y∈{−1,+1} 和连续决策得分 f 定义 L(y,f)=max(0,1−yf)。它只在功能间隔低于 1 时施加惩罚，既覆盖错分样本，也会惩罚虽然判对但离边界太近的样本。

## 2. 形象理解

像要求每次射箭不只是落在正确靶区，还必须留出一定的安全距离；一旦越过安全线，就不再为更远而额外奖励。

**类比的局限：**合页损失不是概率负对数似然，也不是 0–1 错误数；正确分类但 yf=0.5 仍有正的损失。

## 3. 技术原理与核心内容

令 m=yf，若 m≥1 则 L=0；否则 L=1−m。对 f 的分段导数在 m<1 时为 −y，m>1 时为 0，m=1 处不可微但有次梯度。结合 L2 正则的目标可写成 0.5||w||²+CΣ_i max(0,1−y_if_i)。Squared Hinge 为 max(0,1−m)²，与普通 Hinge 在违规处罚及优化性质上不同。标准化、惩罚系数与损失 reduction 的约定需核对具体 solver。

## 4. 工程实践与设计权衡

邮件分类中对模型决策函数使用 hinge loss 训练，但线上若要求‘垃圾邮件概率’，需另行校准；对 C 的选择在训练折内进行并评估少数类召回。

## 5. 关联知识与易混辨析

Hinge Loss 优化分类的安全间隔；Log Loss 优化概率意义下的似然目标；0–1 Loss 仅计算类别是否错；SVR 的 ε-insensitive Loss 具有两个方向的容忍区间，并非 Hinge。

## 6. 中等难度面试题（含参考答案）

1. **问：为什么正确分类的样本也可能有正的 hinge loss？** 答：模型只要求得分符号与 y 一致还不够，若 0<yf<1，仍违反规范功能间隔，损失为 1−yf。

2. **问：普通 Hinge 与 Squared Hinge 对严重错分惩罚哪个更强？** 答：当违反量 1−yf>1 时，平方合页惩罚增长更快；两者对离群点敏感性不同。

## 7. 中等难度考试题（含解析）

1. **题：y=+1、f=0.4，合页损失是多少？** 解：max(0,1−0.4)=0.6，虽然分类符号正确。

2. **题：y=−1、f=+2，合页损失是多少？** 解：yf=−2，L=max(0,1−(−2))=3，是严重错分。
