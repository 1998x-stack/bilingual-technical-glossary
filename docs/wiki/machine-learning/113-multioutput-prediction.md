# Multioutput Prediction（多输出预测）

> 领域：机器学习 · 专题：回归、分类与线性模型 · 监督目标、优化公式和工程条件

## 1. 核心定义

多输出预测（Multioutput Prediction）是同时预测一个样本的多个目标变量的任务总称，包括多目标连续回归、多输出离散分类和可能相关的结构化输出。多个输出不等同多标签：前者可以是多维连续数值，后者通常是一个样本的一组二值类别归属。

## 2. 形象理解

像医生同时预测病人未来的血压、心率和血糖，而不是分别建立完全无关的病人档案。

**类比的局限：**不同输出的单位、噪声和损失尺度可能差别很大，直接平均平方误差会让数值范围大的目标支配训练。

## 3. 技术原理与核心内容

令 Y∈R^(n×m) 表示 m 个连续目标，预测 f(x)∈R^m；可使用 m 个独立估计器，或共享表示加多头输出。多目标损失可设 L=Σ_{j=1}^m α_j·L_j，α_j 需按业务代价或单位解释。对于分类输出，MultiOutputClassifier 是对各个目标分别训练分类器，并非单标签 Softmax；需要保留每个目标自己的 classes_。

## 4. 工程实践与设计权衡

多传感器故障预测可联合预测未来振动和温度，但温度单位与振动幅度必须做合理尺度调整，评估各输出的 MAE、覆盖率和缺失机制，不能只报告合并平均。

## 5. 关联知识与易混辨析

Multioutput 是输出维度概念；Multilabel 是多个可并存的二值标签；Multiclass 是单目标多互斥类别；MultiTask Learning 是多个任务的共享学习设计，不自动等于多输出接口。

## 6. 中等难度面试题（含参考答案）

1. **问：什么条件下联合训练可能优于独立模型？** 答：任务共享可迁移的预测结构、数据相似且共享表征有效；任务冲突或尺度差异大时联合训练也可能产生负迁移。

2. **问：为什么多输出损失需要显式权重？** 答：多个输出的量纲、可观测性与业务代价不同，未加权的数值损失可能由最大量纲的目标主导。

## 7. 中等难度考试题（含解析）

1. **题：100 条样本同时预测 3 个连续目标，Y 的常见形状是什么？** 解：(100,3)，共有 300 个目标标量；如果某些目标缺失还需要单独掩码处理。

2. **题：两个输出 MAE 分别为 2、6，若按等权简单平均，平均输出 MAE 为多少？** 解：(2+6)/2=4；此数字只有在单位和权重解释一致时有意义。
