# Data Augmentation（数据增强）

> 领域：机器学习 · 专题：数据预处理与特征工程 · 定义、原理、数学与真实工程边界

## 1. 核心定义

数据增强通过任务语义允许的变换构造新的训练样本，以提升模型对合理扰动的稳健性与泛化能力。常见变换包括图像裁剪/旋转、文本有限扰动、音频噪声以及 Mixup；其前提是标签应随变换正确保持或按规则变化。

## 2. 形象理解

像教学生辨认同一张路牌：看过不同光照、摄像角度的路牌后，遇到新照片更可能认出它。

**类比的局限：**把数字 6 旋转 180° 可能变成 9，过强增强改变了真实标签；同一原图生成的副本不可穿越训练和测试。

## 3. 技术原理与核心内容

可将训练目标写成 E_{(x,y)∼D_train,T∼A}[ℓ(f(Tx),T_y(y))]；对于标签保持变换 T_y(y)=y，Mixup 则以 λx_i+(1−λ)x_j 与 λy_i+(1−λ)y_j 构造软标签。图像增强参数只在训练模式启用；验证与测试采用固定确定性变换。增强不能解决选择偏差或缺少的目标人群。

## 4. 工程实践与设计权衡

医疗图像先按患者 ID 拆分，再只对训练影像生成旋转/颜色增强；应核查左右方向是否承载诊断意义，评估增强后的分布是否贴近采集设备。

## 5. 关联知识与易混辨析

Data Augmentation 通过合理变换增加多样性；Resampling 改变抽样或重复权重；SMOTE 在特征空间插值少数类，不一定保持数据可行性。

## 6. 中等难度面试题（含参考答案）

1. **问：为什么必须先拆分数据再做增强？** 答：增强副本高度相关，若与原图落入测试集，模型可能记住来源而获得虚高性能；应按患者/原图组级分隔。

2. **问：如何判断某种增强合理？** 答：必须满足任务标签规则及实际部署可能遇到的扰动，按独立验证集比较，关注少数类、关键结构和伪影。

## 7. 中等难度考试题（含解析）

1. **题：Mixup 中 λ=0.25，两个 one-hot 标签分别 [1,0] 和 [0,1]，软标签是什么？** 解：0.25×[1,0]+0.75×[0,1]=[0.25,0.75]，总和为 1。

2. **题：训练 100 张独立原图，每张生成 3 张增强副本（保留原图），共有多少条训练记录？** 解：100×(1+3)=400 条；并非 400 个独立来源样本。
