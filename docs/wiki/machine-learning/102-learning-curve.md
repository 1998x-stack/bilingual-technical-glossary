# Learning Curve（学习曲线）

> 领域：机器学习 · 专题：统计学习与泛化理论 · 定义、条件、推导与工程适用边界

## 1. 核心定义

学习曲线是将模型训练指标和验证指标作为训练样本量的函数绘制的诊断图。它用来判断增加独立数据是否可能改善泛化，以及模型目前更接近高偏差还是高方差情形；与随 epoch 绘制损失的优化曲线不完全相同。

## 2. 形象理解

像观察学生在练习 20、50、100、500 道题时的模考表现，判断多给练习题是否仍有收益。

**类比的局限：**若数据持续来自相同偏置样本框，再增加数量也未必代表新医院、新设备或未来时间的表现。

## 3. 技术原理与核心内容

固定模型超参和可信切分，对不同训练规模 n_k 重拟合，得到 R_train(n_k) 与 R_val(n_k)，可按折平均并给出离散度。典型高偏差：训练与验证表现接近但都差；高方差：训练优、验证差且差距随 n 增加可能缩小。scikit-learn `learning_curve` 采用交叉验证训练大小序列；若是时序/组相关数据须自定义适用 CV，数据增强后的副本不等于独立样本增量。

## 4. 工程实践与设计权衡

比较工业异常检测在 100、500、2000 个独立设备上的学习曲线，而不是仅按传感器行数增长；额外记录误报成本、稀有类别覆盖及时间窗，以免不同规模代表不同分布。

## 5. 关联知识与易混辨析

Learning Curve 横轴是训练样本量；Validation Curve 横轴是超参数；Training Curve 常指优化迭代步数/epoch；三者不能靠图形外观混同。

## 6. 中等难度面试题（含参考答案）

1. **问：训练与验证曲线都在较差得分处重合，为什么单纯加数据可能无效？** 答：说明当前假设类或特征不能解释目标，偏差或优化问题更重要；先排查标签质量、欠拟合、正则过强和特征设计。

2. **问：训练/验证差距随数据量增加变小就一定代表模型已达到目标吗？** 答：不一定，两者可能同时很差，且验证分布不代表部署环境；必须比较绝对指标与可信测试集。

## 7. 中等难度考试题（含解析）

1. **题：训练量从 200 到 800、验证准确率从 0.70 升至 0.82，绝对增加多少百分点？** 解：增加 0.12，即 12 个百分点；无法仅由两个点可靠外推最终上限。

2. **题：两个规模下验证错误率分别 0.24 与 0.18，降低的相对比例？** 解：(0.24−0.18)/0.24=0.25，即相对下降 25%，绝对下降 6 个百分点。
