# Discriminative Model（判别模型）

> 适用领域：机器学习 · 专题：基础概念与学习范式 · 实践、理论与边界

## 1. 核心定义

判别模型主要学习给定输入 x 时的条件预测关系 p(y|x)、决策分数或区分类别的边界，重点是把不同输出区分开来。判别模型不必建立完整的输入数据生成分布 p(x)，但可以输出经过校准的条件概率。

## 2. 形象理解

像法官观察证据并判断属于哪种案件，而非编写所有可能产生证据的过程。

**类比局限：**能给出高置信类别不代表理解数据如何生成，也不代表决策概率一定校准。

## 3. 技术原理与核心内容

逻辑回归通过 z=wᵀx+b、p(y=1|x)=σ(z)=1/(1+e^−z) 建模二类条件概率，典型以交叉熵拟合；SVM 可直接优化间隔型判别函数。多类情形可用 softmax。其训练关注决策风险，通常不需要求出 p(x)。阈值应由误判成本、概率校准及部署基线共同决定。

## 4. 工程实践与设计权衡

欺诈审核用判别模型打分，再由规则执行冻结与人工复审。风险类别发生变化时应重校准并调整阈值；避免用准确率替代不同错误的业务成本。

## 5. 关联知识与易混辨析

判别模型直接估计 p(y|x) 或分数；生成式分类器可先估计 p(x|y) 与 p(y)，再用贝叶斯规则推导后验。两类方法没有普遍优劣顺序。

## 6. 中等难度面试题（含参考答案）

1. **问：为何逻辑回归叫回归却常用于分类？** 答：模型回归的是 log-odds 的线性预测分数，通过 sigmoid 输出类别概率，用阈值作分类；名称来自参数化的回归形式。

2. **问：当误报和漏报代价不同，能否默认概率阈值为 0.5？** 答：不能。需基于校准概率与业务代价最小化期望损失，评估不同人群/时段稳定性；未经校准的分数更不能直接当风险概率。

## 7. 中等难度考试题（含解析）

1. **题：二分类逻辑回归的 logit z=ln 3，正类概率 p 是多少？** 解：p=1/(1+e^−ln3)=1/(1+1/3)=0.75。对应正负 odds 为 3:1。

2. **题：某模型预测 100 条为正，其中真阳性 80、假阳性 20；正类精确率是多少？** 解：Precision=TP/(TP+FP)=80/(80+20)=0.8。此信息不足以求召回率，需要 FN。
