# Group Split（分组划分）

> 适用领域：机器学习 · 专题：数据、样本与数据集划分 · 验证协议与模型选择

## 1. 核心定义

分组划分依据用户、设备、患者或其他相关实体，将同一组的所有记录放在同一训练或测试/验证子集中，以估计对未见分组对象的泛化。其核心约束是组标识不能跨子集。

## 2. 形象理解

同一人的多张照片不能一部分用于练习、一部分用于考‘识别新的人’。

**类比局限：**按组隔离并非万能：如果预测的是同一个人在未来的变化，还必须做时间限制。

## 3. 技术原理与核心内容

设 g_i 为组标签，对每一折要求 groups_train∩groups_test=∅；GroupKFold 让每组只在一次验证折出现，但各折样本数可不完全一致。GroupShuffleSplit 以组为抽样单位。组与类别同时需要均衡时可考虑 StratifiedGroupKFold，但约束可能相互冲突。

## 4. 工程实践与设计权衡

医疗疾病预测按患者 ID 做组级验证；一人多次影像不可跨折。生产目的是新医院泛化时，则应改按医院 ID 做更粗粒度的组验证。

## 5. 关联知识与易混辨析

Group Split 按相关实体约束划分；Stratified Split 保留类别比例；Temporal Split 保持时间因果顺序。三种目标可叠加但存在不可满足的场景。

## 6. 中等难度面试题（含参考答案）

1. **问：按用户分组后某折类比例失衡，可以随便打散组来修复吗？** 答：不应破坏评估目标的实体隔离。可尝试 StratifiedGroupKFold、重新设计折数、扩大数据并明确剩余误差。

2. **问：如何选择分组键？** 答：与部署时真正新出现、需要独立泛化的对象一致，例如用户、医院、设备或实验批次。错误的键会高估性能。

## 7. 中等难度考试题（含解析）

1. **题：4 位患者各 5 次就诊，用 GroupKFold 分成 4 折，理想每折验证就诊记录数？** 解：每折 1 位患者×5=5 条，训练 15 条，且每位患者只在一次验证折出现。

2. **题：用户 A 训练中有 7 条，测试中又有 3 条，同一用户出现造成了什么？** 解：组交集非空（至少 1 组），违反新用户泛化的 Group Split 协议；行级不重复仍然会泄漏用户稳定特征。
