# Bias–Variance Tradeoff（偏差-方差权衡）

> 领域：机器学习 · 专题：统计学习与泛化理论 · 数理条件、训练与泛化能力

## 1. 核心定义

偏差—方差权衡刻画预测器在不同训练样本抽取下的系统性偏离与随机波动之间的关系。在平方损失回归、固定 x 和明确噪声模型时可以做精确误差分解；在其他损失和现代过参数化模型下需重新审视，不能当作永远单调的铁律。

## 2. 形象理解

像射箭：箭簇总偏离靶心是偏差大，箭落点四散是方差大；理想情况是既贴近靶心又较集中。

**类比的局限：**射箭类比隐去不可约的标签噪声和分布移位。模型更复杂不必然在所有数据规模下方差都单调上升。

## 3. 技术原理与核心内容

假设 Y=f*(x)+ε 且 E[ε|x]=0，Var(ε|x)=σ²，在固定 x、对训练集 S 取随机性，E[(Y−h_S(x))²]=Bias(x)²+Var_S(h_S(x))+σ²，其中 Bias(x)=E_S[h_S(x)]−f*(x)。前两项可通过模型类、正则、样本量改变，最后一项为此噪声模型下不可约项；交叉验证衡量总预测性能而不是直接给出偏差与方差独立估计。

## 4. 工程实践与设计权衡

小样本工业标定可从简单线性模型到高阶多项式逐级比较：简模型可能系统偏离，高阶模型随数据小改动剧烈波动。可用学习曲线和重复采样评估稳定性；在非独立样本下应按设备分组。

## 5. 关联知识与易混辨析

Bias 是预测均值偏离真函数；Variance 是模型随训练集波动；噪声项独立于可约的模型误差；Inductive Bias 是算法设计的先验偏好，不等于统计 bias 值。

## 6. 中等难度面试题（含参考答案）

1. **问：为什么不能用一套测试集上的 MSE 唯一确定偏差和方差各占多少？** 答：分解需要对不同训练集的模型预测取期望，单次模型输出无法辨识其跨样本随机波动，也无法在未知真函数时直接估计 Bias。

2. **问：正则化如何影响偏差和方差？** 答：在经典设置中增强正则通常收缩参数、提高系统偏差并降低训练样本波动，但具体风险曲线取决于模型和分布，不能机械外推。

## 7. 中等难度考试题（含解析）

1. **题：某点真函数值为 10，不同训练集模型预测均值为 12，预测方差为 3，噪声方差为 1；平方误差期望是多少？** 解：Bias²=(12−10)²=4，总=4+3+1=8，要求满足给定加性零均值噪声假设。

2. **题：模型 A 的 Bias²=1、Variance=5，模型 B 的 Bias²=3、Variance=2，噪声同为 1；哪个期望平方误差较小？** 解：A 总误差 1+5+1=7，B 为 3+2+1=6，因此按题设选 B。
