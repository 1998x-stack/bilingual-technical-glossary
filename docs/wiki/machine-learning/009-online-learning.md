# Online Learning（在线学习）

> 适用领域：机器学习 · 专题：基础概念与学习范式 · 术语机制、工程边界与评价

## 1. 核心定义

在线学习是样本按时间逐步到来时，模型随每条或每小批新数据增量更新的范式。它关注顺序更新的计算成本、时效与累积预测损失；不等同“在线服务”或“联网训练”。

## 2. 形象理解

像每天收到新试卷就调整答题方法，不必等整学期所有试卷凑齐后重学。

**类比局限：**快速学习也可能快速吸收异常与污染数据；在线更新与业务请求实时可见是两个独立问题。

## 3. 技术原理与核心内容

在线梯度下降在时刻 t 接收样本与损失 ℓ_t 后执行 θ_{t+1}=θ_t−η_t∇ℓ_t(θ_t)，常用 regret_T=Σ_t ℓ_t(θ_t)−min_θΣ_tℓ_t(θ) 衡量相对最佳固定决策的累积损失。真实系统还需处理延迟标签、样本顺序、回放缓冲、漂移检测和模型版本回滚。

## 4. 工程实践与设计权衡

广告点击模型可按小时增量更新，但点击/转化反馈常有延迟；训练队列需要事件时间、去重、异常样本隔离和回滚策略，不能把未完成订单都直接标为负例。

## 5. 关联知识与易混辨析

在线学习按增量更新定义；离线学习按固定数据快照周期训练。实时推断可以使用离线模型，在线训练模型也可以离线批量推断。

## 6. 中等难度面试题（含参考答案）

1. **问：概念漂移与数据污染如何区分？** 答：漂移反映真实目标机制改变，污染来自记录故障或攻击等异常。检查特征/标签来源、时间趋势、分组误差与回放数据，不应见到指标波动就立即自训练。

2. **问：为何在线学习要特别重视延迟标签？** 答：当前时刻观察不到最终结果会产生错误负例、选择偏差。可采用延迟回填、成熟窗口与校正权重，并记录事件时间而非只用处理时间。

## 7. 中等难度考试题（含解析）

1. **题：参数 θ=1，梯度 g=−2，学习率 η=0.1，做一次在线梯度下降。** 解：θ_new=1−0.1×(−2)=1.2。使用的是当前损失在 θ=1 处的梯度。

2. **题：某在线算法三轮损失 1、2、1；对照最优固定参数三轮损失 0.5、1、0.5，计算静态 regret。** 解：Σ算法=4，Σ对照=2，regret=2；需明确对照确是所给函数类内最优固定决策。
