# Leaf Node（叶节点）

> 领域：机器学习 · 专题：树模型与集成学习 · 树结构、训练准则与统计边界

## 1. 核心定义

叶节点（Leaf Node）是决策树中无子节点的终点区域，样本沿路径落入叶后由该叶存储的输出值或类别分布产生预测。叶节点的样本数、纯度和稳定性直接影响模型在稀疏区域的可靠程度。

## 2. 形象理解

像故障排查流程图最后的处理建议框：输入一路回答判断后，终于得到一个诊断类别或数值估计。

**类比的局限：**一个很纯的叶可能只有一条训练记录，这未必意味着预测可靠；类别概率 100% 可能只是小样本极端值。

## 3. 技术原理与核心内容

分类树叶 l 的典型概率估计为 p̂(k|l)=n_{lk}/n_l（有样本权重时改为权重比例）；回归树平方损失下输出叶内训练目标均值，绝对损失下输出中位数。叶区域由路径上的所有阈值交集定义。min_samples_leaf 可限制估计不稳定；但稀有群体、缺失分支和样本权重仍会改变有效支持。

## 4. 工程实践与设计权衡

房价树对只有两套房的叶做预测容易受偶然成交影响。工程上可限制叶最小样本数、启用剪枝和分层回测，并对低支持叶标记预估不确定性或回退到组平均。

## 5. 关联知识与易混辨析

Leaf Node 是最终输出结构，不再使用 split criterion 划分；Internal Node 决定路径；Random Forest 融合多棵树叶预测，并不直接等价单树叶频率。

## 6. 中等难度面试题（含参考答案）

1. **问：为什么叶内类别占比不必然是已经校准的概率？** 答：叶内训练样本可能小、存在采样偏差或过拟合，频率不保证在独立部署数据上的发生率；需单独验证校准。

2. **问：增大 min_samples_leaf 有何偏差—方差取舍？** 答：通常减少叶区域的偶然分裂和预测波动，但可能合并不同条件规律，导致欠拟合；应在训练 CV 中选取。

## 7. 中等难度考试题（含解析）

1. **题：叶里有 8 个正例和 2 个负例，未加权正类预测概率是多少？** 解：8/(8+2)=0.8，分类标签通常选正类。

2. **题：回归叶有目标 [2,4,8]，平方误差最优常数预测值是多少？** 解：均值 (2+4+8)/3=14/3≈4.667；如果以绝对误差为目标，中位数为 4。
