# Support Vector Regression (SVR)（支持向量回归 · SVR）

> 领域：机器学习 · 专题：支持向量机、核方法与近邻 · 数学、工程实践及邻域检索

## 1. 核心定义

支持向量回归（Support Vector Regression，SVR）是将 SVM 的间隔思想扩展到连续目标的回归算法：希望预测函数尽量平滑，并使尽可能多的训练观测落在宽度为 ε 的零损失容忍管内。超出管道的误差才按偏离部分受罚，C 控制其代价。

## 2. 形象理解

像为温度预测画一条允许上下误差各 ε 度的通道，落在通道里的小偏差不追究，越界才支付惩罚。

**类比的局限：**ε 不是模型的预测置信区间或概率覆盖保证；误差管的合适尺度取决于 y 的单位与实际误差成本。

## 3. 技术原理与核心内容

SVR 原始目标 min_{w,b,ξ,ξ*} 0.5||w||²+CΣ_i(ξ_i+ξ_i*)，约束 y_i−f(x_i)≤ε+ξ_i、f(x_i)−y_i≤ε+ξ_i*，ξ_i,ξ_i*≥0。对应 ε-insensitive loss L_ε(y,f)=max(0,|y−f|−ε)。核化时 f(x)=Σ_{i∈SV}(α_i−α_i*)K(x_i,x)+b。改变 C、ε、gamma 影响支持向量数、误差与训练/预测成本；标准 `SVR` 的核求解在样本很大时较昂贵。

## 4. 工程实践与设计权衡

能源负荷预测可基于传感器标准化、严格时间切分，比较 LinearSVR、RBF SVR 和 Ridge 的 MAE、P95 延迟；小误差在 ε 管内不罚，但业务对极端峰值可能更敏感。

## 5. 关联知识与易混辨析

SVR 用 ε-insensitive 回归损失；SVC 用 Hinge 分类间隔；Quantile Regression 使用非对称 pinball loss；Ridge 在全部平方残差上施加惩罚，不设零损失容忍管。

## 6. 中等难度面试题（含参考答案）

1. **问：为什么 ε 变大通常会减少落在管外的样本？** 答：管道更宽，更多训练残差满足 |y−f|≤ε，因而这些样本的 ε-insensitive loss 为零；但对最优模型的整体影响需重新训练评估。

2. **问：SVR 适用于具有业务要求的概率 90% 预测区间吗？** 答：单靠 ε 管无法保证 90% 预测覆盖率，需要额外分位数模型、校准或符合假设的预测区间方法。

## 7. 中等难度考试题（含解析）

1. **题：真实 y=5、预测 f=4.4、ε=0.5，ε-insensitive loss？** 解：残差绝对值 0.6，损失 max(0,0.6−0.5)=0.1。

2. **题：y=3、预测 3.2、ε=0.5，损失？** 解：|3−3.2|=0.2≤0.5，因此损失为 0。
