# Transfer Learning（迁移学习）

> 适用领域：机器学习 · 专题：基础概念与学习范式 · 数理机制与应用边界

## 1. 核心定义

迁移学习将源任务或源域训练所得参数、表征或结构迁移到目标任务，以降低目标数据和计算需求。成功依赖源、目标之间可共享的规律；迁移不当可能造成负迁移。

## 2. 形象理解

学过骑自行车的人较容易掌握某些平衡技巧，然而相似经验也可能导致驾驶新车型时用错策略。

**类比局限：**两个领域名称相似并不能证明数据生成过程兼容。

## 3. 技术原理与核心内容

典型做法先在 D_source 上学习 θ_s，再冻结部分骨干仅拟合任务头，或用较小学习率联合微调全部参数。域、任务、标签空间可相同或不同；重要的是给出迁移假设和目标验证。微调时应关注优化器状态、归一化统计、数据泄漏和灾难性遗忘。

## 4. 工程实践与设计权衡

工业缺陷图像标注少时可从通用视觉骨干出发，先做冻结特征+线性头，再逐步解冻；与从头训练比较同等预算下的召回、算力与推断延迟。

## 5. 关联知识与易混辨析

迁移学习是跨任务/域复用知识；领域自适应特指分布差异下的适配，通常是迁移学习的子问题；微调只是常见的迁移操作。

## 6. 中等难度面试题（含参考答案）

1. **问：为什么冻结骨干有时优于全量微调？** 答：当目标样本很少时，冻结可减少需拟合参数和过拟合风险，也节省计算；若目标域差异很大，则逐层解冻或适配可能更优。

2. **问：如何判断出现了负迁移？** 答：与同等数据预算的从头训练和更简单基线比较，检查目标域分组指标与学习曲线；不能只看源域得分。

## 7. 中等难度考试题（含解析）

1. **题：骨干 8,000,000 参数，任务头 20,000 参数，只训练任务头时可训练参数占总参数比例？** 解：20000/8020000≈0.249%。注意冻结参数仍需前向计算和保存模型权重。

2. **题：目标域模型从头训练错误率 12%，迁移后 15%，按错误率差与相对变化报告结果。** 解：绝对恶化 3 个百分点；相对增加 (15−12)/12=25%。该题的样本外误差需来自同一目标测试协议。
