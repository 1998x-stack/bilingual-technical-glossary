# Covariate Shift（协变量偏移）

> 领域：机器学习 · 专题：统计学习与泛化理论 · 定义、条件、推导与工程适用边界

## 1. 核心定义

协变量偏移（Covariate Shift）描述训练与目标环境的输入分布不同，即 P_s(X)≠P_t(X)，但条件目标规律保持 P_s(Y|X)=P_t(Y|X)。这一假设若成立，可通过重要性权重调整某些训练与评估统计量；不变性和支持集覆盖不可自动从边际漂移推得。

## 2. 形象理解

像两座城市的人年龄组成不同，但在相同年龄、相同健康条件下某病的条件风险关系相同。

**类比的局限：**如果新城市出现训练中完全没有的年龄/环境组合，简单加权不能从零样本恢复规律；如果关系本身变了，加权也不够。

## 3. 技术原理与核心内容

目标风险 E_t[ℓ(h(X),Y)] 在条件不变且 P_t(X) 对 P_s(X) 绝对连续时可写为 E_s[w(X)ℓ(h(X),Y)]，其中 w(x)=p_t(x)/p_s(x)。权重未知需估计，极小源密度导致权重爆炸与方差大；可进行权重裁剪并报告由此引入的偏差。训练与验证独立分组/时间要求依旧存在。重要性加权 CV 的无偏性取决于本文设定的假设。

## 4. 工程实践与设计权衡

当新门店年轻客户比例升高而消费偏好条件关系尚可信时，使用人口层权重估计目标损失，检查覆盖率与有效样本量，不将新门店行为变化误当纯协变量偏移。

## 5. 关联知识与易混辨析

Covariate Shift 指 P(X) 变而 P(Y|X) 不变；Label Shift 则 P(Y) 变而 P(X|Y) 不变；Sampling Bias 是数据进入训练样本的选择偏差，可能表现为协变量偏移但不等同。

## 6. 中等难度面试题（含参考答案）

1. **问：为什么协变量偏移下使用 w=p_t/p_s 的权重可以修正风险？** 答：在条件分布不变和支持集重叠条件下，通过密度比的换测度把源域积分变成目标域积分；若假设不成立推导就失效。

2. **问：为什么需要监控极端重要性权重？** 答：若源域几乎没有目标域某区域样本，w 非常大，风险估计方差飙升；需报告有效样本量并考虑补采样。

## 7. 中等难度考试题（含解析）

1. **题：某 x 所在区域源概率质量 0.1、目标 0.3，按离散分组密度比赋权多少？** 解：w=0.3/0.1=3，题设假设两域在组内条件分布一致且分组代表 x 的相同事件。

2. **题：给两条样本权重分别 2 和 1、损失 0.1 和 0.4，简单归一加权平均损失？** 解：(2×0.1+1×0.4)/(2+1)=0.6/3=0.2；自归一估计与未归一重要性风险的统计性质不同。
