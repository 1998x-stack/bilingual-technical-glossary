# Underfitting（欠拟合）

> 领域：机器学习 · 专题：统计学习与泛化理论 · 数理条件、训练与泛化能力

## 1. 核心定义

欠拟合指模型假设、特征表示或训练过程不足以捕捉任务中的重要关系，导致训练和未知数据表现都不理想。它可由模型过于简单、过强正则、学习率/迭代不足或错误特征造成；不是一个靠增加数据一定能解决的问题。

## 2. 形象理解

像让学生只用加减法做微积分题，无论反复练习多少次都难以表达需要的微分关系。

**类比的局限：**训练数据标签错误或训练失败也能造成双高损失，不宜把所有低分都归咎于模型容量不足。

## 3. 技术原理与核心内容

欠拟合常见高偏差行为：训练 loss 在较高水平停滞，验证 loss 也高且与训练相近。诊断可通过学习曲线、残差结构与简单可控的复杂度阶梯（线性→二次项→树/核模型）。缓解手段包括增加有效特征、减小正则、训练更久、选择更适当模型类；必须同时观察验证集以免走向过拟合。

## 4. 工程实践与设计权衡

预测建筑能耗时仅以建筑面积作线性模型且两侧残差呈明显非线性，尝试加入温度、季节和二次交互项。先确认时间标签、单位与数据质量，再评估复杂度是否真正提升未来预测。

## 5. 关联知识与易混辨析

Underfitting 是模型学习不足；Overfitting 是对训练细节适配过多；Bias–Variance Tradeoff 用于解释某些统计机制，但不能被视作每个现代模型的完整定律。

## 6. 中等难度面试题（含参考答案）

1. **问：训练和验证损失都很高但相近，下一步应怎样排查？** 答：先验证标签/特征和优化是否正确，再检查模型表达能力和正则强度；可做能否拟合一小批数据的 sanity check。

2. **问：把正则系数继续加大能解决欠拟合吗？** 答：通常会进一步约束参数使欠拟合加重；应比较更弱的正则、更多特征或更充分训练，并通过独立验证确定。

## 7. 中等难度考试题（含解析）

1. **题：训练 MSE=20、验证 MSE=22，另一个模型训练 MSE=2、验证 MSE=4，若任务一致如何比较？** 解：第二个模型的验证 MSE 4 更好；第一个两者都高，提示可能欠拟合或数据质量问题。

2. **题：模型 ŷ=a 为常数，训练 y=[1,3,5]，最小平方损失常数 a 是多少？** 解：训练均值 a=(1+3+5)/3=3，此模型无法刻画随 x 变化的趋势。
