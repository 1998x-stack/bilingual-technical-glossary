# Inductive Learning（归纳学习）

> 适用领域：机器学习 · 专题：基础概念与学习范式 · 算法机制与适用边界

## 1. 核心定义

归纳学习从有限训练样本推得一个可应用于未知新样本的规则或预测函数 f。核心是学习能够在训练样本以外使用的模型，而不是仅对本次给定的测试样本输出标签。

## 2. 形象理解

学会一般的乘法规律，遇到尚未见过的两个数也能计算。

**类比局限：**总结的规则只对其假设和数据支持范围有意义；不能由几道例题保证适用于所有新分布。

## 3. 技术原理与核心内容

给定 D_train，归纳算法构造 f̂= A(D_train)，后续对任意允许输入 x 输出 f̂(x)。函数类、损失、正则与样本分布确定归纳偏置；可用独立测试估计 R(f̂)。现代深度模型虽复杂，通常仍属归纳预测。若训练中利用了特定未标注目标测试节点的图结构，则具有直推成分。

## 4. 工程实践与设计权衡

用户流失模型训练完成后，可用于次日新用户，只要特征规则一致且有适当分布监测。要防止未来标签、同一客户跨数据集泄漏，按用户与时间评估。

## 5. 关联知识与易混辨析

归纳学习训练可复用预测函数；直推学习可以利用某个固定测试集合的未标注结构，只针对该集合推断，不一定输出可推广规则。

## 6. 中等难度面试题（含参考答案）

1. **问：为什么归纳模型对未来新样本的表现比对当前测试集拟合度更重要？** 答：真正部署会接收未知个体。若模型依赖测试样本独特结构或误用标签，当前结果可乐观而不支持未来泛化。

2. **问：归纳偏置是一定要消除的“错误偏差”吗？** 答：不是。有限数据下无法不作假设地泛化；正则化、平滑性和模型类都是归纳偏置，关键是与实际任务结构相匹配。

## 7. 中等难度考试题（含解析）

1. **题：训练数据为 (x,y)={(1,2),(2,4)}，选择过原点的线性模型 y=ax，最小二乘解 a 是多少？预测 x=3。** 解：a=(1×2+2×4)/(1²+2²)=10/5=2；新样本预测 y=6。假设数据无误且线性结构适用。

2. **题：一个模型训练结束后只保留参数，可对后来出现的任意新样本独立预测；另一个算法需知道本批 20 个未标注测试节点间的边。这两个哪一个体现直推成分？** 解：前者是标准归纳预测，后者利用特定测试集合结构，具有直推特征。
