# K-nearest Neighbors (KNN)（K 近邻算法 · KNN）

> 领域：机器学习 · 专题：支持向量机、核方法与近邻 · 数学、工程实践及邻域检索

## 1. 核心定义

K 近邻算法（K-nearest Neighbors，KNN）是一类基于样本间距离、在预测时检索最邻近 k 个已知训练样本，并据其类别投票或目标值加权汇总的非参数预测方法。它的训练通常主要是保存数据及建立索引，但推理成本与存储、特征表示高度相关。

## 2. 形象理解

像遇到一件不认识的植物，就找最相似的 k 个已有样本，参考它们的品种投票来判断，而不是拟合一条统一线性分类公式。

**类比的局限：**‘近’完全由选定距离及标准化决定；高维距离集中、错标样本和类别不平衡都可能让邻居投票产生偏差。

## 3. 技术原理与核心内容

对查询 x，在训练集中找索引集合 N_k(x)，分类统一权重可按 argmax_c Σ_{i∈N_k}1[y_i=c]，距离权重可设 w_i∝1/(d(x,x_i)+ε₀)。回归通常取邻居均值或距离加权均值。k 小更局部、方差通常较大；k 大更平滑、可能欠拟合。KNN 可利用 brute、KDTree、BallTree 等进行搜索，但高维稀疏输入常退化为 brute。训练/查询预处理必须一致且不借用验证折的信息。

## 4. 工程实践与设计权衡

医学相似病例辅助系统可对标准化的年龄、检验值和明确编码的离散字段检索候选，再提供人工审查；应避免把训练患者的多个就诊副本误当独立邻居，并审查少数病种召回。

## 5. 关联知识与易混辨析

KNN 是依邻居集合进行分类/回归的学习规则；Nearest Neighbor Search 仅找近邻索引与距离，未必执行预测；SVM 的 Support Vector 经优化确定，不等于最近的 k 个训练样本。

## 6. 中等难度面试题（含参考答案）

1. **问：为什么 KNN 在高维样本上可能失效？** 答：许多维度组合使距离分布趋于集中且查询空间稀疏，近邻与远邻难区分；应选更适当特征、权重与度量。

2. **问：k 越大是否一定提高 KNN 准确率？** 答：不一定：大 k 会平滑局部异常，但可能掩盖真正的小区域类别边界，需用合适 CV 选择。

## 7. 中等难度考试题（含解析）

1. **题：k=3，邻居标签为 [A,B,A]，等权 KNN 分类结果？** 解：A 获得 2 票，B 1 票，故预测 A。

2. **题：k=3，邻居回归目标 [2,4,9]，等权 KNN 回归预测？** 解：(2+4+9)/3=15/3=5，未考虑距离加权。
