Data Structure数据结构组织、存储和访问数据的方式及相应操作。
Abstract Data Type (ADT)抽象数据类型只规定数据与操作的语义，不限定实现细节。
Data Type数据类型值的集合及可执行操作的约束。
Primitive Type基本类型语言直接提供的基本数据类型，如整数与布尔值。

Node节点具有数据字段和可能的链接字段的基本单元。
Key键用于标识、检索或比较记录的字段。
Value值与键关联或作为容器成员的数据。
Record记录由若干字段构成的一条结构化数据。

Sentinel哨兵简化边界判断的特殊标记或节点。

Mutable Structure可变数据结构创建后可原地修改元素或链接的结构。
Immutable Structure不可变数据结构构建后不改变既有实例状态的结构。
Persistent Data Structure持久化数据结构更新时保留旧版本，并生成可访问的新版本。

Implementation实现将抽象操作映射到具体存储布局和算法。

Iteration迭代按序逐次取得元素或执行重复操作。

02 · 复杂度与存储布局

Complexity & Memory Layout 27 TERMS

理解术语在性能分析、内存组织和实现取舍中的作用。

ENGLISH / 英文中文译名简明释义
Time Complexity时间复杂度描述输入规模增长时操作时间的渐近变化。
Space Complexity空间复杂度描述输入规模增长时所需空间的渐近变化。
Big O Notation大 O 记号表示函数增长率的渐近上界。
Big Omega Notation大 Ω 记号表示函数增长率的渐近下界。
Big Theta Notation大 Θ 记号表示函数增长率的渐近紧确界。
Worst-case Complexity最坏情况复杂度在最不利输入下的资源消耗上界。
Average-case Complexity平均情况复杂度给定输入分布下的期望资源消耗。
Amortized Analysis均摊分析将一系列操作的总成本分摊到单次操作。
Amortized Complexity均摊复杂度序列操作中平均分摊到每次的代价上界。
Auxiliary Space辅助空间除输入与输出数据本身以外的额外空间。
Memory Footprint内存占用数据结构及相关元数据消耗的存储空间。
Contiguous Memory连续内存数据元素占据相邻的内存地址区间。
Non-contiguous Memory非连续内存元素可散布在不同地址并通过链接关联。
Random Access随机访问能够直接通过位置标识访问任意元素。
Sequential Access顺序访问通常沿既定顺序逐个访问元素。
Cache Locality缓存局部性访问数据时倾向重复访问附近或近期的位置。
Spatial Locality空间局部性程序倾向访问地址相邻的存储位置。
Temporal Locality时间局部性程序倾向短期内重复访问同一数据。
Memory Allocation内存分配为元素或节点申请可用内存空间。
Dynamic Allocation动态分配运行期间按需申请与释放内存。
Fragmentation内存碎片空闲空间被分割，降低有效利用或分配效率。
Capacity容量容器当前无需扩容即可容纳的元素上限。
Size大小容器当前实际包含的元素个数。
Load Factor负载因子已存储元素数与桶数等容量指标的比值。
Resize调整容量改变底层可容纳元素数量的操作。
Reallocation重新分配申请新的存储区域并可能搬移既有元素。
Memory Alignment内存对齐按特定地址边界布置对象以满足平台要求。

03 · 数组、序列与矩阵

Arrays, Sequences & Matrices 28 TERMS

掌握连续存储、索引、动态扩容及多维表示的核心词汇。

ENGLISH / 英文中文译名简明释义
Array数组按索引访问、通常在连续存储区排列的同类型元素序列。
Static Array静态数组长度在创建后固定的数组。
Dynamic Array动态数组容量可通过重新分配等方式增长的数组。
Resizable Array可调整大小数组支持运行时扩容或缩容的数组实现。
Array List数组列表基于动态数组实现的列表容器名称。
Sequence序列元素按明确次序组织的抽象集合。
List列表支持按位置访问或插入删除的有序集合抽象。
Indexing索引访问使用位置编号定位元素。
Zero-based Indexing从零开始的索引首元素下标为零的索引约定。
Subarray子数组原数组中一段连续的元素区间。
Slice切片从序列中选择连续区间或按步长抽取元素。
View视图共享底层数据、提供不同访问方式的表示。
Array Copy数组复制将数组内容复制到另一存储区域。
In-place Operation原地操作主要在原有数据区域中完成修改。
Append尾部追加在序列末端加入一个元素。
Insert插入在指定位置加入元素并维护次序。
Delete删除移除指定位置或满足条件的元素。
Shift移位为插入、删除或重排移动元素位置。
Circular Array循环数组将固定数组下标按模运算首尾衔接使用。
Multidimensional Array多维数组使用多个下标表示元素位置的数组。
Matrix矩阵按行和列组织元素的二维数据结构。
Row-major Order行主序同一行的元素在内存中相邻排列的存储次序。
Column-major Order列主序同一列的元素在内存中相邻排列的存储次序。
Stride步长跨越某个数组维度一个索引单位时的内存偏移量。
Sparse Matrix稀疏矩阵绝大多数元素为零或缺省值的矩阵。
Dense Matrix稠密矩阵通常显式存储大部分位置元素的矩阵。
Compressed Sparse Row (CSR)压缩稀疏行格式以行指针、列索引和值表示稀疏矩阵。
Compressed Sparse Column (CSC)压缩稀疏列格式以列指针、行索引和值表示稀疏矩阵。

04 · 链表与指针结构

Linked Lists & Pointer Structures 19 TERMS

区分单链、双链、循环链表及常见节点操作。

ENGLISH / 英文中文译名简明释义
Linked List链表通过节点间链接组织的线性数据结构。
Singly Linked List单向链表每个节点通常仅保存后继节点链接的链表。
Doubly Linked List双向链表节点同时保存前驱与后继链接的链表。
Circular Linked List循环链表尾节点链接回某个起始节点的链表。
Circular Doubly Linked List循环双向链表前驱和后继关系均首尾闭合的双向链表。
Head Node头节点链表起始位置的节点；有时专指虚拟头节点。
Tail Node尾节点链表末端的节点。
Dummy Head虚拟头节点不承载普通业务元素、用于简化边界操作的节点。
Next Pointer后继指针指向下一个节点的链接。
Previous Pointer前驱指针指向上一个节点的链接。
Predecessor前驱在指定顺序中位于目标元素之前的元素。
Successor后继在指定顺序中位于目标元素之后的元素。
List Reversal链表反转将链表节点的链接方向或次序反转。
List Splicing链表拼接通过调整链接合并或移动一段链表。
Cycle Detection环检测判断链表中是否存在可重复到达的节点。
Fast and Slow Pointers快慢指针使用不同移动速度的指针完成检测或定位。
Skip List跳表通过多层有序链接实现期望对数级查找的结构。
Unrolled Linked List分块链表每个节点存储多个连续元素的链表变体。
Intrusive Linked List侵入式链表将链接字段直接放入被管理对象的链表。

05 · 栈、队列与双端队列

Stacks, Queues & Deques 23 TERMS

理解 LIFO、FIFO、双端操作以及实际工程中的队列变体。

ENGLISH / 英文中文译名简明释义
Stack栈遵循后进先出次序的线性容器。
Last In, First Out (LIFO)后进先出最后加入的元素最先被取出。
Push入栈向栈顶加入元素。
Pop出栈从栈顶移除并通常返回元素。
Peek / Top查看栈顶读取栈顶元素但不移除。
Stack Overflow栈溢出栈空间超出允许容量或调用栈限制。
Stack Underflow栈下溢在空栈上执行非法弹出等操作。
Monotonic Stack单调栈保持元素按单调关系排列的栈。
Call Stack调用栈保存函数调用帧和返回信息的运行时栈。
Queue队列通常遵循先进先出次序的线性容器。
First In, First Out (FIFO)先进先出最先加入的元素最先被取出。
Enqueue入队向队列尾端加入元素。
Dequeue出队从队列头端移除并通常返回元素。
Front队首队列中下一次通常被取出的元素位置。
Rear / Back队尾队列中通常执行追加的位置。
Circular Queue循环队列用环形下标复用固定缓冲区的队列。
Deque (Double-ended Queue)双端队列支持在首尾两端插入和删除的容器。
Monotonic Queue单调队列保持候选值单调，用于窗口极值等查询。
Blocking Queue阻塞队列在空或满等条件下可使操作等待的并发队列。
Bounded Queue有界队列最多容纳预设数量元素的队列。
Unbounded Queue无界队列不规定固定元素上限的队列抽象。
Ring Buffer环形缓冲区在固定空间内循环复用读写位置的缓冲结构。
Producer–Consumer Queue生产者—消费者队列在生产任务和消费任务间传递元素的队列。

06 · 哈希表与映射

Hash Tables & Maps 27 TERMS

覆盖哈希函数、冲突处理、哈希容器和探测策略。

ENGLISH / 英文中文译名简明释义
Hash Table哈希表通过哈希函数把键映射到桶或槽位的结构。
Hash Map哈希映射使用哈希表实现键到值映射的容器。
Hash Set哈希集合基于哈希表实现的去重元素集合。
Map / Dictionary映射／字典保存键值关联并支持按键查找的抽象类型。
Set集合不包含重复元素的抽象容器。
Multiset多重集合允许同一元素出现多次的集合抽象。
Multimap多重映射允许一个键对应多个值的映射抽象。
Hash Function哈希函数将输入键转换为固定范围摘要或索引的函数。
Hash Value哈希值哈希函数计算得到的摘要或数值。
Hash Code哈希码对象或键用于哈希分桶的整数等表示。
Bucket桶哈希表中负责容纳一个或多个条目的位置或分组。
Slot槽位底层表中可放置条目的单个位置。
Hash Collision哈希冲突不同键映射到同一桶或槽位的情形。
Collision Resolution冲突解决在碰撞发生时仍能正确存储和查找键的方法。
Separate Chaining链地址法将同桶碰撞项放入链表或其他次级容器。
Open Addressing开放寻址法通过探测表中其他槽位解决碰撞。
Linear Probing线性探测碰撞后依次检查相邻候选槽位。
Quadratic Probing二次探测以二次函数决定探测位移的策略。
Double Hashing双重哈希使用第二个哈希函数确定探测步长。
Robin Hood Hashing罗宾汉哈希通过平衡探测距离减少较长探测链的策略。
Cuckoo Hashing布谷鸟哈希在多个候选位置之间搬移键以处理冲突。
Tombstone删除标记开放寻址表中用于标识已删除槽位的标记。
Rehashing重新哈希改变容量或布局时重新安排各键的位置。
Hash Flooding哈希洪泛大量冲突导致哈希结构性能下降的情形。
Perfect Hashing完美哈希针对给定静态键集实现无碰撞映射的方法。
Minimal Perfect Hash最小完美哈希将 n 个固定键无碰撞映射到 n 个槽位。
Ordered Map有序映射按键顺序或插入顺序维持确定迭代次序的映射。

07 · 树与遍历

Trees & Traversals 30 TERMS

从节点关系、树的形态到深度优先与层序遍历。

ENGLISH / 英文中文译名简明释义
Tree树由节点和无环的层次连接关系组成的结构。
Rooted Tree有根树指定一个根节点以定义父子关系的树。
Root根节点有根树中没有父节点的起始节点。
Parent Node父节点树中直接连接到某个子节点上方的节点。
Child Node子节点由某个父节点直接连接的下层节点。
Sibling Nodes兄弟节点拥有相同父节点的节点。
Leaf Node叶子节点没有子节点的节点。
Internal Node内部节点至少拥有一个子节点的节点。
Ancestor祖先节点沿父指针不断向上可以到达的节点。
Descendant后代节点沿子指针向下可以到达的节点。
Subtree子树由某节点及其所有后代构成的树。
Forest森林若干互不相交的树的集合。
Degree of a Node节点的度节点直接拥有的子节点数（有根树语境）。
Depth of a Node节点深度从根到该节点的边数。
Height of a Node节点高度从该节点到最深叶节点的最长边数。
Height of a Tree树高根节点的高度；空树约定因实现而异。
Level层依据根到节点距离划分的层级；起始层编号依约定。
Binary Tree二叉树每个节点最多有左右两个子节点的树。
Full Binary Tree严格二叉树／真二叉树每个节点的子节点数只能是零或二的二叉树。
Perfect Binary Tree满二叉树／完美二叉树全部内部节点有两个子节点且叶子在同一层。
Complete Binary Tree完全二叉树除末层外各层已满，末层节点从左向右排列。
Skewed Tree斜树绝大多数节点只有单侧子节点的退化树。
Tree Traversal树遍历按指定顺序访问树中全部节点。
Preorder Traversal前序遍历按根、左子树、右子树的顺序访问二叉树。
Inorder Traversal中序遍历按左子树、根、右子树的顺序访问二叉树。
Postorder Traversal后序遍历按左子树、右子树、根的顺序访问二叉树。
Level-order Traversal层序遍历从上到下逐层访问节点，通常借助队列。
Depth-first Search (DFS)深度优先搜索优先深入尚未访问的分支，之后回溯。
Breadth-first Search (BFS)广度优先搜索按与起点距离的层次依次扩展节点。
Lowest Common Ancestor (LCA)最近公共祖先两个节点共同祖先中深度最大的节点。

08 · 搜索树与平衡树

Search Trees & Balanced Trees 26 TERMS

理解查找不变量、旋转、平衡约束和常见平衡树变体。

ENGLISH / 英文中文译名简明释义
Binary Search Tree (BST)二叉搜索树左子树键小于节点键、右子树键大于节点键（重复键规则另定）。
Search Tree搜索树利用键顺序或分区规则支持高效检索的树。
Balanced Tree平衡树通过结构约束控制高度以保证操作效率的树。
Self-balancing Tree自平衡树在更新时自动维持指定平衡条件的树。
AVL TreeAVL 树通过左右子树高度差约束保持平衡的搜索树。
Red–Black Tree红黑树以节点颜色与路径约束限制高度的平衡搜索树。
Splay Tree伸展树通过访问后的旋转将操作节点移至根部的搜索树。
Treap树堆同时满足搜索树的键顺序和堆的优先级约束。
Scapegoat Tree替罪羊树在失衡时重建子树的平衡搜索树。
Weight-balanced Tree权重平衡树依据子树大小或权重维持平衡的搜索树。
AA TreeAA 树使用简化层级约束实现平衡的搜索树。
Tree Rotation树旋转局部调整父子链接且维持中序顺序的操作。
Left Rotation左旋围绕节点与其右子节点进行的局部旋转。
Right Rotation右旋围绕节点与其左子节点进行的局部旋转。
Balance Factor平衡因子常指左右子树高度的差值。
Rebalancing重新平衡插入或删除后恢复树的平衡约束。
Order Statistic Tree顺序统计树支持按排名选取元素等操作的增强搜索树。
Rank Query排名查询求小于指定键的元素数量或对应位置。
Select Query按秩选择按排序位置查找第 k 个元素。
Successor Query后继查询查找比给定键大的最小键。
Predecessor Query前驱查询查找比给定键小的最大键。
B-TreeB 树允许多键、多子节点、适合块存储的平衡搜索树。

PRECISION NOTES / 术语辨析

容易混淆的 12 组概念

以下对比是学习和阅读源码时最常遇到的命名边界。

Heap vs. Heap Memory
堆（数据结构）≠ 堆内存
前者通常是满足堆序性质的树；后者指动态内存分配区域。
Array vs. List
数组 ≠ 列表抽象
数组强调索引与布局；List 是抽象序列，可用数组或链表实现。
Stack vs. Call Stack
栈 ≠ 调用栈
栈是 LIFO 容器抽象；调用栈是运行时保存调用帧的实现机制。
Priority Queue vs. Heap
优先队列 ≠ 堆
优先队列是抽象类型；二叉堆、平衡树等都可实现它。
Map vs. Hash Map
映射 ≠ 哈希映射
Map 描述键值关联；Hash Map 只是其中一种实现。
BST vs. Binary Tree
二叉搜索树 ≠ 二叉树
二叉搜索树额外规定键顺序；普通二叉树没有此要求。
Full vs. Perfect vs. Complete
严格／满／完全二叉树
严格：节点有 0 或 2 个孩子；满：叶同层且内部节点各有 2 个孩子；完全：按层从左填充。
Trie vs. Prefix Tree
Trie 与前缀树
通常是同一类数据结构的两种名称；不同实现可能压缩路径。
Set vs. Multiset
集合 ≠ 多重集合
Set 不允许重复元素；Multiset 允许并记录重复次数。
B-Tree vs. B+ Tree
B 树 ≠ B+ 树
B+ 树常把数据条目放在叶层，并通过叶间链接支持范围扫描。
DFS vs. BFS
深度优先 ≠ 广度优先
DFS 优先深入分支；BFS 按距离层次扩展。
Bloom Filter vs. Hash Set
布隆过滤器 ≠ 哈希集合
Bloom Filter 节省空间但可能误判存在；Hash Set 通常给出精确成员答案。
