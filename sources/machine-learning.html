基础概念与学习范式

Foundations & Learning Paradigms

ENGLISH TERM中文推荐译法简明释义
Machine Learning (ML)机器学习从数据中学习规律，用于预测、决策或生成的技术总称。
Artificial Intelligence (AI)人工智能研究和构建表现出智能行为的系统的广泛领域。
Statistical Learning统计学习以统计理论刻画从样本到预测规则的学习过程。
Supervised Learning监督学习利用带目标标签的样本学习输入到输出的映射。
Unsupervised Learning无监督学习在无目标标签数据中发现结构、分组或表征。
Semi-supervised Learning半监督学习结合少量有标签与大量无标签数据进行学习。
Self-supervised Learning自监督学习从数据自身构造监督信号进行表征学习。
Reinforcement Learning (RL)强化学习通过与环境交互、根据奖励学习行动策略。
Online Learning在线学习样本持续到来时增量更新模型的学习方式。
Offline Learning / Batch Learning离线学习／批量学习先汇集数据，再分批训练模型的方式。
Active Learning主动学习模型主动选择最值得人工标注的样本。
Transfer Learning迁移学习将源任务或领域所学知识应用于新任务。
Multi-task Learning多任务学习联合训练相关任务，以共享有益的表征。
Meta-learning元学习学习如何更快适应新的任务或训练设置。
Few-shot Learning少样本学习仅使用少量示例完成新任务的学习方法。
Zero-shot Learning零样本学习不依赖目标类别的训练样本完成预测。
Domain Adaptation领域自适应减小训练域与目标域分布差异带来的影响。
Inductive Learning归纳学习从训练样本学习可推广到未知样本的规则。
Transductive Learning直推学习针对给定的未标注目标样本进行推断。
Generative Model生成模型学习数据分布，支持采样或生成数据。
Discriminative Model判别模型学习类别边界或条件预测关系。
Predictive Modeling预测建模构建用于预测未知结果的统计或机器学习模型。
Representation Learning表征学习自动学习适合下游任务的数据表示。
Foundation Model基础模型在广泛数据上预训练、可适配多种任务的模型。

数据、样本与数据集划分

Data, Samples & Dataset Splits

ENGLISH TERM中文推荐译法简明释义
Dataset数据集用于训练、验证或评估的样本集合。
Sample / Instance样本／实例数据集中一次观测或一个数据对象。
Observation观测被记录的数据测量或事件。
Feature特征作为模型输入的可测量属性或变量。
Target / Label目标变量／标签希望模型预测或解释的值。
Ground Truth真实标注／参考真值用作训练或评估依据的可信参考标签。
Feature Matrix (X)特征矩阵以样本为行、特征为列的输入矩阵。
Target Vector (y)目标向量与样本对应的预测目标序列。
Training Set训练集用于拟合模型参数的数据部分。
Validation Set验证集用于模型选择、调参与监控训练的数据部分。
Test Set测试集用于最终估计泛化表现的保留数据部分。
Holdout Set留出集从训练过程中隔离，用于独立评估的数据。
Train–Test Split训练测试划分将样本划分成用于训练和评估的子集。
Stratified Sampling分层抽样按类别等分层因素保持分布比例的抽样方式。
Group Split分组划分保证同一组的样本不会跨训练与测试划分。
Temporal Split时间划分按照时间先后进行数据划分，减少未来信息泄漏。
Cross-validation (CV)交叉验证重复划分训练和验证数据以评估模型。
K-fold Cross-validationK 折交叉验证将数据分成 K 份，轮流用一份验证。
Stratified K-fold分层 K 折交叉验证每折尽量维持类别比例的 K 折验证。
Leave-one-out CV (LOOCV)留一交叉验证每次留一个样本作验证，其余样本训练。
Out-of-fold Prediction (OOF)折外预测在样本未参与对应模型训练的折上产生预测。
Data Leakage数据泄漏训练时不当使用评估集或未来信息造成评估虚高。
Label Leakage标签泄漏特征包含了预测时不可获得的目标信息。
Sampling Bias抽样偏差样本选取机制导致数据不代表目标总体。
Class Imbalance类别不平衡不同类别的样本数量差异明显。
Missing Value缺失值某项特征的观测值未被记录。
Outlier离群点相对主要数据分布显著偏离的观测。
Data Annotation数据标注为原始数据提供类别、边界或其他监督信息。

数据预处理与特征工程

Preprocessing & Feature Engineering

ENGLISH TERM中文推荐译法简明释义
Data Cleaning数据清洗修正重复、缺失、错误或不一致的数据。
Data Preprocessing数据预处理模型训练前的清洗、变换和编码流程。
Feature Engineering特征工程设计、构造和处理能改善模型表现的特征。
Feature Extraction特征提取将原始数据变换为更有用的特征表示。
Feature Selection特征选择从候选特征中选择相关、有效的子集。
Imputation缺失值填补用规则或模型估计缺失的数据值。
Mean Imputation均值填补使用已观测数值的均值替代缺失值。
Standardization标准化常指减均值后除以标准差的数值变换。
Normalization归一化按约定尺度变换数据；具体含义依场景而异。
Min–Max Scaling最小最大缩放将特征线性映射到指定值域。
Robust Scaling稳健缩放利用中位数和分位距减弱异常值影响。
One-hot Encoding独热编码将类别编码为只有对应位置为 1 的向量。
Ordinal Encoding序数编码将类别映射为有顺序的整数值。
Target Encoding目标编码利用目标统计量表示类别，需要防止数据泄漏。
Label Encoding标签编码将离散标签映射为整数编码。
Binning / Discretization分箱／离散化将连续变量划分为有限个区间。
Polynomial Features多项式特征通过原特征的幂与交互项扩展输入。
Interaction Feature交互特征表征两个或多个变量联合作用的特征。
Log Transformation对数变换以对数压缩长尾分布或较大数值范围。
Box–Cox TransformationBox–Cox 变换对正值数据使用参数化幂变换。
Feature Hashing特征哈希通过哈希将高维离散特征映射到固定维度。
Bag of Words (BoW)词袋模型以词出现情况或频次表征文本。
TF–IDF词频-逆文档频率衡量词在文档中的重要性并抑制常见词。
Embedding嵌入向量将对象映射为连续、低维或稠密的数值表示。
Sparse Feature稀疏特征取零值或缺失状态的比例很高的特征。
Dense Feature稠密特征多数维度都有有效数值的特征。
Data Augmentation数据增强通过合理变换样本扩充训练数据多样性。
Resampling重采样改变样本选择或重复使用方式以调整数据分布。
SMOTE合成少数类过采样技术在特征空间合成少数类样本以缓解不平衡。
Pipeline流水线串联预处理和预测器并统一训练、推断的流程。

统计学习与泛化理论

Statistical Learning & Generalization

ENGLISH TERM中文推荐译法简明释义
Empirical Risk经验风险模型在训练样本上的平均损失。
Expected Risk期望风险模型在目标数据分布上的期望损失。
Empirical Risk Minimization (ERM)经验风险最小化通过最小化训练数据上的损失选择模型。
Structural Risk Minimization (SRM)结构风险最小化在拟合误差之外控制模型复杂度。
Generalization泛化模型对未见样本保持有效表现的能力。
Generalization Gap泛化差距训练指标与验证或测试指标之间的差异。
Overfitting过拟合模型过度记忆训练样本，未见样本表现下降。
Underfitting欠拟合模型表达能力或训练程度不足，难以捕获规律。
Bias–Variance Tradeoff偏差-方差权衡模型偏差与对样本变化敏感度之间的折中。
Inductive Bias归纳偏置学习算法为了推广到新样本而采用的先验假设。
Regularization正则化通过约束或惩罚降低过拟合风险。
L1 RegularizationL1 正则化惩罚参数绝对值之和，可促进稀疏性。
L2 RegularizationL2 正则化惩罚参数平方和，倾向于缩小参数幅度。
Elastic Net Regularization弹性网络正则化组合 L1 与 L2 惩罚的正则化方法。
Model Complexity模型复杂度衡量模型表达能力或自由度的概念。
Capacity模型容量模型能拟合的函数集合的丰富程度。
VC DimensionVC 维衡量假设类分类表达能力的理论量。
PAC Learning概率近似正确学习通过概率保证和样本复杂度研究可学习性。
Sample Complexity样本复杂度达到目标误差和置信水平所需样本规模。
Learning Curve学习曲线观察性能随训练样本量或训练过程变化的曲线。
Validation Curve验证曲线观察训练和验证表现随超参数变化的曲线。
Distribution Shift分布偏移训练环境和实际使用环境的数据分布发生改变。
Covariate Shift协变量偏移输入分布变化而条件标签机制假设保持不变。
Label Shift / Prior Shift标签偏移／先验偏移类别先验比例变化而类条件输入分布保持不变。
Concept Drift概念漂移输入与目标之间的预测关系随时间改变。

回归、分类与线性模型

Regression, Classification & Linear Models

ENGLISH TERM中文推荐译法简明释义
Regression回归预测连续数值目标的学习任务。
Classification分类预测离散类别的学习任务。
Binary Classification二分类在两个类别中判断样本所属类别。
Multiclass Classification多类别分类在三个及以上互斥类别中分类。
Multilabel Classification多标签分类为一个样本预测多个可同时成立的标签。
Multioutput Prediction多输出预测对每个输入同时预测多个目标变量。
Linear Regression线性回归以特征的线性组合预测连续目标。
Ordinary Least Squares (OLS)普通最小二乘法最小化残差平方和来估计回归系数。
Ridge Regression岭回归采用 L2 惩罚的线性回归。
Lasso Regression套索回归采用 L1 惩罚的线性回归。
Elastic Net弹性网络同时使用 L1 和 L2 惩罚的线性模型。
Logistic Regression逻辑回归通过逻辑函数建模类别条件概率的分类方法。
Softmax RegressionSoftmax 回归将多类得分转为类别概率的线性分类模型。
Generalized Linear Model (GLM)广义线性模型用链接函数连接预测变量和响应均值的模型族。
Poisson Regression泊松回归常用于计数型响应变量的广义线性模型。
Quantile Regression分位数回归估计条件分布中指定分位数的回归方法。
Robust Regression稳健回归降低异常值或模型偏离对估计的影响。
Decision Boundary决策边界将不同预测类别划分开的边界。
Decision Function决策函数将样本映射为分类得分或判别量的函数。
Logit对数几率概率 p 对应的 log(p/(1-p)) 值。
Sigmoid FunctionSigmoid 函数将实数压缩到 0 与 1 之间的 S 形函数。
Softmax FunctionSoftmax 函数将多个得分变换为和为 1 的概率型向量。
Residual残差观测目标与模型拟合值之差。
Coefficient回归系数线性模型中描述特征影响的参数。
Intercept截距输入特征为零时线性模型的基准输出项。
Multicollinearity多重共线性多个输入特征之间存在较强线性相关。
06 / 1924 条术语

树模型与集成学习

Trees & Ensemble Learning

ENGLISH TERM中文推荐译法简明释义
Decision Tree决策树通过层层条件划分数据的树形预测模型。
Root Node根节点决策树最上层的起始节点。
Internal Node内部节点用于特征条件判断和样本分裂的节点。
Leaf Node叶节点决策树中输出最终预测的终端节点。
Tree Depth树深度从根到叶的最大边数或层级数，依实现定义。
Split Criterion划分准则判断哪种特征划分最有利的指标。
Gini Impurity基尼不纯度衡量节点内类别混杂程度的指标。
Information Gain信息增益分裂前后信息熵减少的量。
Tree Pruning决策树剪枝删减树枝以控制复杂度和提高泛化能力。
Bagging (Bootstrap Aggregating)自助聚合对重采样数据训练多个模型并聚合输出。
Bootstrap Sampling自助采样从样本中有放回地重复抽样。
Random Forest随机森林组合多棵随机化决策树的集成模型。
Extra Trees极端随机树在树的划分阈值中引入更多随机性的集成方法。
Boosting提升法顺序训练弱学习器并组合成更强模型。
AdaBoost自适应提升根据样本误差动态调整权重的提升算法。
Gradient Boosting梯度提升沿损失函数负梯度方向逐步添加基学习器。
GBDT梯度提升决策树以决策树为弱学习器的梯度提升模型。
XGBoost极端梯度提升高效实现正则化梯度提升树的算法与库。
LightGBM轻量级梯度提升机强调高效直方图建树等策略的 GBDT 框架。
CatBoost类别提升擅长处理类别特征的梯度提升框架。
Stacking堆叠集成用次级模型组合多个基模型的预测。
Voting Ensemble投票集成通过投票或概率平均融合多个分类器。
Out-of-bag Error (OOB)袋外误差利用未被某棵树抽中的样本估计泛化误差。
Feature Importance特征重要性估计某特征对模型预测或指标的贡献程度。

支持向量机、核方法与近邻

SVM, Kernel Methods & Neighbors

ENGLISH TERM中文推荐译法简明释义
Support Vector Machine (SVM)支持向量机通过间隔最大化等原则构建分类或回归模型。
Support Vector支持向量对最大间隔决策边界起关键作用的训练样本。
Margin间隔分类边界与样本之间的距离或函数性间隔。
Maximum Margin Classifier最大间隔分类器选择使类别分离间隔尽可能大的分类器。
Hinge Loss合页损失在间隔不满足要求时产生惩罚的分类损失。
Soft Margin软间隔允许部分样本违反间隔要求的 SVM 设定。
Kernel Trick核技巧不显式映射高维特征即可计算内积的方法。
Kernel Function核函数计算某特征映射空间中内积的函数。
Linear Kernel线性核以原始向量内积定义的核函数。
Polynomial Kernel多项式核用输入内积的多项式构造非线性相似度。
RBF Kernel / Gaussian Kernel径向基核／高斯核根据样本距离构造局部相似度的核函数。
Support Vector Regression (SVR)支持向量回归采用间隔思想进行连续值预测的方法。
K-nearest Neighbors (KNN)K 近邻算法根据距离最近的 K 个样本作预测。
Nearest Neighbor Search最近邻搜索在特征空间中寻找距离最小的样本。
Distance Metric距离度量度量两个样本相异程度的函数。
Euclidean Distance欧氏距离向量差的 L2 范数。
Manhattan Distance曼哈顿距离各坐标绝对差之和。
Cosine Similarity余弦相似度由向量夹角余弦衡量方向相似性。
Metric Learning度量学习学习使相似样本更近、不相似样本更远的表示或距离。
Approximate Nearest Neighbor (ANN)近似最近邻以近似正确结果换取更快的近邻检索。
08 / 1924 条术语

概率模型与统计推断

Probabilistic Models & Inference

ENGLISH TERM中文推荐译法简明释义
Probability Distribution概率分布描述随机变量取值概率的数学对象。
Conditional Probability条件概率给定一个事件后另一个事件发生的概率。
Bayes’ Theorem贝叶斯定理联系先验、似然、证据与后验的公式。
Prior Probability先验概率观察当前数据之前对假设的概率判断。
Likelihood似然在给定模型参数下观察到数据的相对支持程度。
Posterior Probability后验概率结合先验和数据后得到的概率分布。
Maximum Likelihood Estimation (MLE)极大似然估计选择使观测数据似然最大的参数。
Maximum A Posteriori (MAP)最大后验估计选择使后验密度或质量最大的参数。
Bayesian Inference贝叶斯推断利用贝叶斯规则更新参数或假设的不确定性。
Naive Bayes朴素贝叶斯给定类别时假定各特征条件独立的分类器。
Gaussian Naive Bayes高斯朴素贝叶斯假设每类内连续特征服从高斯分布的模型。
Gaussian Mixture Model (GMM)高斯混合模型用多个高斯分布的加权和拟合数据分布。
Latent Variable潜变量模型中未直接观测到、用于解释数据的变量。
Expectation–Maximization (EM)期望最大化算法交替求潜变量期望与更新参数的估计方法。
Markov Chain马尔可夫链下一状态仅依赖当前状态的随机过程模型。

Machine Learning Operations (MLOps)机器学习运维将 ML 开发、部署、监控和治理工程化的实践。
ML Pipeline机器学习流水线串联数据准备、训练、评估及部署的自动化流程。
Data Pipeline数据流水线负责收集、清洗、变换和输送数据的处理流程。
Feature Store特征存储平台统一管理、复用并服务训练与在线推断特征的系统。
Feature Registry特征注册表记录特征定义、元数据与版本的信息目录。
Experiment Tracking实验跟踪记录模型参数、代码版本、指标和产物的过程。
Model Registry模型注册表管理模型版本、状态和元数据的系统。
Artifact产物训练后生成的模型文件、指标文件或其他可复用结果。
Model Serving模型服务将模型封装成可供调用的推断服务。
Inference推断用训练后的模型对输入数据产生输出。
Online Inference在线推断收到请求时实时调用模型生成结果。
Batch Inference批量推断定期或离线对大量样本生成预测。
Streaming Inference流式推断对连续输入的数据流进行持续预测。
Inference Latency推断延迟从请求到获得预测结果所经历的时间。
Throughput吞吐量单位时间内处理的请求数或样本数。
Model Compression模型压缩在尽量保持质量的同时减小模型资源需求。
Quantization量化使用更低精度的数值形式表示参数或计算。
Model Pruning模型剪枝删除较不重要的权重、通道或其他结构。
ONNX开放神经网络交换格式用于模型表示与不同框架间交换的开放格式。
Concept Drift Monitoring概念漂移监测检测模型预测关系随时间改变的迹象。
Data Drift数据漂移生产输入数据的统计分布相对参考分布发生变化。
Training–Serving Skew训练与服务偏差训练特征与在线推断特征的生成方式或分布不一致。
Model Monitoring模型监控持续观察数据、性能、延迟与异常状况。
Canary Deployment金丝雀发布先将新模型投放给少量流量验证风险。
A/B TestingA/B 测试随机分配流量比较两个方案的实际效果。
Shadow Deployment影子部署新模型并行预测但不影响正式决策的验证方式。
Model Rollback模型回滚当新模型出现问题时恢复到旧版本。
Reproducible Training可复现训练固定数据、配置、代码和环境以重建训练结果。
Data Versioning数据版本管理追踪训练和评估所用数据快照及其变化。
Continuous Training (CT)持续训练按计划或触发条件自动更新训练模型。
19 / 1924 条术语

可解释性、公平性与安全

Interpretability, Fairness & Safety

ENGLISH TERM中文推荐译法简明释义
Interpretability可解释性模型机制及其预测原因能被人理解的程度。
Explainability可解释说明能力为模型行为提供可理解解释的能力或方法。
Global Explanation全局解释解释模型整体规律或普遍行为。
Local Explanation局部解释解释针对单个样本的具体预测。
Permutation Importance置换重要性打乱特征后根据性能下降估计重要性。
Partial Dependence Plot (PDP)部分依赖图显示特征变化对模型平均预测的影响。
Individual Conditional Expectation (ICE)个体条件期望图展示每个样本的预测随某特征变化的轨迹。
SHAPSHAP 特征归因用 Shapley 值思想分配特征对预测的贡献。
LIME局部可解释模型无关解释在预测附近拟合简单替代模型进行解释。
Counterfactual Explanation反事实解释展示改变哪些输入可能改变模型预测。
Fairness公平性研究模型对不同群体或个体是否存在不当差异。
Protected Attribute受保护属性公平性分析中需特别审慎处理的人群属性。
Demographic Parity人口统计均等不同群体具有相同正向决策率的公平标准。
Equal Opportunity机会均等不同群体在真实正例上的真正例率相同。
Equalized Odds均衡机会不同群体的真正例率和假正例率都相同。
Algorithmic Bias算法偏差算法预测中可能出现的系统性不公平差异。
Robustness鲁棒性面对噪声、扰动或环境变化仍稳定工作的能力。
Adversarial Example对抗样本经过特定扰动以诱导模型错误预测的输入。
Adversarial Training对抗训练在训练中加入对抗扰动以提升稳健性的方法。
Privacy-preserving ML隐私保护机器学习尽量减少模型训练或使用时隐私风险的技术。
Differential Privacy (DP)差分隐私限制单个记录对输出分布影响的隐私保证框架。
Federated Learning联邦学习数据留在本地、多方协同训练模型的机制。
Model Card模型卡片记录模型用途、评估、限制及风险的说明文档。
Dataset Documentation数据集文档描述数据来源、采样、标注和适用边界的信息。
EDITORIAL NOTES

翻译与使用约定

本表用于快速查阅，不替代完整的数学定义、算法论文或框架 API 文档；不同教材与研究社区可能使用不同译名。

  • Accuracy 与 Precision：前者为分类整体准确率；后者为预测为正的样本中实际为正的比例。
  • Precision 与 Recall：精确率侧重误报，召回率侧重漏报；取舍应由业务目标决定。
  • Parameter 与 Hyperparameter：前者由训练学习，后者控制训练过程或模型配置。
  • Data Drift 与 Concept Drift：前者多指输入分布变化；后者关注输入与目标关系变化。
  • Normalization 与 Standardization：术语依语境可能重叠，实际使用应写明变换公式。
