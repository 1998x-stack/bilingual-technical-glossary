APPENDIX A / 重点辨析

易混数学术语辨析

同为常见英文术语，但数学含义不一定可互换；下表适合写作、翻译和教学时快速校对。
术语对照区别与使用提醒
导数 derivative / 微分 differentialderivative 是变化率；differential 是变化量的一阶线性部分。
像集 image / 陪域 codomain像集是实际输出的集合；陪域是预先指定的目标集合。
单射 injective / 满射 surjective单射强调输入不混淆；满射强调输出无遗漏。
极大值 maximum / 上确界 supremummaximum 必须被集合某元素取到；supremum 可以取不到。
可导 differentiable / 连续 continuous一元函数可导必连续；连续不一定可导。
等价 equivalent / 相等 equal等价依赖语境中的关系；相等强调值或对象相同。
秩 rank / 维数 dimension秩通常指像空间维数；维数可指任意向量空间的基数。
特征值 eigenvalue / 奇异值 singular value特征值可为复数；奇异值为非负实数，且一般不相同。
互斥 mutually exclusive / 独立 independent互斥指不能同时发生；独立指 P(A∩B)=P(A)P(B)。
概率密度 PDF / 分布函数 CDFPDF 不直接表示单点概率；CDF 表示 P(X≤x)。
统计量 statistic / 参数 parameter统计量依赖样本；参数描述总体分布。
估计量 estimator / 估计值 estimateestimator 是随机函数；estimate 是计算后的具体数值。
显著 statistical significance / 实际重要 practical importance统计显著不自动意味着效应足够大或具有应用价值。
逐点收敛 pointwise / 一致收敛 uniform一致收敛要求误差在整个定义域统一小。
稳定性 stability / 收敛性 convergence稳定性关注误差传播；收敛性关注离散化细化后的极限。
局部最优 local optimum / 全局最优 global optimum局部最优只比较附近；全局最优比较整个可行域。
解析 analytic / 全纯 holomorphic在复分析开集上两者等价；在实分析中 analytic 要求局部幂级数展开。
条件收敛 conditional / 绝对收敛 absolute绝对收敛可推出收敛；条件收敛不满足绝对收敛。
拓扑同胚 homeomorphism / 微分同胚 diffeomorphism后者要求映射及其逆足够光滑，条件更强。
标准差 standard deviation / 标准误 standard error标准差刻画数据散布；标准误刻画估计量抽样波动。
